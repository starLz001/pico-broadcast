MR 安全防护
========================================
插件提供 MR 安全防护功能。当场景内的物体与 PICO 头戴或手柄间的距离处于一定范围内时，虚拟场景会变为半透明状态，呈现出现实场景。因此，在保证用户安全的前提下，该功能可以最大限度地保持应用的沉浸式体验。
*原理简述
头戴或手柄位置包裹的碰撞球与空间中的网格发生碰撞后，现实环境透出。
*
*MR 安全防护使用须知
我们希望持续为用户提供良好的系统体验，降低系统使用摩擦，保证系统使用安全。在新一代 MR 系统体验中，透视效果获得了明显提升，我们也将引入更多优秀的 MR 体验。
在 MR 应用和体验中，用户天然地可以看到周围的真实环境，对于周围危险的感知也更明确，在此情况下，我们希望提出一种全新的系统安全措施，使得用户在安全的前提下，能够顺畅、无障碍地在 MR 环境中使用应用。
*生效时机
“MR 安全”仅在一些 MR 应用中生效，而其他应用则启用“VR 安全”，在主控室中则启用“主控室安全”。你可以点击 Home 键，在【导航栏】 -【控制中心】中看到当前启用的安全模式。
*安全提醒
在启用了 MR 安全的应用中，系统将会自动检测现实环境中的物品或墙面，并在你靠近它们时，在虚拟画面中透出展示这些物体，提醒你已经接近障碍物。（目前仅针对头和双手进行检测）
*如果真实环境没有被虚拟物体或虚拟环境覆盖，则用户与真实环境交互是无感的。
*如果真实环境被虚拟物体或虚拟环境覆盖，当用户靠近真实环境中的物品时，系统会透出这些物品，提醒你已经接近障碍物。
*请始终留意周围环境
请注意，设备屏幕展示的外部世界是摄像头录制画面，可能并不能精确反映真实世界的距离感和位置关系；同时，MR 安全系统对现实环境的检测能力有限，可能无法检测出部分物体或危险，如透明、反光、暗色或低反射材料、远距离或高速移动的物体等。因此，使用MR功能时请务必谨慎注意周围环境、他人或动物，远离危险物品，确保原地使用。
*确保活动空间安全
请保持只在室内使用 PICO 一体机。避免在使用 MR 功能时进行高速运动或快速摆动四肢。使用设备前，请确保你的活动空间是安全的，并移除一切不适合在 MR 环境下互动的危险、障碍物品（例如液体、热源或尖锐物体）。请勿在需要注意安全的情况下使用本设备，例如驾驶交通工具、开展户外运动等。
*安全开展互动
使用 MR 功能前，请阅读并严格遵循安全警告和系统指引，正确摆放用于 MR 的真实世界物品并谨慎地与之互动。
更多的设置选项，例如碰撞提醒的灵敏度等，你也可以前往【设置】-【安全防护】中进行自定义设置。
*为什么需要 MR 安全防护？
全新的 MR 应用体验中，用户可以看到周围真实环境，并可以根据当下需要，任意选择与真实环境交互还是与虚拟物体或虚拟环境交互。
VR 安全边界已经无法满足用户在这种情况下的良好体验：
*它会限制用户的移动范围。
*在用户靠近边界时显示围栏。
*并且在走出边界后就无法与应用中的虚拟信息进行交互。
为此，我们提出全新的 MR 安全体系，希望提供给用户更加自然、友好、舒适的 MR 系统体验，同时保证用户的安全性：
*用户可以在真实环境中走动，不会显示安全边界。
*可同时与真实物体和虚拟物体或虚拟环境互动。
*仅当虚拟物体或虚拟环境遮盖了视野时，用户靠近障碍物才会提醒用户。
*什么类型的应用可以使用 MR 安全防护？
MR 安全仍是实验性系统安全体验，目前需要满足以下条件才可申请使用 MR 安全模式：
*全程开启透视功能，用户可以无障碍地查看现实世界。
*没有长时间、大范围虚拟画面遮挡用户视野，核心场景均采用 MR 体验形式。
*应用的主要交互没有使用跑动、快速移动等激烈动作。
对于以下的一些特殊情况，也可以申请使用 MR 安全模式，但需要有足够明确的安全提示信息和用户同意交互，针对应用体验形式给出一些相应的必要保护措施：
*替换真实物体表面类型的虚拟体验。此类型的体验建议采用半透明效果，使得用户可以观察到真实环境并做出判断，并需要有足够的安全措施保障用户安全。如果用户移动超过约一米，建议将所有显示内容变为半透明，当用户原地使用时恢复虚拟体验。
*应用内短暂的出现 VR 场景，如主界面、设置、暂停、过渡等非应用核心场景。首先应用中应尽可能避免这类体验出现，如无法避免，需要有足够的安全措施保障用户安全。如果用户移动超过约一米，建议将所有显示内容变为半透明，当用户原地使用时恢复虚拟体验。
*对于出拳、踢腿等动作，仅可在原地进行，需要有足够的安全措施和提醒，保障用户安全。如果用户移动超过约一米，建议将所有显示内容变为半透明，当用户原地使用时恢复虚拟体验。
*最终能否使用 MR 安全模式，会以应用审核结果为准。
*为应用开启 MR 安全保护能力
*前提条件
*在 UE 编辑器中创建一个项目或打开已有项目。
*已为应用启用 “空间网格” 能力。详细说明参考此文档。启用空间网格能力后，系统可以扫描物理环境，生成 Mesh 数据，作为空间内的障碍物。
*操作步骤
*在 UE 编辑器中创建一个项目或打开已有项目。 
*在编辑器左上角，点击 编辑（Edit） > 项目设置（Project Settings） > 插件（Plugins） > PICO OpenXR。 
*移动到 Mixed Reality 选项卡下，确认已勾选 Enable MR Safeguard 选项。
