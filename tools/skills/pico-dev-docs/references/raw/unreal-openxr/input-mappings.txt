手柄输入映射
========================================
*本文档介绍如何使用 PICO Unreal OpenXR Plugin 在 UE 编辑器中设置手柄输入映射。
*设备要求
*PICO 设备：PICO Neo3、PICO 4、PICO 4 Pro、PICO 4 Enterprise、PICO G3、PICO 4 Ultra 或 Project Swan（PICO OS 6）
*前提条件
你已在引擎中安装并启用了 PICO Unreal OpenXR 插件。详情参考 PICO Unreal OpenXR 快速开始。
*配置步骤
参考以下步骤配置 Enhanced Input 插件后，再进行 PICO 手柄的按键映射。
*前往 编辑 >  插件 > 内置 >Input，勾选 Enhanced Input 插件。
* 
*前往 内容浏览器 > 内容 > VRTemplate > Input，根据场景需要，对输入映射上下文的数据资产进行 PICO 手柄的按键映射。 
* 
*你可参考下表示例添加 PICO 手柄的按键映射，也可以自定义你的按键映射。
