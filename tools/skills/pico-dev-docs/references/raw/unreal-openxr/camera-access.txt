访问相机数据
========================================
Camera API 允许你在虚幻引擎中通过蓝图和 C++ 访问 PICO 设备的物理相机（例如透视彩色相机）。其接口主要通过蓝图函数库 UPICOCameraFunctionLibrary 提供，而相关的枚举、结构体和句柄类型则定义在 PICO_CameraTypes.h 文件中。
Camera API 采用基于会话 (Session) 的生命周期，其典型工作流程如下：
*枚举可用相机并选择一个 CameraID。
*创建设备句柄。
*基于设备和配置创建捕捉会话。
*在会话中查询相机的内外参数。
*开始捕捉并逐帧获取图像。
*按顺序结束捕捉，并销毁会话和设备。
在运行时，Camera API 通过两个核心句柄来管理对象：FPICOCameraDeviceHandle (相机设备) 和 FPICOCameraCaptureSessionHandle (捕捉会话)。要判断句柄是否有效，你可以在 C++ 中调用 IsValid() 方法，或在蓝图中检查异步节点的 bSuccess 输出引脚。
*环境要求
*PICO 设备型号：PICO 4 Ultra 或 Project Swan（PICO OS 6）
*PICO 设备系统版本：5.15.0 及以上
*前提条件
*选择 Edit > Project Settings > Platforms > Android，找到 Advanced APK Packaging 并在 Extra Permissions 中添加 android.permission.CAMERA。
 
*实现方法
*本文以蓝图为例展示如何使用 Camera API 访问相机数据。
*申请相机权限
*主动调用 Request Android Permissions 蓝图接口，在 Permissions 中输入权限字段：android.permission.CAMERA 申请相机权限。
* 
*枚举可用相机的 Camera ID
*使用 Enumerate Available Cameras PICO 枚举可用的 Camera ID（可传入 FPICOCameraPropertyFilter 进行朝向、位置和类型过滤）。
* 
*你可以根据 Camera ID 查询每个物理相机具备的能力属性及参数。
* 
*创建设备和捕捉会话
*选择一个 Camera ID，调用 Create Camera Device Async PICO 异步创建设备，得到 FPICOCameraDeviceHandle。你可以根据FPICOCameraDeviceHandle 查询相机内外参数。
*结合 Get Supported Resolutions PICO、Get Supported Image Formats PICO、Get Supported FPS PICO、Get Supported Transfer Types PICO、Get Supported Models PICO 等能力查询结果，构造 FPICOCameraCaptureConfig，然后调用 Create Capture Session Async PICO  创建捕捉会话，得到 FPICOCameraCaptureSessionHandle。
* 
*查询相机内外参
*需要标定或对齐时，调用 Get Camera Intrinsics PICO 和 Get Camera Extrinsics PICO 查询相机内外参。
* 
*开启相机捕获
*调用 Begin Camera Capture PICO 开启相机捕获。
*在 Tick 中循环调用 Acquire Camera Image PICO 获取图像数据，再通过 Update Render Target With Image Data PICO  或 Create Texture From Image Data PICO 更新到材质或纹理中。
* 
*例如，你可以先创建一个 RenderTarget2D 和一个无光照材质，再将该材质应用到场景中的 Plane 模型上。开启相机捕获后，你便可以在每一帧获取相机图像，并用它来更新此 RenderTarget2D。
* 
*清理资源
*使用完成后，按 End Camera Capture PICO → Destroy Capture Session PICO  → Destroy Camera Device PICO  的顺序清理资源。
