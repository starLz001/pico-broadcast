什么是 PICO OpenXR 插件
========================================
PICO Unreal OpenXR Plugin 是 PICO 官方基于 OpenXR 标准提供的、集成在虚幻引擎上的插件，提供了对 Unreal OpenXR 的支持和额外扩展能力，还包含 Tile 可视化工具、编辑器设置、运行时设置、PICO OpenXR Loader。你可前往 Fab 安装该插件到虚幻引擎 5 开发正式的 PICO 应用。
Plugin 所提供的功能皆遵循 Unreal 建立的 XR 规范。你可阅读 UE 官方 XR 文档 了解相关信息。
*重要提示
*PICO Unreal OpenXR Plugin 仅支持开发 64 位应用。
*功能清单
PICO Unreal OpenXR Plugin 最新版提供以下功能。了解更多信息，参考 PICO Unreal OpenXR Plugin 更新说明。

*PICO Unreal OpenXR Plugin 与 PICO Unreal Integration SDK 中的 OnlineSubsystemPICO 插件和 PicoSpatialAudio 插件可以共同使用。了解更多，参考 PICO Unreal Integration SDK 文档。

模块

功能

说明

*渲染  

系统启动画面

支持添加自定义图片作为加载应用时的系统启动画面，优化用户的等待体验。 



应用内启动画面

支持调用虚幻引擎接口实现应用内启动画面。



注视点渲染

支持静态注视点渲染和眼动追踪注视点渲染，将视野中心区域以高分辨进行渲染，周边区域以低分辨率渲染，从而减轻 GPU 负担。 



Tile 可视化工具 

支持使用 Tile 可视化工具，可以在虚幻引擎中可视化屏幕上每个 Tile 的分辨率。 



Vulkan 渲染

支持 Vulkan 渲染。



屏幕刷新率

支持获取和设置屏幕刷新率。 



屏幕分辨率

支持设置屏幕分辨率。



VR 合成层

支持使用 VR 合成层渲染场景中的焦点对象，例如信息、光标等。 



多视图渲染

支持多视图渲染能力。 



应用空间扭曲

支持应用以实际屏幕刷新率的一半来渲染画面，而不影响显示质量。



焦点感知

支持查询应用焦点状态。



PICO 3D 高斯溅射插件（Beta）

支持加载和渲染 3D 高斯溅射 (3DGS) 资源。



图像超分辨率

支持启用超分辨率能力。



图像锐化

支持启用锐化能力。

*输入&追踪 

手柄输入映射

支持配置手柄的按键映射。 



系统键盘

支持设置虚拟键盘。 



触觉反馈

支持虚幻引擎触觉反馈能力。 



眼动追踪

支持眼动追踪和眼动追踪校准。 



手势追踪 

支持获取手部姿势和动作数据。 



手势交互

支持用户在没有手柄的情况下，使用手势作为“手柄”使用相关能力。



手掌位姿

支持将 Motion Controller 的动作数据源设定为手掌。



原点追踪

支持根据设置的原点来追踪和计算位置变化。



全身动捕

*支持收集用户的身体位置和动作信息，并将其转换为可再现的姿态数据。



独立追踪

支持实时追踪并输出体感追踪器的 6DoF 信息。



扩展外设

支持用户连接自己的硬件外设。



脸部追踪

支持获取面部表情和 Lipsync 权重。

*环境感知 

视频透视 

支持将真实物理世界画面实时显示在 PICO 头显内。



平面检测

支持识别现实环境中的水平面、垂直面和语义平面，用于放置或对齐虚拟对象。



获取相机帧数据

支持读取设备物理相机的校正后双目 RGB 图像，支持相机能力查询、设备与会话创建、图像采集、纹理更新、内外参获取及资源释放。



共享空间锚点

支持在同一物理空间内，当不同的用户体验同一款应用时，让用户们共享场景内容。



空间网格

支持将物理世界重构为空间网格，可以更好地实现虚拟物体与现实物体之间的交互。



场景标定

支持标定现实空间中的家具等，并用于与 MR 虚拟物体进行交互。



MR 安全防护

支持当场景内的物体与 PICO 头戴或手柄间的距离处于一定范围内时，虚拟场景会变为半透明状态，呈现出现实场景。 

*其它 

内容保护 

支持内容保护功能，防止用户对应用中的画面截屏、录屏或投屏。 



安全区

支持使用虚幻引擎接口获取当前空间（如 Stage 空间）的安全区。



查询设备信息&设置设备

支持查询和设置 PICO 设备。



查看虚幻引擎日志

支持查看虚幻引擎日志。



混合现实捕捉

支持录制混合现实视频。



PICO OpenXR Portal

提供项目配置向导、项目检测以及文档、Samples、源码快捷入口。
