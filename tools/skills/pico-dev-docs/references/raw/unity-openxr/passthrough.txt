透视
========================================
透视（Passthrough）技术可以打破 VR 头显提供的全封闭式虚拟环境。其通过头显上的摄像机实时采集周围环境的视图，然后通过图像处理算法将真实场景画面呈现在头显屏幕上，使用户可以直接在头显屏幕上浏览现实场景。最终，透视画面可以与应用内的虚拟场景融合，呈现混合现实效果。 
透视画面由 PICO 系统直接处理并上屏展示，应用程序无法获取用户的任何物理环境信息。
* 
*环境要求
*SDK 版本：
**
*PICO 设备型号：PICO Neo3 系列、PICO 4 系列、PICO 4 Ultra 系列
*PICO 设备系统版本：5.7.0 及以上
*注意事项 
*使用 ”透视“ 能力时，需禁用场景内的所有后处理能力，否则透视无法生效。 
*若你在项目中使用了通用渲染管线（URP），则需要禁用 HDR，否则透视无法生效。
* 
*准备工作
*第一步：设置场景内的主相机
*选中场景中的主相机（通常为 Main Camera）。 
*在 Camera 面板处，为主相机进行以下设置： 
*将 Clear Flags 设置为 Solid Color。 
*设置完成后，相机渲染每一帧前，会在逐像素过程中清除每个像素的颜色值，然后将需要渲染的颜色值（即接下来设置的 Background 颜色值）写入。 
* 
*在 Background 处，点击颜色条，打开 Color 窗口，将 R、 G、 B、 A 值都设置为 0，或直接将 Hexadecimal 设置为 000000。 
*场景的背景颜色已被设置为黑色，Alpha 通道已被设置为完全透明。 
* 
* 第二步：启用 OpenXR Passthrough 拓展
*前往 Edit > Project Settings > XR Plug-in Management > OpenXR。
*在 OpenXR Feature Groups 区域，勾选 OpenXR Passthrough 选框。
*已开启透视能力。
* 
*设置全场景透视
全场景透视（Reconstruction Passthrough）可以将整个背景作为透视层。现实世界作为背景实时显示在 PICO 头显屏幕上，场景中的虚拟物体将覆盖在背景图上，形成穿透式 AR 场景。
* 
*方式一：调用接口
*在代码编辑器中打开你的脚本文件，然后在 Awake 或者 Start 部分调用 EnableSeeThroughManual 接口，为应用开启透视。 
*暂停应用后，透视将自动失效。因此，需在 OnApplicationPause 部分再次调用 EnableSeeThroughManual 接口，以便应用恢复后重启透视。

*设置投射型透视
你可以指定背景中的某一块区域作为透视层，即投射型透视（Projected Passthrough）。

*已知问题
*若设备的系统版本为 5.8.0，调用 SetColorMapbyMonoToMono 和 SetColorMapbyMonoToRgba 接口为全场景透视（Reconstruction Passthrough）设置特效会导致黑屏。

// 开启透视 
void Awake() 
{ 
    PassthroughFeature.EnableSeeThroughManual(true); 
} 
 
// 应用恢复后，再次开启透视 
void OnApplicationPause(bool pause) 
{ 
    if (pause)
    {
        PassthroughFeature.EnableSeeThroughManual(false);
    }
    else
    {
        PassthroughFeature.EnableSeeThroughManual(true);
    }
}

public void SetBrightnessContrastSaturation()
{
    // 设置透视画面的亮度、对比度和饱和度
    PassthroughFeature.SetBrightnessContrastSaturation(ref passthroughStyle, brightness,contrast,saturation);
    // 将设置的特效更新至透视层
    PassthroughFeature.SetPassthroughStyle(passthroughStyle);
}

public void MONO_TO_MONO()
{
    // 设置 Mono 值
    MONOvalues = new int[PassthroughFeature.XR_PASSTHROUGH_COLOR_MAP_MONO_SIZE_FB];
    for (int i = 0; i < PassthroughFeature.XR_PASSTHROUGH_COLOR_MAP_MONO_SIZE_FB; ++i)
    {
        MONOvalues[i] = i;
    }
    PassthroughFeature.SetColorMapbyMonoToMono(ref passthroughStyle, MONOvalues);
    // 将设置的特效更新至透视层
    PassthroughFeature.SetPassthroughStyle(passthroughStyle);
}

public void MONO_TO_RGBA()
{
    // 设置 RGBA 值
    values = new Color[PassthroughFeature.XR_PASSTHROUGH_COLOR_MAP_MONO_SIZE_FB];
    for (int i = 0; i < PassthroughFeature.XR_PASSTHROUGH_COLOR_MAP_MONO_SIZE_FB; ++i)
    {
        float colorValue = i / 255.0f;
        values[i] = new Color(0.0f, colorValue, 0.0f, 1.0f);
    }
    PassthroughFeature.SetColorMapbyMonoToRgba(ref passthroughStyle, values);
    // 将设置的特效更新至透视层
    PassthroughFeature.SetPassthroughStyle(passthroughStyle);
}

public static unsafe void SetBrightnessContrastSaturation(ref PassthroughStyle style, float brightness ,
    float contrast , float saturation )



参数

说明

style

SDK 会使用传入的亮度值、对比度值和饱和度值生成一个 Color Map，然后最终生成 PassthroughStyle 结构体中的 TextureColorMapType、TextureColorMapDataSize 和TextureColorMapData 数据。

brightness

指定亮度值。取值范围：[0,1]。

contrast

指定对比度值。取值范围：[0,1]。

saturation

指定饱和度值。取值范围：[0,1]。

public static unsafe void SetColorMapbyMonoToMono(ref PassthroughStyle style, int[] values)



参数

说明

style

SDK 会使用传入的 values 值生成一个 Color Map，然后最终生成 PassthroughStyle 结构体中的 TextureColorMapType、TextureColorMapDataSize 和TextureColorMapData 数据。

values

传入整数数组，该数组定义了映射关系。数组中的每个元素对应于特定的输入亮度级别，整数值表示该输入亮度级别的期望输出亮度级别。

public static unsafe void SetColorMapbyMonoToRgba(ref PassthroughStyle style, Color[] values)



参数

说明

style

SDK 会使用传入的 values 值生成一个 Color Map，然后最终生成 PassthroughStyle 结构体中的 TextureColorMapType、TextureColorMapDataSize 和TextureColorMapData 数据。

values

传入 RGBA 颜色数组，取值范围：[0,1]。该数组定义了映射关系。数组中的每个元素对应于特定的亮度级别，并且 Color 值表示该亮度级别所对应的 RGBA 颜色。

public static void SetPassthroughStyle(PassthroughStyle style)

  public struct PassthroughStyle
    {
        public bool enableEdgeColor;
        public bool enableColorMap;
        public float TextureOpacityFactor;
        public Color EdgeColor;
        public PassthroughColorMapType TextureColorMapType;
        public uint TextureColorMapDataSize;
        public IntPtr TextureColorMapData;
    }



字段

类型

说明

enableEdgeColor

bool

是否启用定义边缘渲染颜色：
*true：启用，Runtime 会读取 EdgeColor。
*false：不启用。

enableColorMap

bool

是否启用 ColorMap 特效：
*true：启用，Runtime 会读取 TextureColorMapType、TextureColorMapDataSize、和 TextureColorMapData。
*false：不启用。

TextureOpacityFactor

float

透明度。取值范围：[0,1]。

EdgeColor

Color

边缘渲染颜色。可指定任意颜色，该颜色会作为透视图像边缘的颜色。

TextureColorMapType


PassthroughColorMapType

Color Map 类型，由调用的具体接口决定。值如下：
*PassthroughColorMapType.BrightnessContrastSaturation
*PassthroughColorMapType.MonoToMono
*PassthroughColorMapType.MonoToRgba

TextureColorMapDataSize

uint

Color Map 的数据大小，由 SDK 自动转化。

TextureColorMapData

IntPtr

Color Map 的数据地址，由 SDK 自动生成。
