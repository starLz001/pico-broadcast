最佳实践
========================================
*使用多线程渲染
*使用多线程渲染，从而在单独的线程上完成底层图形接口调用。详见官方文档。
*关闭帧率同步
*无论你设置的目标帧率是多少，VSync 都会将应用的帧率与显示器的刷新率进行同步。因此，如果你想通过使用目标帧率来更好地控制应用的帧率，可以关闭帧率同步。步骤如下：
*从上方菜单栏处，选择 Edit > Project Settings。
*你将看到 Project Settings 弹窗。
*从左侧导航栏处，选择 Quality。
*窗口右侧将显示 Quality 配置面板。
*在 Others 处，将 VSync Count 设置为 Don't Sync。
