启动画面
========================================
用户点击一款应用的图标后，PICO 系统需要一段时间来初始化渲染系统和 XR 系统，然后才启动应用。你可以在 Unity 编辑器内添加一张 .png 图片，作为应用的启动画面。
*应用场景
*减少初始化加载画面停留时间
*为了保证用户体验，应用的初始化加载画面停留时间不宜过长，建议控制在 5 秒以内。在关闭所有后台应用的前提下，你可以启动目标应用，测试其初始化所需时间。如果超过 5 秒，则建议为应用添加启动画面。
*宣传应用形象
*结合应用的主题，在启动画面上设计相关素材，宣传应用形象。
*提升品牌知名度
*在启动画面上添加开发者或开发商信息，提升品牌知名度。
*环境要求
*PICO 设备型号：PICO Neo3 系列、PICO 4 系列、PICO 4 Ultra 系列
*PICO 设备系统版本：5.7.0 及以上

*配置启动画面
*在 Unity 编辑器内打开你的项目。
*前往 Edit > Project Settings > XR Plugin-in Management > OpenXR。
*在 OpenXR Feature Groups 区域，点击 PICO Support 选框右侧的设置按钮。
* 
*你将看到 PICO Support 窗口。
*在 System Splash Screen 处，上传一张 .png 格式的图片，作为应用的启动画面。
