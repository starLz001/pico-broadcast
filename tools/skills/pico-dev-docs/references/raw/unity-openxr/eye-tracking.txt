眼动追踪
========================================
通过眼动追踪功能，可在应用中实时追踪用户的注视点。眼动追踪本质上是一种传感器技术，可将用户的眼部移动转换为数据流，包含瞳距、双目注视向量以及注视点，作为设备的输入。设备通过对数据流进行解码，向用户实时呈现其眼球的注视画面。 眼动追踪技术可大大提升应用画面的流畅性，减轻 VR 应用使用中可能导致的眩晕感。
*环境要求
*PICO 设备型号：PICO Neo3 Pro Eye、PICO 4 Pro 和 PICO 4 Enterprise
*PICO 设备系统版本：5.7.0 及以上
*Graphics API：Vulkan
*使用流程
*第一步：为应用开启眼动追踪
*在 Unity 编辑器内打开你的项目。
*前往 Edit > Project Settings > XR Plugin-in Management > OpenXR。
*在 Interaction Profiles 区域，点击 + 展开菜单，然后添加 Eye Gaze Interaction Profile。Eye Gaze Interaction 相关信息可参考 Unity 官方文档。
* 
*在 OpenXR Feature Groups 区域，点击 PICO Support 选框右侧的设置按钮。
*你将看到 PICO Support 窗口。
*勾选 Eye Tracking 选框。
* 
*已开启眼动追踪能力。
*(可选) 勾选 Eye Tracking Calibration 选框。 
*开启后，你的应用可以唤起 PICO 系统提供的 ”校准视线追踪“ 功能，进行眼动追踪校准。
*第二步：为 PICO 设备开启眼动追踪
为 PICO 设备开启眼动追踪能力，以便在设备上体验眼动追踪效果。
*启动 VR 一体机。 
*前往 设置 > 实验室 > 视线追踪。 
*打开 视线追踪 开关。 
* 
*点击 校准视线追踪 > 开始校准。 
* 
*按照提示完成校准。
*第三步：体验眼动追踪效果
*在 Project 窗口中，前往 /Assets/Samples/OpenXR Plugin/1.7.0/Controller 目录，双击打开 ControllerSample 场景。
* 
*前往 File > Build Settings，打包当前场景并在 PICO 设备上运行。
