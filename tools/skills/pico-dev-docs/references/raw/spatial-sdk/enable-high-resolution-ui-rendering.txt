开启高清 UI 渲染
========================================
高清 UI 渲染是一种将原本由独立应用进程完成的 2D 界面渲染，转变为由 PICO OS 6 系统服务统一渲染 UI 和合成的技术，解决了当用户走向已打开的 2D 窗口时，界面会逐渐变糊的问题。
*开启之后：
*为用户提供高清文字和矢量图；
*减少高清渲染的性能开销；
*协助实现 Spatial UI 中的空间浮起等特效。
当前高清 UI 渲染功能仍处于 Beta 阶段，你可以在开发者选项里为应用开启或关闭高清 UI 渲染。
* 


如需体验 Spatial UI 的功能，需要开启高清 UI 渲染。
