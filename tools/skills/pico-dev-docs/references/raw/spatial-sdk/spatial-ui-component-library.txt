Spatial UI 主题和组件
========================================
Spatial UI 是在 PICO OS 6 上首要支持的空间应用开发框架，提供声明式的开发体验，主要特性如下：
*Android 开发者友好，兼容 Android 生态
*声明式 UI
*2D/3D 融合
*支持多窗口与多应用形态
*多交互模态友好
*远场：眼手、手柄
*近场：裸手触控， 手柄
*外设：鼠标、键盘等
 
*基于 PICO Design 的品牌风格，Spatial UI 提供了丰富的主题和组件，助力你为应用打造体验统一且品牌鲜明的用户界面。
*主题
Spatial UI 组件库提供了一套具有 PICO 品牌风格的主题样式（PicoTheme），包含颜色、文字排版、通用以及系统材质四项配置，用于定义空间应用的外观风格并影响各组件的默认表现。例如：

*组件
组件是用于灵活构建一个完整空间应用的模块化单元。Spatial UI 组件库提供了一系列基于 PICO Design 的高质量、可配置组件，例如 Button、TextField 和 ToolBar。通过使用这些 UI 组件，你可以将传统 2D 内容与交互集成到应用中。
 
更多关于组件的介绍和使用说明参考《Spatial UI 组件库》。
