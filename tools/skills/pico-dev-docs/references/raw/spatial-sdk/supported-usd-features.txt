支持的 USD 特性
========================================
PICO Spatial SDK 和 PICO Spatial Editor 使用 OpenUSD（版本 26.03）作为主要的 3D 内容格式。为了帮助你判断哪些 USD 特性可以直接使用、哪些存在兼容性限制，本文从几何、材质、动画与骨骼、场景结构四个方面，介绍各项特性在 PICO Spatial SDK 中的支持情况。
支持情况用于评估 USD 文件中的特性是否能够被 PICO Spatial SDK 和 PICO Spatial Editor 正确导入。本文使用以下标记表示支持情况。

❌ 不支持

不支持 cylinder_1 和 capsule_1（即顶部和底部半径支持单独定义的圆柱体和胶囊体）。

为确保颜色通道被正确识别，对应属性的命名需要符合 OpenUSD 推荐的标准 Primvar： primvars:displayColor。

颜色和不透明度应分别使用 OpenUSD 推荐的标准 Primvar：primvars:displayColor 和 primvars:displayOpacity。不要使用自定义名称替代这两个标准 Primvar。

*不同 DCC 工具导出的 MaterialX 支持程度存在差异。
*支持的 MaterialX 版本为 1.38.7。

纹理仅支持 .usdz 格式。使用 DCC 工具导出纹理时需要采用相对路径。

*PICO Spatial SDK 支持导入，但 PICO Spatial Editor 暂不支持导入。
