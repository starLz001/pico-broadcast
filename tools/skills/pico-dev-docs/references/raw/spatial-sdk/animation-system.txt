动画系统
========================================
*动画系统是用于驱动场景中内容产生动态效果的一整套机制与工具。借助动画系统，你可以为场景中的角色、物体和 UI 元素添加动态表现与交互效果。
*核心功能
*PICO Spatial SDK 提供了完整的动画系统框架，涵盖以下核心功能：
*动画数据管理：支持读取 3D 模型所绑定的动画数据。
*动画播放控制：包括播放、暂停、停止、循环等功能。
*动画的程序化生成：通过程序化生成实现补间动画。
*动画类型
*PICO Spatial SDK 支持多种类型的动画和动画事件。
*骨骼动画：基于骨骼层级与蒙皮权重的角色动画，适用于生物等复杂模型的自然运动。详情参阅《骨骼动画》。
*Blend Shape 动画：通过在基础网格与一个或多个目标形态之间执行线性插值来实现几何变形。通过组合多个权重参数，可以实现复杂的复合表情。详情参阅《Blend Shape 动画》。
*补间动画：通过插值来驱动属性变化的轻量动画，适合 Transform 或 Material 发生简单变化的场景。详情参阅《补间动画》。
*轨道动画：轨道动画是一种围绕指定轴线进行 “公转” 的动画效果。它会让一个对象以圆形路径绕某个轴线运动。详情参阅《轨道动画》。
*Timeline 动画：Timeline 动画是通过 PICO Spatial Editor 的 Timelines 动画效果器创建的动画。详情参阅《Timeline 动画》。
*动画事件：在动画播放过程中嵌入回调机制，实现如音效触发、逻辑同步等自定义控制。详情参阅《动画事件》。
