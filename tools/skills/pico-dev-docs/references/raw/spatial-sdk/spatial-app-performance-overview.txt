总览
========================================
在空间应用上，性能对于用户体验来说至关重要。一款优质的空间应用能够快速响应用户的交互，流畅显示各类内容。
*关键指标
通常来讲，应用的性能可以分为以下几个部分：
*启动和加载时间
*包括空间应用冷启动和其中内容加载的时间，加快加载速度能够减少用户的等待时间。
*交互流畅度
*用户在与空间应用中的 UI 或者物体交互时，应该能够获得实时的反馈：比如点击按钮后立刻展示一个弹窗，或者用手拿起一个虚拟的物体时，物体会紧紧跟随用户的手移动。
*渲染流畅度
*不同于传统应用，空间应用对于渲染流畅度的要求更加严格，掉帧和卡顿会严重影响用户体验，甚至引起用户的不适。
*内存占用
*一个空间应用可以运行在 Shared Space 下，与其他空间应用同时运行，尽可能低的内存占用不仅可以提高自身的运行效率，也可以提升用户在多任务下的体验。
*电池消耗
*复杂的任务会带来更快的电量消耗和更快的设备发热，降低设备续航时间，甚至进一步引起系统层面的对应用的限制。为了避免用户体验受损，空间应用应该更高效地利用有限的设备资源，比如减少线程数和不必要的后台任务。
*影响性能的常见因素
*2D UI 的编写
在空间应用中，2D UI 是重要的组成部分之一。虽然 Compose UI 本身提供了良好的性能表现，但仍然需要遵循其最佳实践，才能够避免常见的问题，提升用户体验。详情参阅《Jetpack Compose 性能》。
*模型的复杂度
复杂的模型会增加渲染压力、占用更多内存，从而影响渲染流畅度。一个模型的复杂度通常可以通过面数、纹理数量和分辨率、材质数量和类型、以及骨骼数量来衡量。
*ECS 的复杂度
在 ECS 中，实体和系统的复杂度都会对性能产生影响。
*系统（System）：如果需要保持 90 fps 运行，则要求每一帧的运算都在 11 ms 之内完成。而空间应用每一帧的运算不仅仅有应用定义的系统，还会包括你的 Compose UI 重组、动画、物理模拟等逻辑。这也就要求系统中的运算能够高效完成。
*实体（Entity）：实体的数量不仅会影响其占用的内存，还会增加一些操作的耗时（比如在系统中查询实体）。如果你的应用创建了大量实体，那么应用运行的流畅度就有可能会受到影响。
*物理模拟
如果在实体上添加了物理相关的组件，物理模拟就会持续运行，每帧都会计算每个实体的碰撞、受力、速度等，从而计算出每个实体新的位置和姿态，使得场景更加真实。但随着受力复杂度的增加，或参与碰撞计算的实体数量增多，每帧的物理模拟计算就会越复杂，耗时也就越久。
*动态光源和阴影
动态光源可以为场景和模型附加实时光照和阴影效果，使得场景更加真实。但动态光照的计算是很消耗性能的，光源数量越多，受光照影响的物体越多，都会提高运算消耗。
*性能问题排查工具
*PICO Spatial Profiler
PICO Spatial Profiler 是一款专门用于排查空间应用性能问题的工具，提供以下功能：
*快速诊断：帮助你快速查询空间应用及 PICO 空间引擎（PICO Spatial Engine）的 FPS、CPU 占用率等关键指标。
*Spatial Frames：在 Timeline 上显示 PICO 空间引擎每一帧的渲染阶段和耗时。
*Bottlenecks：在 Timeline 上识别并标记潜在的性能瓶颈。
*Spatial Metrics：提供 PICO 空间引擎的核心 3D 渲染指标。
如需了解该工具的详细用法，参阅《PICO Spatial Profiler》。
*Android Studio Profiler
Android Studio Profiler 提供了数个开箱即用的性能分析工具，包括：
*System Trace
*抓取 Trace 记录，分析运行状况。
*Analyze Memory Usage
*Dump 堆内存，分析内存使用状况。
*Find CPU Hotspots
*通过 Callstack Sample 或者 Method Recording 来记录 CPU 上各方法的耗时，发现性能瓶颈。
*Track Memory Consumption
*追踪 Java/native 对象的创建和回收，分析内存使用状况。
*View Live Telemetry
*展示实时 CPU 和内存占用。
关于 Android Studio Profiler 的详细使用说明，参阅官方文档。
*Perfetto
Perfetto 是一个开源 Trace 记录分析工具，可以用于记录、查看和分析系统和应用的 Trace 记录。通过 Perfetto，你可以了解、分析空间应用的运行记录。此外，Perfetto 也可以和 System Trace 共同使用。
*空间应用性能数据
空间应用拥有其不同于传统应用的特点和内容，比如空间容器、3D 内容、ECS 等等。为此，PICO 提供了一系列 Trace 数据来帮助分析这部分独特内容的运行状况和使用情况。详情可参阅《获取并分析 Trace》。
*优化性能
*性能优化是空间应用开发中的核心环节，贯穿于整个开发周期，其不仅能确保应用在复杂场景中稳定流畅运行，还能确保为用户带来更优质、更沉浸的体验。参阅《性能优化》，了解空间应用性能优化的流程以及常见问题的排查和处理方法。
