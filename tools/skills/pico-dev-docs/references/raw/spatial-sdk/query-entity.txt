查询实体
========================================
实体以树的方式维护其层级结构。你可以使用 PICO Spatial SDK 提供的函数来快速查询目标实体。
*实现方法
*使用 scene.queryEntity
通过 scene.queryEntity(EntityQueryCondition)，你可以查找到符合条件的所有实体。该函数会将这些实体返回为一个列表。

*使用 entity.findEntity(name)
*如果你已知目标实体的名称，则可以通过 entity.findEntity(name) 在当前实体的层级结构中查询对应的实体。该函数会遍历当前实体及其所有子实体（包含当前实体自身），返回第一个名称匹配的实体；若存在多个同名实体，仅返回遍历中最先命中的那个；若未找到则返回 null。该函数需要在主线程调用。
 
*使用 scene.findById(id) 
如果你已知目标实体的 ID，则可以通过 scene.findById(id: Long) 查找当前 Scene 中已注册的实体。如果实体不属于当前 Scene、已经从当前 Scene 中移除、已经销毁，或者不存在对应的 ID，则返回 null。该函数需要在主线程调用。
 
*使用 entity.getChildren
你可以通过 entity.getChildren() 获取当前实体的所有子实体，并结合广度优先搜索（BFS）或深度优先搜索（DFS）遍历整个实体树，在遍历过程中判断每个实体是否为目标实体。
 
*查询骨骼动画与 Timeline 动画实体
对于从模型加载得到的实体，你可以使用以下函数遍历当前实体及其子实体，检索特定类型的实体。这些函数需要在主线程调用；没有符合条件的实体时返回空数组。
*entity.findSkeletonRootEntity(includeDisabled: Boolean = false): Array<Entity>：查找可作为骨骼动画播放入口的骨骼根实体。
*entity.findTimelineEntity(includeDisabled: Boolean = false): Array<Entity>：查找可调用 playTimeline() 的 Timeline 动画实体。
*entity.findSkinnedMeshEntity(includeDisabled: Boolean = false): Array<Entity>：查找蒙皮网格实体。
其中，includeDisabled 表示是否将处于禁用状态的实体一并纳入查询结果，默认为 false。
 
*API 参考
EntityQueryCondition 类中提供了用于查询实体的接口，详情参阅 API 参考。根据你所处的地理位置选择合适的文档链接：
*中国大陆：https://developer-cn.picoxr.com/spatial-api/index.html

// 以广度优先（BFS）遍历实体树，查找名称为“PICO”的实体
fun findByNameBFS(root: Entity, targetName: String): Entity? {
    val queue = ArrayDeque<Entity>()
    queue.add(root)
    while (queue.isNotEmpty()) {
        val current = queue.removeFirst()
        if (current.getName() == targetName) {
            return current
        }
        queue.addAll(current.getChildren())
    }
    return null
}
