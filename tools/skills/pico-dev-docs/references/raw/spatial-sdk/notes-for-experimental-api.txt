实验性 API 的使用注意事项
========================================
*PICO Spatial SDK 提供了一些实验性 API，供开发者体验和测试新功能。这些 API 尚处于开发和验证阶段，因此在使用前，请务必了解并遵循以下注意事项。
*定义与风险
*实验性 API 是指尚未正式发布、仍在快速迭代中的接口。使用它们意味着你需要接受以下潜在风险：
*功能尚不稳定：实验性 API 的功能可能存在缺陷或不完善之处，其行为表现可能与最终正式版本不同。
*不保证向后兼容：我们不承诺对实验性 API 的向后兼容性。在未来的 SDK 版本中，其接口、参数或行为都可能发生重大变更，这或将导致你应用的代码需要重构才能适配。
*可能被移除或修改：任何实验性 API 都可能在未来的版本中被大幅修改甚至直接移除，届时将不再提供支持。

*PICO 商店上架限制
*请特别注意，任何使用了实验性 API 的应用，都无法在 PICO 应用商店上架。
*在应用提审时，PICO 商店的审核系统会检测应用是否包含 pico.spatial.use_experimental_api 这个 meta-data 标志。若检测到此标志，你的应用提交将被拒绝。
*因此，实验性 API 仅可用于开发、测试和原型验证目的。请切勿在计划上架发布的正式版本应用中使用。


<meta-data
    android:name="pico.spatial.use_experimental_api"
    android:value="1" />
