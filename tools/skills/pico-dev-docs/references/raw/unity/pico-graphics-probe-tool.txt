PICO 图像分析和调试工具
========================================
你可以使用 PICO 图像分析和调试工具（PICO Graphics Probe Tool）对应用的性能进行分析和调试。
*应用场景
*系统 GPU 数据抓取与分析
*抓取系统运行期间的 GPU 实时数据，例如 GPU 占用率、纹理缓存命中率、纹理过滤方式、显存读写速率等。
*应用渲染阶段数据抓取与分析
*启动某个应用，抓取该应用运行期间的渲染阶段数据，例如每帧的渲染耗时、Surface 数量、Tile-based-rendering (TBR) 渲染的 Bin 块数量、渲染模式等。
*绘制调用（Draw Call）相关数据抓取与分析
*启动某个应用，抓取该应用一次绘制调用命令的实时数据，例如 ALU 指令数量、硬件剔除的面片数量、顶点着色器处理的顶点数、像素着色器的片元数量等。
*环境要求
*PICO 设备型号：PICO Neo3 和 PICO 4 系列
*PICO 设备系统版本：5.8.0 及以上
*前置条件
*确保 PC 端已下载 Andorid Debug Bridge（即 adb 工具）。
*确保已使用 USB 数据线连接 PICO 设备和电脑。可以使用 adb devices 命令行查看已连接的 PICO 设备 ID。
*命令行参数说明
工具支持以下命令行参数，可用于获取 GPU 性能数据、追踪渲染阶段数据、追踪绘制调用数据等。
*
使用命令时，可以配合如下可选参数，实现不同的数据输出效果。
*
*获取 GPU 性能数据
获取 GPU 的实时性能数据，包括 GPU 使用率、GPU 频率、纹理/顶点/着色器相关数据等。
* 
*使用步骤
*执行 adb shell gprobe -r 或 adb shell gprobe --realtime 命令，获取 GPU 的实时数据。可配合以下可选参数实现更多能力（详细说明参考 “命令行参数说明” 部分）。
**
*通过终端支持的快捷键组合（例如：Ctrl + C）终止数据输出。
*GPU 性能指标参考
以下为 GPU 实时数据的指标 ID 和指标名称对照表。
*
*追踪渲染阶段数据
获取应用的渲染阶段数据，包括渲染时长、抗锯齿（MSAA）等级等。
* 
*步骤如下：
*执行 adb shell gprobe -e 或 adb shell gprobe --enable-detailed 命令，开启 GPU 性能详细分析功能。
*在头戴端手动启动目标应用。
*执行 adb shell gprobe -t 或 adb shell gprobe --trace 命令，追踪渲染阶段数据。可配合以下可选参数实现更多能力（详细说明参考 “命令行参数说明” 部分）。
**
*追踪绘制调用数据
获取应用的绘制调用数据，包括调用耗时、纹理/顶点/着色器相关数据等。
* 
*使用步骤
*执行 adb shell gprobe -e 或 adb shell gprobe --enable-detailed 命令，开启 GPU 性能详细分析功能。
*在头戴端手动启动目标应用。
*执行 adb shell gprobe -x 或 adb shell gprobe --drawcall 命令，追踪绘制调用数据。可配合以下可选参数实现更多能力（详细说明参考 “命令行参数说明” 部分）。

*已知问题
对于 PICO 4 Ultra 系列设备，使用 PICO Graphics Probe Tool 执行 gprobe -r id1 id2 ... id10 命令并运行几分钟后，设备会出现卡死并重启的情况。

*参数

完整命令

*说明

*-r 或 --realtime

adb shell gprobe -r 或 adb shell gprobe --realtime

获取 GPU 的实时数据。可以通过终端支持的快捷键组合（例如：Ctrl + C、Ctrl + Z）终止数据输出。

*-e 或 --enable-detailed
*

adb shell gprobe -e 或 adb shell gprobe --enabled-detailed

启动 GPU 性能详细分析功能，是追踪渲染阶段数据和绘制调用数据的前提条件。该命令在驱动程序的初始化阶段生效。因此，必须在目标应用启动之前开启该功能。若在启动该功能之前，目标应用已开始运行，则必须重启应用。
提示：
功能开启后，可能会增加至多约 10% 的 GPU 负载。

*-d 或 --disable-detailed

adb shell gprobe -d 或 adb shell gprobe --disable-detailed 

关闭 GPU 性能详细分析功能。

*-t 或 --trace

adb shell gprobe -t 或 adb shell gprobe --trace

执行一次渲染阶段数据追踪。

-x 或 --drawcall

adb shell gprobe -x 或 adb shell gprobe --drawcall

执行一次绘制调用数据追踪。

*-s 或 --select

adb shell gprobe -s {应用包名} 或 adb shell gprobe --select {应用包名}

通过包名指定某个应用，例如 adb shell gprobe -s com.pico.testpackage。
提示：不使用该命令时，默认使用 adb shell gprobe -a 命令选择所有可以被追踪性能数据的应用。

-a 或 --all

adb shell gprobe -a 或  adb shell gprobe --all

绑定所有当前可以被追踪性能数据的应用，包括 PICO 的系统级应用如 runtime、veshell、xrshell、seethrough 应用等，也包括在开启 GPU 性能详细分析功能后打开的其他三方应用。若成功则返回所有已选中的应用进程 ID。

-h 或 --help

adb shell gprobe -h 或  adb shell gprobe --help

获取命令行总览和说明。




参数

说明

--time n

--time 用于设置获取数据的间隔时间或持续时间，单位为 “秒”。该参数可以和 -r (或 --realtime)、-t ( 或 --trace) 以及 -x (或 --drawcall) 搭配使用，如 adb shell gprobe -r --time 2 表示每隔 2 秒获取一次渲染阶段数据。

-l 或 --low-mode

以低 GPU 负载模式执行一次渲染阶段数据追踪。需与 -t (或 --trace) 搭配使用，最终命令为 adb shell gprobe -t -l。设置该参数后，将不会输出详细的渲染阶段和 Bin 信息，而是以一个总体的 Workload(us) 指标代替。

-b 或 --bin

获取渲染阶段的 Bin 块相关的详细信息，包括 Bin 块分布，Bin 的渲染阶段耗时、部分静态注视点渲染（Fixed Foveated Rendering, FFR）信息。需与 -t (或 --trace) 搭配使用，最终命令为 adb shell gprobe -t -b。

-p 或 --poll-mode

以连续轮询的形式输出数据，减轻内存压力。可通过 Ctrl+C 终止数据输出。可以与 -t (或 --trace) 和 -x (或 --drawcall) 搭配使用，如 adb shell gprobe -t -p。

-m 或 --message

罗列 GPU 实时数据和绘制调用数据的指标 ID 和指标名称。需与-r (或 --realtime) 和 -x (或 --drawcall) 搭配使用，如 adb shell gprobe -m -r。

--table

以表格形式打印绘制调用相关数据，以便对照分析。后续可通过 adb shell gprobe -x --table > {文件名}.txt 命令将表格保存到本地。



可选参数

说明

-- time n

自定义获取实时数据的时间间隔。

-r id1 id2 id3 ...

选择需要输出的指标数据（idn 为指标 ID，具体参阅 “GPU 性能指标参考” 部分）。
提示：建议一次性获取不超过 10 种指标数据，否则会影响数据精度。

*18

*% Shaders Busy

所有着色器忙碌时间百分比。 

*19

*% Shaders Stalled

*EFU / Vertex

*% Time Shading Fragments

*% Time Shading Vertices

顶点着色耗费的时间百分比。计算公式：着色顶点所耗费的时间 / 着色所有内容所耗费的时间。 

*35

*% Time Compute

计算工作耗费的时间百分比。计算公式：计算工作所耗费的时间 / 着色所有内容所耗费的时间。

*% Shader ALU Capacity Utilized

*% Time ALUs Working

*% Time EFUs Working

*40

*% Linear Filtered

*48

说明

--time n

用于指定一次渲染阶段数据追踪的持续时间，默认为 0.05 秒。例如，adb shell gprobe -t --time 0.25 表示获取 0.25 秒内的渲染阶段数据。

-l

以低 GPU 负载模式执行一次渲染阶段数据追踪。

-p

以连续轮询的形式输出数据。

-b

获取渲染阶段的 Bin 块相关的详细信息。
