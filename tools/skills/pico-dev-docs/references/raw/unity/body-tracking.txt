全身动捕
========================================
*全身动捕是一种动作捕捉技术，用于收集用户的身体位置和动作信息，并将其转换为可再现的姿态数据。全身动捕技术能够支持用户在 XR 场景中进行跑、踢、踩、躺、扭腰等动作，丰富用户的动作体验。
PICO 的全身动捕功能需要结合 PICO 体感追踪器进行使用。PICO 体感追踪器可以获取用户身体位置和动作信息。全身动捕相关的接口会将这些信息转换为多个人体节点的姿态数据，作为应用的输入。
* 
*动捕模式
SDK 提供 “半身动捕” 和 “全身动捕” 两种模式，说明如下：
*
*环境要求
*PICO 设备型号：PICO 4 系列、PICO 4 Ultra 系列
*PICO 设备系统版本：5.13.0 及以上
*PICO 体感追踪器（正式版）
*前提条件
已在场景内添加 XR Origin 对象并为其挂载 PXR_Manager (Script) 组件。
*接入全身动捕功能
*第一步：为应用开启全身动捕能力
*在 Inspector 窗口中的 PXR_Manager (Script) 面板上，勾选 Body Tracking 选框，为应用开启全身动捕能力。开启后，可以调用全身动捕相关接口在应用内实现该功能。
* 
*第二步：获取 PICO 体感追踪器相关信息
PICO 体感追踪器硬件需与一体机端的 “体感追踪器” APP 配套使用。为确保你的应用能够接收来自体感追踪器的身体移动数据，需确保用户将体感追踪器硬件与 “体感追踪器” APP 进行配对（即连接），并在 APP 内完成人体校准。你可以通过接口获取体感追踪器的连接和校准状态。
*
 
*第三步：开始全身动捕功能
当 PICO 体感追踪器已与 “体感追踪器” APP 完成连接，用户已完成校准，体感追踪器的电量正常，且追踪模式已设置为 “全身动捕”，便可以开始全身动捕。相关接口如下：
*
在 StartBodyTracking 接口中，你需要指定人体追踪模式：BODY_JOINT_SET_BODY_START_WITHOUT_ARM （半身动捕）；BODY_JOINT_SET_BODY_FULL_START（全身动捕）。

调用 GetBodyTrackingData 接口获取各个身体节点的位置和方向数据，作为应用的输入。 
 
*第五步：停止全身动捕功能
当场景内已无需使用全身动捕功能或用户退出应用后，调用 StopBodyTracking 接口停止全身动捕。

模式

说明

半身动捕

输出 14 个人体关节点（0 至 13 节点）的位置和姿态信息，并提供踩踏数据。

全身动捕

输出全身 24 个人体关节点的位置和姿态信息，并提供踩踏数据。



接口

说明

GetBodyTrackingSupported

获取当前设备是否支持全身动捕

GetBodyTrackingState

获取已连接的体感追踪器的状态。

StartMotionTrackerCalibApp（相关废弃接口：OpenFitnessBandCalibrationAPP）

打开 “体感追踪器” APP 并启动校准。PICO 体感追踪器（正式版）支持一眼校准，Beta 版需按照 APP 界面提示的流程完成校准。

提示
为确保全身动捕数据的准确性，建议在使用过程中监听校准状态的变化。若数据变为不可用状态，则及时引导用户进行校准。



接口

说明

StartBodyTracking

开始全身动捕。

*BodyTrackingBoneLength boneLength = new BodyTrackingBoneLength();

*int ret = PXR_MotionTracking.StartBodyTracking(BodyJointSet.BODY_JOINT_SET_BODY_FULL_START,boneLength);

public class PXR_BodyTrackingBlock : MonoBehaviour
{
    public Transform skeletonJoints;
    public bool showCube = true;
    public float zDistance = 0;

    private bool supportedBT = false;
    private bool updateBT = true;

    private BodyTrackingGetDataInfo bdi = new BodyTrackingGetDataInfo();
    private BodyTrackingData bd = new BodyTrackingData();
    private Transform[] boneMapping = new Transform[(int)BodyTrackerRole.ROLE_NUM];
    BodyTrackingStatus bs = new BodyTrackingStatus();
    bool istracking = false;
    // 第一帧更新前调用 Start
    void Start()
    {
        skeletonJoints.transform.localPosition += new Vector3(0, 0, zDistance);
        InitializeSkeletonJoints();
        StartBodyTracking();
    }

    // 每帧调用一次 Update
    void Update()
    {
      

#if UNITY_ANDROID
        // 更新全身动捕位姿
        if (updateBT )
        {
            PXR_MotionTracking.GetBodyTrackingState(ref istracking, ref bs);

            // 若未完成人体校准，唤起 “PICO 体感追踪器” app 进行校准
            if (bs.stateCode!=BodyTrackingStatusCode.BT_VALID)
            {
                return;
            }
            // 获取每个人体节点的位置和朝向
            int ret = PXR_MotionTracking.GetBodyTrackingData(ref bdi, ref bd);

            // 若返回成功
            if (ret == 0)
            {
                for (int i = 0; i < (int)BodyTrackerRole.ROLE_NUM; i++)
                {
                    var bone = boneMapping[i];
                    if (bone != null)
                    {
                        bone.transform.localPosition = new Vector3((float)bd.roleDatas[i].localPose.PosX, (float)bd.roleDatas[i].localPose.PosY, (float)bd.roleDatas[i].localPose.PosZ);
                        bone.transform.localRotation = new Quaternion((float)bd.roleDatas[i].localPose.RotQx, (float)bd.roleDatas[i].localPose.RotQy, (float)bd.roleDatas[i].localPose.RotQz, (float)bd.roleDatas[i].localPose.RotQw);
                    }
                }
            }
        }

#endif
    }

    public void StartBodyTracking()
    {
        // 查询当前设备是否支持全身动捕
        PXR_MotionTracking.GetBodyTrackingSupported(ref supportedBT);
        if (!supportedBT)
        {
            return;
        }
        BodyTrackingBoneLength bones = new BodyTrackingBoneLength();

        // 开始全身动捕
        PXR_MotionTracking.StartBodyTracking(BodyJointSet.BODY_JOINT_SET_BODY_FULL_START, bones);
        
        PXR_MotionTracking.GetBodyTrackingState(ref istracking, ref bs);

        // 若未完成人体校准，唤起 “PICO 体感追踪器” app 进行校准
        if (bs.stateCode!=BodyTrackingStatusCode.BT_VALID)
        {
            if (bs.message==BodyTrackingMessage.BT_MESSAGE_TRACKER_NOT_CALIBRATED||bs.message==BodyTrackingMessage.BT_MESSAGE_UNKNOWN)
            {
                PXR_MotionTracking.StartMotionTrackerCalibApp();
            }
        }
        
        skeletonJoints.gameObject.SetActive(true);
        updateBT = true;
    }

    private void OnDestroy()
    {
        int ret = PXR_MotionTracking.StopBodyTracking();
        updateBT = false;
    }

    public void InitializeSkeletonJoints()
    {
        Queue<Transform> nodes = new Queue<Transform>();
        nodes.Enqueue(skeletonJoints);
        while (nodes.Count > 0)
        {
            Transform next = nodes.Dequeue();
            for (int i = 0; i < next.childCount; ++i)
            {
                nodes.Enqueue(next.GetChild(i));
            }

            ProcessJoint(next);
        }
    }

    void ProcessJoint(Transform joint)
    {
        int index = GetJointIndex(joint.name);
        if (index >= 0 && index < (int)BodyTrackerRole.ROLE_NUM)
        {
            boneMapping[index] = joint;
            Transform cubeT = joint.Find("Cube");
            if (cubeT)
            {
                cubeT.gameObject.SetActive(showCube);
            }
        }
        else
        {
            Debug.LogWarning($$"{joint.name} was not found.");
        }
    }

    // 返回与作为字符串传入的 JointIndices 枚举值对应的整数值。
    int GetJointIndex(string jointName)
    {
        BodyTrackerRole val;
        if (Enum.TryParse(jointName, out val))
        {
            return (int)val;
        }
        return -1;
    }
}

int ret = PXR_MotionTracking.StopBodyTracking();



概念

说明

坐标系

均为和头戴设备数据相同的世界坐标系。

根关节节点

0 (Pelvis)

父/子关节节点

1 至 23 号节点，靠近根关节节点的为父节点，靠近肢体端的为子节点。

骨骼

位于两个节点之间的一段刚体，其姿态存储在靠近根节点一侧的父节点结构内。比如：小腿骨骼的姿态角度，会存储在关节点 Knee 结构中。
更多例子 : 
*4 号节点 (LEFT_KNEE)：存放了左膝盖关节的位置信息，以及左小腿骨骼的姿态。
*7 号节点 (LEFT_ANKLE)：存放了左脚踝关节的位置信息，以及左脚面骨骼的姿态。

public enum BodyTrackerRole
    {
        Pelvis = 0,  // 骨盆
        LEFT_HIP = 1,  // 左侧臀部
        RIGHT_HIP = 2,  // 右侧臀部
        SPINE1 = 3,  // 脊柱
        LEFT_KNEE = 4,  // 左腿膝盖
        RIGHT_KNEE = 5,  // 右腿膝盖
        SPINE2 = 6,  // 脊柱
        LEFT_ANKLE = 7,  // 左脚踝
        RIGHT_ANKLE = 8,  // 右脚踝
        SPINE3 = 9,  // 脊柱
        LEFT_FOOT = 10,  // 左脚
        RIGHT_FOOT = 11,  // 右脚
        NECK = 12,  // 颈部
        LEFT_COLLAR = 13,  // 左侧锁骨
        RIGHT_COLLAR = 14,  // 右侧锁骨
        HEAD = 15,  // 头部
        LEFT_SHOULDER = 16,  // 左肩膀
        RIGHT_SHOULDER = 17,  // 右肩膀
        LEFT_ELBOW = 18,  // 左手肘
        RIGHT_ELBOW = 19,  // 右手肘
        LEFT_WRIST = 20,  // 左手腕
        RIGHT_WRIST = 21,  // 右手腕
        LEFT_HAND = 22,  // 左手
        RIGHT_HAND = 23  // 右手
    }
