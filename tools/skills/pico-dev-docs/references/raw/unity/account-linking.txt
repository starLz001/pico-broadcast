账号关联
========================================
通过账号关联服务，你可以将用户的 PICO 账号与自己的自有账号体系关联起来，获取用户 PICO 账号的昵称、用户 ID、头像等信息，从而允许用户使用 PICO 账号登录你的应用。

*名称

*说明

SSO

单点登录（Single Sign On），是一种身份验证解决方案，允许用户使用一个唯一的凭证（如用户名和密码）登录到多个应用中，而不需要在每个应用中都输入一遍凭证。

SSO 重定向域名

你自己的登录服务。

Access Token

访问令牌，有效期为 15 天，用于获取 PICO 账号的信息。

Refresh Token

刷新令牌，有效期为 30 天，用于更新过期的 Access Token。

*仅支持 https:// 开头的域名。
*域名不得超过 500 个字符。
*输入完整 URL 时，仅保留域名部分。

https://platform-cn.picovr.com
https://platform-cn.picovr.com/open/v1/authorize/login

https://$pico_auth_domain/oauth/authorize?client_key=$app_id&redirect_uri=$developer_code_receive_url



参数名

说明

pico_auth_domain

PICO 提供的三方授权页面对应的域名：
*中国大陆：openid.picovr.com
*非中国大陆：open-global.picoxr.com

client_key

应用的 ID（App ID），在 PICO 开发者平台上查看。详细说明参考此文档。

redirect_uri

PICO 账号授权登录成功后，需要跳转到你自己的登录服务，跳转时会带上 PICO 账号的授权码。该地址必须支持 https，且域名必须与你在 PICO 开发者平台上配置的 SSO 重定向域名一致。

https://openid.picovr.com/oauth/authorize?client_key=xxxxf0c4aafa504fc1ae8386113c8421&redirect_uri=https://platform-cn.picovr.com/open/v1/authorize/login

https://platform-cn.picovr.com/open/v1/authorize/login?code=xxxx4530340d3292bccctu0Mu5NGYWmXcyux&scopes=user_info





格式

说明

接口地址

https://$pico_auth_domain/passport/open/access_token/


PICO 提供的三方授权页面对应的域名：
*中国大陆：openid.picovr.com
*非中国大陆：open-global.picoxr.com

方法

POST

-

Content-Type

application/x-www-form-urlencoded

-

Body


client_key=$app_id&client_secret=$app_secret&code=$code&grant_type=authorization_code

*client_key：应用的 ID（App ID），在 PICO 开发者平台上查看。
*client_secret：应用的密钥（App Secret），在 PICO 开发者平台上查看。
*code：授权码，从第三步中获取。
提示：关于如何查看应用的 ID 和密钥，参考此文档。

curl -X POST "https://openid.picovr.com/passport/open/access_token/" -H "Content-Type: application/x-www-form-urlencoded; charset=UTF-8" -d "client_key=xxxxf0c4aafa504fc1ae8386113c8421&client_secret=ec850766400cc0a383332f85faac01d4&code=xxxx4530340d3292bccctu0Mu5NGYWmXcyux&grant_type=authorization_code" -v
