MR 功能兼容性和迁移说明
========================================
本文为 MR 功能兼容性和迁移说明。你可以参考本文档将项目中 2.5.0 及更早版本的 MR 接口升级为 3.0.0 版本。
*相关提示
由于 SDK 3.0.0 版本中的 MR 功能重构不涉及视频透视，所以本文不讨论视频透视功能的兼容性。
