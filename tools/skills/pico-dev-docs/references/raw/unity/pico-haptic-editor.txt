PICO 触觉编辑器
========================================
PICO 触觉编辑器（PICO Haptic Editor）支持编辑宽频、多通道的触觉反馈。你可以通过导入 PHF 文件（.phf）、音频文件（.wav）、视频文件（.mp4），或使用 PICO 提供的素材库来快速编辑触觉反馈，然后在 PICO 设备上体验效果。编辑完成后，你可以导出文件，然后将文件内的触觉反馈设置应用于不同的 PICO 设备。
*准备工作
下载并安装 PICO Developer Center 至本地电脑。PDC 工具安装包需以管理员身份运行，安装时会弹出授权窗口，需授予权限。
*安装 PICO 触觉编辑器
*启动 PICO Developer Center。
*前往 下载中心 > 工具包。
*找到 PICO 触觉编辑器，然后点击 下载 按钮。
* 
*下载完成后，你可以在 已安装 标签页中找到 PICO 触觉编辑器。
* 
*编辑触觉反馈
*前往 已安装 标签页，然后点击 启动 按钮，启动 PICO 触觉编辑器。
*PICO 触觉编辑器界面如下：
* 
*添加轨道。从以下方式中选择：
**
* 
*设置触觉反馈应用的手柄类型。选项有：Left（左手柄）、Right（右手柄）、Both（双手柄）。
* 
*编辑振动强度（Intensity）和振动频率（Frequency）节点。
*振动强度的取值范围为 0 到 1
*振动频率的取值范围为 50 到 500 Hz
*从以下方式中选择：
**
*(可选) 移动时长控制条，增加/减少轨道的时长。
*增加时长会新增节点
*减少时长会减少节点（默认至少保留四个节点）
* 
*(可选) 按需进行下表所述操作。
**
* 
*(可选) 在顶部菜单栏处，点击 File > Export to PHF File，将当前触觉反馈设置导出为 .phf 文件。
*关于 .phf 文件
PHF 流式振动具有较高的灵活性，相关设置存储在 .phf 格式的文件中。更多信息参考《触觉反馈》指南。

操作说明

1

点击 + Add a new track，添加一条轨道。

2

导入并使用你自己的资产文件。
*在顶部菜单栏处，点击 File > Add Asset File。
*导入资产文件。
*提示：目前仅支持导入 .phf、.wav 和 .mp4 文件。
*导入后的文件将展示在 Asset 区域。
*将资产文件从 Asset 区域拖至轨道区域。

3

将 Library 库中的资产文件拖至轨道区域。
* 

若拖入轨道的是 .mp4 文件，你可以点击顶部的播放按钮，然后在 Preview 区域预览该视频。
