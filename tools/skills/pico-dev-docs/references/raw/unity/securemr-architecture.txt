架构
========================================
SecureMR 的核心是一个独立、安全的运行时服务，它允许开发者部署需要访问 RGB 和深度数据的定制 MR 算法。该服务还支持将 3D 混合现实内容直接渲染到屏幕上。客户端应用程序与 SecureMR 服务之间的通信是严格单向的：开发者可以传入数据、3D 资产、算法和执行命令，但不会有任何敏感输出内容（如摄像头帧或深度图）返回给应用程序。该设计通过防止访问可能敏感的传感器数据，有力地保障了用户隐私。
* 
*在该架构下，应用程序永远无法直接访问摄像头或传感器数据。相反，独立的 SecureMR 服务充当代理，代表应用程序执行定制算法和渲染命令，并将最终的混合现实输出内容直接呈现给用户。
*一旦启动，SecureMR 服务还将维持一个覆盖式 OpenXR 会话，该会话与客户端应用程序的 XR 会话相关联。应用程序可以渲染其非 MR 内容，如用户界面或静态资产，而 SecureMR 服务将执行应用程序提交的 pipeline，并将 pipeline 结果渲染在应用程序图层下方的独立图层上。
