半透明物体处理建议
========================================
本文就混合现实场景下的半透明物体处理提供相关参考思路。
*多层半透明物体无法正确渲染
目前不支持正确渲染多层半透明物体，建议尽量少用或不使用半透明物体。
*半透明物体与非半透明物体交叉在一起
半透明物体与非半透明物体交叉在一起时，需要手动设置物体的 Render Queue。
以下图为例，红色和黄色区域内的半透明方块物体中透出了墙面和天空盒。对于红色区域来说，原因是墙面与半透明方块物体的 Render Queue 数值相同，所以引擎先绘制半透明方块物体，再绘制墙面，导致半透明方块物体中透出了天空盒。黄色区域的情况类似，淡绿色透明圆柱体比半透明方块物体先绘制，导致半透明方块物体中透出了墙面和天空盒。
* 
解决方法如下：
*将墙壁的绘制方式设置成正确的 Opaque 绘制方式，将其的 Render Queue 调整为半透明物体队列。
*调整后，红色区域内的半透明方块物体中不透出天空盒。
* 
*增大黄色方块区域内半透明方块物体的 Render Queue 值，将它的渲染顺序往后调。
*区域内各物体的最终 Render Queue 值如下：
*墙面：1000
*绿色半透明圆柱体：3000
*半透明方块物体：4000

*启用 PremultipliedAlpha
为确保半透明物体在不同厂商的设备上的渲染效果一致，可以使用以下代码来启用 PremultipliedAlpha。启用 PremultipliedAlpha 后，RGB 通道将乘以 Alpha 值（R×A，G×A，B×A），从而提升半透明元素（例如 UI、粒子）的性能和视觉质量。
