相机图像数据（用户设备）
========================================
本文介绍如何在 PICO XR 设备上使用 PXR_CameraImage 类提供的接口来管理相机图像数据。
*关于 PXR_CameraImage 
*PXR_CameraImage 是一个静态工具类，封装了 PICO XR 设备相机相关能力，主要包括：
* 枚举设备上可用的相机
* 查询相机属性与能力（分辨率、格式、帧率、模型等）
* 创建和管理相机设备与捕获会话
* 获取相机内参与外参
* 实时获取并释放相机图像数据
PXR_CameraImage 底层基于 OpenXR 扩展 XR_PICO_camera_image，并依赖 XR_EXT_future 提供的异步能力。
*环境要求
*设备型号：PICO 4 Ultra、Project Swan
*设备系统版本：
*PICO 4 Ultra：5.15.0 及以上
*Project Swan：PICO OS 6
*权限声明
在 AndroidManifest.xml 中声明相机权限。
 
*整体使用流程
*申请相机权限。
*调用 GetAvailableCameras 获取可用相机。
*查询相机能力（分辨率、格式等）。
*调用 CreateCameraDeviceAsync 创建相机设备。
*调用 CreateCameraCaptureSessionAsync 创建捕获会话。
*调用 BeginCameraCapture 开始捕获图像。
*在循环中使用 AcquireCameraImage 获取图像。
*处理所获取的图像。
*调用 ReleaseCameraImage 释放图像资源。
*调用 EndCameraCapture 结束捕获。
*调用 DestroyCameraCaptureSession 和 DestroyCameraDevice 清理资源。

private IEnumerator ProcessCameraImageAsync()
{
    // 获取相机图像
    ulong imageId;
    PxrResult acquireResult = PXR_CameraImage.AcquireCameraImage(targetCamera, lastCaptureTime, out imageId,out Int64 captureTime);
    
    if (acquireResult == PxrResult.SUCCESS && imageId > 0)
    {
        // 获取图像的原始数据
        XrCameraImageDataRawBuffer imageData;
        if (PXR_CameraImage.GetCameraImageData(targetCamera, imageId, out imageData) == PxrResult.SUCCESS)
        {
            // 将原始图像数据渲染到 Texture2D 
          
        }
        
        // 释放图像资源
        PXR_CameraImage.ReleaseCameraImage(targetCamera, imageId);
    }
    else if (acquireResult != PxrResult.SUCCESS)
    {
        UpdateStatus($$"获取图像失败: {acquireResult}");
    }
    
    yield return null;
}
