入门示例
========================================
GetStartedDemo 包含室内（Indoor）和室外（Outdoor）两个场景。你可以在 Demo 中体验视角转动、连续运动、传送和场景切换功能。
**
*预览视频
 
*开发环境
*SDK 版本：2.3.0
*PICO 设备系统版本：5.7.0
*Unity 编辑器版本：2020.3.48
*图形接口：OpenGLES3
*应用架构：64 位
*APK 安装包
你可以直接将 Demo 的 APK 文件安装到设备上进行体验。
 
*GitHub 仓库
*前往 PICO Developer GitHub 下载 Demo 工程。
*体验步骤
*视角转动：左右推动左右手柄的摇杆
*连续运动：上下推动左右手柄的摇杆
*传送：瞄准目标位置，按下左手柄的抓握（Grip）键
*场景切换：按下左手柄的 Y 键
