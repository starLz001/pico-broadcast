安装串流服务
========================================
通过串流服务，你可以监控 PICO 设备的性能数据。若你使用的是 Windows 操作系统，还可以搭配 PICO Unity Live Preview Plugin 来实时预览 Unity 项目。
安装串流服务的步骤如下：
*使用 USB 数据线连接 PC 和 PICO 设备。
*打开 PDC 工具。
*从左侧导航栏中，选择 下载中心。
*在 工具包 页面，根据设备型号选择对应版本的串流服务：
*Project Swan 设备：选择 串流服务 for Swan。
*其他设备型号：选择 串流服务。
* 
*点击 下载 按钮。
*下载完成后，根据页面提示完成安装流程。
