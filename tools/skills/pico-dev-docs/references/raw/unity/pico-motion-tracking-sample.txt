运动追踪示例
========================================
PICOMotionTrackerSample 是展示使用 PICO 体感追踪器 进行全身动捕和独立追踪功能开发的技术示例。你可以在 PICO 设备上连接 PICO 体感追踪器并运行该示例，然后体验全身动捕和独立追踪功能的一些简单应用场景。为了提供更丰富的体验，此示例使用了 PICO Unity Avatar SDK 中的部分功能。
*开发环境
*PICO Unity Integration SDK 版本：3.0.0
*PICO Unity Avatar SDK 版本: 2.0.0
*PICO 设备型号：PICO Neo 3 系列、PICO 4 系列、PICO 4 Ultra 系列
*PICO 设备系统版本：5.11.0
*PICO 体感追踪器（正式版）
*工程配置
*
*APK 文件
以下为示例的 APK 文件，你可以直接将其安装至 PICO 设备进行体验。
* 
 
*GitHub 仓库
你可以前往 PICO 开发者 GitHub 上的 GitHub - Pico-Developer/PICOMotionTrackerSample-Unity 仓库，克隆示例项目。该项目包括源代码脚本、艺术资产和其他资源。
*体验流程
*使用 USB 数据线连接电脑和 PICO 设备。
*安装示例的 APK 文件至你的 PICO 设备。你可以使用以下 ADB 命令进行安装：
* 
*启动示例。 
*选择要体验的运动追踪模式：全身追踪或独立追踪。
* 
*如果选择的追踪模式和当前场景不同，将弹出模式转换弹窗，在弹窗中确认是否需要切换追踪模式并校准。
* 
*全身动捕场景
*平台服务配置 
体验全身动捕场景前，需要先为应用开启 Avatar 服务、运动数据服务，并完成 PC 调试配置。
*登录 PICO 开发者平台。 
*在 我的应用 页面上创建应用。 
*进入该应用的 概览 页。 
*在左侧导航栏中，分别选择 平台服务 > Avatar 和 平台服务 > 运动数据，然后点击 启用服务 按钮。
*在左侧导航栏中，点击 平台服务 > API 测试，进入 API 页面。 
*在 授权管理 部分，选择所有选项，点击 获取 Access Token 按钮，然后在弹窗中复制获取到的 Access Token。 
*在 Unity 编辑器中打开你的项目。 
*在顶部菜单栏中，点击 PXR_SDK > PC Debug Settings，前往 Inspector 窗口，根据你所在的区域配置 Region 参数，然后在 Access Token 参数处添加先前获取到的 Access Token。 
*点击 PXR_SDK > Platform Settings，然后在 PICO Platform Settings 窗口中输入应用的 ID。
*全身动捕配置
*首先，选择全身动捕的精度模式。
* 
**
*然后，点击 立即校准。
*如果先前未启动或者绑定过 PICO 体感追踪器，将进入绑定确认界面。
* 
*如果 PICO 体感追踪器正常启动，将进入追踪校准流程。
* 
后续依旧可以在 PICO运动追踪器 面板中动态修改追踪模式并再次校准。
* 
追踪状态 面板中罗列了追踪器型号、当前连接的追踪器数量、当前的校准状态。你可以根据需求在开发的程序中对这些数据进行检查，以便在由于长时间的遮挡或者强干扰的状态导致校准失效时，提供重新校准的提示。
*Avatar 功能配置
校准后进入应用，可以在应用内看到一个镜子，以及代表你自己的 Avatar。在这个场景中，你可以四处走动并且尝试活动身体，观察 Avatar 是否可以正确的映射自己的身体动作。
* 
*模型切换
本示例提供了几种 Avatar 形象供选择体验，可在 PICO运动追踪器 面板的 形象 列表中选择。
* 
*地面对齐
如果 Avatar 在场景中悬空或者嵌入地面，可点击 显示设置 面板中的 地面对齐 按钮。
* 
*视角设置
在 显示设置 面板的 镜子 列表处，可以选择 Avatar 的显示方式，包含正面、背面、是否跟随等。
* 
*关节显示
在 调试菜单 面板中勾选 显示形象关节 选框后，自身的 Avatar 形象会变成由 24 关节点构成的小人。这些节点位置信息通过 PICO Unity Avatar SDK 获取。
*绿点代表头戴和两个手柄的位置。可以观察到在手柄进入盲区并停止更新位置后，动捕数据点位中的上肢点仍然可以通过 IMU 数据进行预测。
* 
*视频透视模式
*勾选 VST 模式设置 面板中的 开启VST模式 选框后，可以开启视频透视，从而看到真实环境下的 Avatar 模型。
* 
*视频录制
点击 2D 视频录制 面板中的 开始 按钮开始视频录制，点击 结束 按钮结束录制。录制完成后，你可以在 PICO 设备的文件管理中心查看录制的视频；也可以使用 USB 数据线连接头戴和电脑，然后在 Movies 目录中查看。
* 
*踩踏小游戏
点击 踩踏游戏 面板上的 开始 按钮体验踩踏游戏。踩中地鼠出现的格子后，将获得分数。
* 
*在 显示设置 面板的 踩踏特效 列表中，你可以选择踩踏特效的触发方式。
* 
*其他设置
*在 调试菜单 面板中，你可以通过 升高相机 和 降低相机 按钮来微调摄像机的高度。
* 
*在 显示设置 面板的 环境 列表中，你可以切换场景。
* 
*在 显示设置 面板的 射线交互 字段处，你可以进行射线交互相关设置。
* 
*独立追踪场景
*初始设置
*在 VST模式设置 面板中，勾选 开启VST模式 选框，开启视频透视，场景内将显示 PICO 体感追踪器在真实环境中的位置。
* 
*勾选 显示Tracker名字 选框后，将显示 PICO 体感追踪器的名字，用于辅助确定你想要绑定的追踪器。
* 
*你也可以尝试短按追踪器按键，场景中对应的追踪器模型将播放光效辅助你确定对应关系。
* 
*PICO 体感追踪器模型状态说明
*
*PICO 体感追踪器模型替换
在已连接的追踪器的信息面板中，你可以选择将默认的模型替换成一系列预设的物品模型，如球拍、饮料罐、枪等。
* 
*PICO 体感追踪器位置标定
*通过 手动标定 按钮，你可以调整模型物体与体感追踪器的相对位置以及旋转的偏移量，以实现更贴近现实的抓握交互方式。假如你在现实中将追踪器固定在某个物体表面，通过调整可以使虚拟场景中的物体模型与真实物体匹配。
