运动数据授权
========================================
“PICO 运动”是 PICO 系统的预装应用，用来采集用户使用 PICO 设备时所产生的运动数据，包括运动时长、运动消耗、应用偏好等。此外，用户可通过 “PICO 运动” 来制定和管理运动计划。
运动数据授权服务提供了从 “PICO 运动” 获取用户运动数据的接口。PICO 系统上的运动类应用可以通过数据来分析用户的运动情况，从而为用户提供更好的定制化体验。
* 
*基本概念
*
*功能说明
调用运动数据授权服务相关接口时，需要获取用户授权。若未取得授权，调用接口时会弹窗提示用户进行授权。你可以调用 UserService.RequestUserPermissions 来向用户申请访问其运动中心数据的权限，也可以调用 UserService.GetAuthorizedPermissions 来查看已获得的权限列表。
*获取基础信息和运动计划
调用 SportService.GetUserInfo() 来获取用户的基础信息和运动计划信息，包括：性别、年龄、身高、体重、运动级别、计划每日运动时长、计划每周运动天数、运动目标。
*获取今日运动数据
调用 SportService.GetSummary 获取 最近 24 小时内 任意时间段（查询的起始时间距离当前时间不得超过 24 小时）产生的运动数据，包括实际运动时长和实际消耗卡路里。
*获取每日运动数据
调用 SportService.GetDailySummary 来查询用户 最近 90 天内 任意时期（查询起始时间不得早于 90 天前）产生的每日运动数据，包括实际运动时间、计划运动时间、计划卡路里消耗量和实际卡路里消耗量。
*功能接入流程
*完成基础配置
参考《平台服务概览》文档，完成基础配置，包括添加应用 ID、初始化平台服务等。
*申请权限
运动数据授权服务目前处于实验性阶段。若你想使用该服务，需向 PICO 团队提交应用 ID 进行权限开通。开通权限后，方可使用。
*调用接口
调用接口，为应用添加“应用数据授权”相关功能。
*Demo
你可以使用 SportCenter Demo 来调试运动数据授权接口。关于 Demo 的具体使用说明，参考《运动数据授权示例》文档。

概念
说明
运动中心
PICO 系统的内置应用，帮助用户管理运动计划。
运动计划
用户在运动中心设置的运动计划，包括运动时长、卡路里目标、每周运动天数等。
运动级别
用户的运动强度偏好，分为“低”、“中”、“高”三个级别。
运动目标
用户想要达到的运动目的，目前有“减脂”和“保持健康”两个选项。
