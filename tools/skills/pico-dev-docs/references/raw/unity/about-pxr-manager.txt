功能

简述

Home 键校准

长按 Home 键进行校准。

*场景渐变

*勾选 Open Screen Fade 选项后，PXR Manager 会将 PXR_ScreenFade 脚本添加至 GameObject，帮助实现场景切换时的淡入淡出效果。

眼动追踪注视点渲染

眼动追踪注视点渲染（Eye Tracked Foveated Rendering，ETFR）根据眼球的注视方向，以全分辨率渲染眼球注视区域的图像，以更低分辨率渲染边缘区域图像。

静态注视点渲染

*在静态注视点渲染（Fixed Foveated Rendering）中，视野焦点被固定于视口中心位置，分辨率由中心向周围递减。

眼动追踪

眼动追踪（Eye Tracking）将用户的眼部移动转换为数据输入。

面部追踪

面部追踪（Face Tracking）可以将用户的面部表情转换为数据输入。

手势追踪

手势追踪（Hand Tracking）可将用户的手部动作转换为数据输入。

身体追踪

*身体追踪（Body Tracking）用于收集用户的身体位置和动作信息，并将其转换为可再现的姿态数据。

内容保护

勾选 Use Content Protect 选项后，若用户在应用内截屏或录屏，相关画面将呈现黑色。

混合现实捕捉

勾选 MRC 选项，实现现实世界与虚拟场景的融合，用于 MRC 视频录制。

延迟锁定

延迟锁定（Late Latching）可消除 1 帧的头戴和手柄动作延迟。

抗锯齿

勾选 Use Recommended MSAA 选项后，将为场景开启默认抗锯齿倍数（4xMSAA）。

自适应分辨率

自适应分辨率（Adaptive Resolution）可以根据设备的 GPU 负载自动调节渲染分辨率，以保证应用始终在稳定的帧率下运行。

视频透视

开启视频透视，可以将现实世界作为背景实时显示在 PICO 头显屏幕上。

空间锚点

空间锚点技术可以将虚拟环境中的位置与真实世界中的位置进行锚定，用于将虚拟对象锚定到现实世界的位置或物体上。
