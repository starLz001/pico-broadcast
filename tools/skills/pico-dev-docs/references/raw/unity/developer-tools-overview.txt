开发者工具概览
========================================
PICO 提供或支持以下开发者工具，涵盖应用调试、性能监测、交互体验编辑等。
*



工具

说明

*PICO 开发者中心

集成各类型 PICO 应用开发工具或组件的 PC 客户端工具平台。详见 PICO 开发者中心（PDC 工具）。
提示：目前，PICO Unity OpenXR SDK 暂不支持 PDC 工具提供的实时预览功能（即 PICO Unity Live Preview Plugin）。

PICO 模拟器 (Beta)

你可以在 PICO 模拟器中安装应用并运行，然后预览应用的实际效果。详见 PICO 模拟器 (Beta)。

头戴端性能监测工具 (Metrics HUD)

用于实时追踪运行中应用的性能数据。详见头戴端性能监测工具 (Metrics HUD)。

RenderDoc for PICO

用于图像分析和调试。详见 RenderDoc for PICO。

CLI 命令行工具

用于管理 PICO 开发者平台的文件。详见 CLI 命令行工具。

PICO 触觉编辑器

支持编辑宽频、多通道的触觉反馈。详见 PICO 触觉编辑器。

PICO 图像分析和调试工具

 用于对应用的性能进行分析和调试。详见 PICO 图像分析和调试工具。

骁龙分析器

*用于分析 CPU、GPU、DSP、内存、功耗、散热和网络数据，从而发现并修复性能瓶颈。详见骁龙分析器。
