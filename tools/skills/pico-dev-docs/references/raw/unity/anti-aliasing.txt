抗锯齿
========================================
低分辨率场景下，物体边缘容易呈现锯齿状，影响场景视觉效果和用户体验。你可以使用多重采样抗锯齿（Multisampling Anti-Aliasing，MSAA）功能对多边形物体的边缘进行抗锯齿处理，即：对有锯齿边缘的画面进行采样，然后将其和周围像素的颜色进行混合，让画面过渡得更加自然，从而大大减轻锯齿效果。抗锯齿倍数越高，画面质量越好，性能消耗越大。
*效果展示
从左至右依次为：原图、2 倍抗锯齿、4 倍抗锯齿、8 倍抗锯齿。
 
 
*使用推荐抗锯齿倍数
SDK 提供的默认抗锯齿倍数为 “4 倍 MSAA”。建议使用默认抗锯齿倍数，这样能在性能开销不是很大的情况下获得比较清晰的视觉效果。
*在 Unity 编辑器中打开项目。
*在 Hierarchy 窗口中，点击 + > XR > XR Origin (VR)。
*选中 XR Origin。
*Inspector 窗口中将展示 XR Origin 挂载的脚本和组件。
*点击 Inspector 窗口底部的 Add Component。
*搜索 PXR_Manager 脚本，然后双击添加。
*PXR_Manager 脚本面板如下：
* 
*勾选 Use Recommended MSAA。一般已默认勾选。
*使用其他抗锯齿倍数
若不想在场景中使用推荐抗锯齿倍数，可设置其他倍数。
*在 PXR_Manager 面板处，取消勾选 Use Recommended MSAA。
*在上方菜单栏处，选择 Edit > Project Settings。
*你将看到 Project Settings 窗口。
*从左侧导航栏处，选择 Quality。
*在 Rendering 下，设置 Anti Aliasing （抗锯齿倍数）。
