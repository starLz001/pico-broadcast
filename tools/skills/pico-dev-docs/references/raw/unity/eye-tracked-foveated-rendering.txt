眼动追踪注视点渲染
========================================
眼动追踪注视点渲染（Eye Tracked Foveated Rendering，ETFR）根据眼球的注视方向，以全分辨率渲染眼球注视区域的图像，以更低分辨率渲染边缘区域图像。随着眼球的移动，全分辨率渲染区域也会相应地变化。使用 ETFR 可降低应用运行时设备的 GPU 负载。
* 
*环境要求
*PICO 设备型号：仅支持搭载眼动追踪摄像头的 PICO 设备，包括 PICO Neo3 Pro Eye、PICO 4 Pro 和 PICO 4 Enterprise
*PICO 设备系统版本：5.7.0 及以上
*分辨率示意图
SDK 提供四种 ETFR 等级：低级、中级、高级、超高级。其中，高级和超高级效果一致。以下为各个 ETFR 等级的分辨率分布示意图。
* 
*ETFR vs FFR
与静态注视点渲染（FFR）相比，ETFR 可以追踪用户当前真实的注视点位置，在眼球周围区域分辨率的降低上可以比 FFR 的浮动更大。FFR 由于无法捕捉到用户的注视点位置，只能假设用户大概率注视着屏幕中央，在分辨率的降低方面比 ETFR 更加保守。因此，使用 ETFR 可以为应用降低更多的 GPU 消耗。
* 
以下为开启 Top High 等级（超高级）的 ETFR 与 FFR 后的性能数据对比。数据来源于 PICO 内部测试，实际使用中可能存在误差。
*
*使用限制
眼动追踪注视点渲染与静态注视点渲染互斥。因此，你只能为应用开启其中一个模式。
*开启眼动追踪注视点渲染
*为场景添加 XR Origin。
*为 XR Origin 添加 PXR_Manager 脚本。
*在 PXR_Manager (Script) 面板处，完成以下操作：
*将 Foveated Rendering Mode (注视点渲染模式) 设置为 Eye Tracking Foveation Rendering。
*设置 Foveated Rendering Level (注视点渲染等级)。
*    若选择 Low、Med、High 或 Top High，面板上会显示 Subsampling 选框。
**
*(可选) 勾选 Subsampling 选框，开启下采样。
* 
* 
*切换注视点渲染等级
调用 SetFoveationLevel，动态切换注视点渲染等级。
 
*切换注视点渲染模式
从 ETFR 切换到 FFR：
*调用 SetFoveationLevel，将 FoveationLevel 参数设置为 None，以关闭应用当前的注视点渲染模式和等级。
*再次调用 SetFoveationLevel，将 isETFR 参数设置为 false，在 FoveationLevel 参数中指定 FFR 等级。
 
从 FFR 切换到 ETFR：
*调用 SetFoveationLevel，将 FoveationLevel 参数设置为 None，以关闭应用当前的注视点渲染模式和等级。
*再次调用 SetFoveationLevel，将 isETFR 参数设置为 true，在 FoveationLevel 参数中指定 ETFR 等级。
* 
 
*AndroidManifest 权限声明
启用 ETFR 后，SDK 会自动在 AndroidManifest.xml 文件中写入以下权限声明：
*<meta-data android:name="picovr.software.eye_tracking" android:value="1"/>
*<uses-permission android:name="com.picovr.permission.EYE_TRACKING" />
若非必要，请不要修改相关的权限声明内容。如果使用自定义 Manifest，请根据相应功能添加对应的权限声明。

说明

低级，外围视觉逼真度较高，应用性能较低。

High 

高级/超高级，外围视觉逼真度较低，应用性能较高。目前，High 与 Top High 级别的效果一致。

Top High



下采样（Subsampling）是一种渲染优化技术，需与注视点渲染配合使用。开启后，眼部纹理将采用下采样的布局方式，消除视野边缘低分辨率区域的视觉伪影，提高应用性能。用户在移动时，设备的画面过渡也将更平滑流畅，从而减少眩晕感。

// FFR 开启后，动态设置注视点渲染等级
PXR_FoveationRendering.SetFoveationLevel(FoveationLevel.High, false);

// ETFR 开启后，动态设置注视点渲染等级
PXR_FoveationRendering.SetFoveationLevel(FoveationLevel.High, true);

// 从 ETFR 切换到 FFR
PXR_FoveationRendering.SetFoveationLevel(FoveationLevel.None, true);
PXR_FoveationRendering.SetFoveationLevel(FoveationLevel.High, false);

第二次调用可能执行失败。若注视点渲染模式未成功切换，请尝试第三次调用 SetFoveationLevel，将 isETFR 参数设置为 true，在 FoveationLevel 参数中指定 ETFR 等级。

// 从 FFR 切换到 ETFR       
PXR_FoveationRendering.SetFoveationLevel(FoveationLevel.None, false);
PXR_FoveationRendering.SetFoveationLevel(FoveationLevel.High, true);

行号

说明

1

*bSupported 用于判断设备是否支持眼动追踪：true（支持）；false（不支持)
*level 为注视点渲染等级：-1（关闭）；0（Low）；1（Med）；2（High）；3（Top High）
*result 为接口调用结果：0 表示成功，其他值表示失败

2

*bEnable 用于判断 ETFR 是否开启：true（开启）；false（未开启）
*result 为接口调用结果：0 表示成功，其他值表示失败

3

*m_RecreatingEyeTextures 表示是否需要重新创建眼部纹理：true（需要）；false（不需要）
*result 为接口调用结果：0 表示成功，其他值表示失败
