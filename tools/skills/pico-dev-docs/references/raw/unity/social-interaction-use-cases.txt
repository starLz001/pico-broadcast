场景教学 & 代码示例
========================================
本文档具体介绍 “社交互动” 服务的使用场景并提供对应的代码示例。
*设置/更新/清空 Presence 信息
调用 PresenceService.Set 接口设置用户的所有 Presence 信息。调用时，需先创建 PresenceOptions，然后设置 Presence 信息，最后在请求成功之后打印当前用户的 Presence 信息。当玩家离开房间或退出应用时，需调用 PresenceService.Clear 接口及时清空相应玩家的 Presence 信息。
 
*查看好友的位置和 Presence 信息
用户可以查看好友的位置和 Presence 信息。
 
*邀请好友
“邀请好友” 和 “加入好友” 是多人社交互动中的成对行为，也是最基础和重要的社交互动体验。Destination、Deeplink 和 Presence 共同实现了应用内的 “邀请/加入好友” 能力。目前，PICO SDK 支持的邀请方式为好友间发送邀请消息卡片。邀请实现流程如下：
*用户 A 向好友 B 发送邀请。
*系统将用户 A 的 Presence 信息抽取出来然后存储在邀请消息中。
*好友 B 点击邀请信息，相关应用被启动。
*你需要将 Deeplink 里的信息抽取出来作为 Launch Details（例如 Destination、Lobby Session ID、Match Session ID 等信息），然后解析 Launch Details，将玩家 B 传送至目标位置。
* 
用户需要在邀请面板上向指定好友发送邀请。邀请面板中会展示用户的全部好友，用户可从中选择好友进行邀请。你可以直接复用 “好友” APP 的邀请面板（下图所示）和交互逻辑，该方式更加便捷。若不使用系统邀请面板，则需要自定义邀请流程，同时需自行设计并实现相关 UI 界面和交互逻辑。

*获取应用启动详情
*应用的启动方式包括冷启动（后台不存在该应用进程）和热启动（应用从后台切换至前台）。 你需要同时完成冷启动和热启动相关配置。
*应用 冷启动 时，可以直接调用 ApplicationService.GetLaunchDetails 接口获取启动参数。 
*应用 热启动 时，如果 LaunchDetails 发生变化，并触发 ApplicationService.SetLaunchIntentChangedCallback 设置的回调函数，则可在接收到此回调函数之后立即调用 ApplicationService.GetLaunchDetails。
 
*跳转至其他应用
PICO 系统支持应用间跳转，即在某个应用中启动并前往另一个应用。为实现该能力，你需要调用 ApplicationService.LaunchApp 或 ApplicationService.LaunchAppByAppId 接口，然后在 Options 参数中传入 SetDeeplinkMessage 函数对象。SetDeeplinkMessage 函数对象中自定义了具体的跳转规则。

public async Task LaunchToAppStoreIfOutdated()
{
    var appVersionMsg = await ApplicationService.GetVersion().Async();
    var appVersion = appVersionMsg.Data;
    var outdated = appVersion.CurrentCode < appVersion.LatestCode;
    if (outdated)
        ApplicationService.LaunchStore();
    else
        Debug.Log("App version is up to date");
}
