功能

备注

PresenceService.Set

设置用户的所有 Presence 信息，包括 Destination、可加入状态、Lobby Session ID、Match Session ID 和额外信息。

-

PresenceService.Clear

清空用户的 Presence 信息。

-

PresenceService.GetInvitableUsers

获取可邀请好友。

-

PresenceService.LaunchInvitePanel

邀请好友加入应用内的某个位置。

三个接口皆使用 “好友” APP 提供的系统默认邀请面板。

RoomService.LaunchInvitableUserFlow

邀请好友加入私人房间。



ChallengesService.LaunchInvitableUserFlow

邀请好友加入挑战。



PresenceService.SendInvites

邀请好友加入应用内的某个位置。

三个接口皆使用自定义邀请面板。

RoomService.InviteUser

邀请好友加入私人房间。



ChallengesService.Invite

邀请好友加入挑战。



PresenceService.GetSentInvites

获取已发送的邀请。

PresenceService.GetDestinations

PresenceService.GetNextDestinationListPage

接口

功能

ApplicationService.LaunchApp

跳转至目标应用。应用通过包名指定。

ApplicationService.LaunchAppByAppId

跳转至目标应用。应用通过 APP ID 指定。

ApplicationService.LaunchStore

跳转至应用在 PICO 商店的详情页。

ApplicationService.GetLaunchDetails

获取应用启动详情。

ApplicationService.SetLaunchIntentChangedCallback

回调函数，当 LaunchIntent 发生变化时，你将收到通知。
