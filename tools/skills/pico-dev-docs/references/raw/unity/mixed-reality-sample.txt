混合现实示例
========================================
PICO 混合现实示例是面向开发者提供的技术示例项目，展示了 PICO Unity Integration SDK 混合现实相关功能，包括视频透视、场景标定、空间网格、空间锚点和共享空间锚点。你可以在示例中体验装饰房间、墙面涂鸦、射击小游戏等混合现实功能的简单示例场景。此外，此示例提供了部分技术示例场景，你可以在 Unity 编辑器中通过模拟数据体验混合现实功能，或打包单独的场景进行体验。
*开发环境
*SDK 版本：3.0.0 及以上
*PICO 设备：PICO 4 系列和 PICO 4 Ultra
*PICO 设备系统版本：5.11 及以上

*PICO 网络服务配置
*体验共享空间锚点场景前，需要先配置 PICO 网络服务。步骤如下：
*登录 PICO 开发者平台。 
*在 我的应用 页面上创建应用。
*进入该应用的 概览 页。
*在左侧导航栏中，选择 平台服务 >  匹配服务 以前往 匹配服务 配置页面，然后为应用开启匹配服务并配置匹配池。详细说明参考《房间&匹配》文档。
*在左侧导航栏中，点击 平台服务 > API 测试，进入 API 页面。
*在 授权管理 部分，选择所有选项，点击 获取 Access Token 按钮，然后在弹窗中复制获取到的 Access Token。
*在 Unity 编辑器中打开你的项目。
*在顶部菜单栏中，点击 PXR_SDK > PC Debug Settings，前往 Inspector 窗口，根据你所在的区域配置 Region 参数，然后在 Access Token 参数处添加先前获取到的 Access Token。
*点击 PXR_SDK > Platform Settings，然后在 PICO Platform Settings 窗口中输入应用的 ID。
*打开示例中的 PXR_SharedAnchorManager.cs 脚本，将所创建的匹配池的 Key 和匹配用户数分别填入 poolKeyName 和 maxUsers 变量中。
* 
*打包示例项目并安装至你的 PICO 设备。
*在设备中运行示例，使用你的 PICO 账号进行登录，打开共享空间锚点场景，然后点击主菜单上的 Connect To Other Player 按钮来尝试匹配其他用户。

操作类型

步骤

演示模板

*点击 演示模板 按钮，你身前将生成一组演示用的多米诺骨牌和滑倒套组。

清除全部

*点击 清除全部 按钮后，将清除所有已经生成的小球、多米诺骨牌和滑道。

小球

*点击 小球 后将切换到小球预览状态，你可以尝试通过 Trigger 键放置重力小球，然后通过自建的滑道来撞击多米诺骨牌。

多米诺骨牌

*点击 多米诺骨牌 后将切换到多米诺骨牌预览状态，你可以尝试通过 Trigger 键在地面或者标定的桌椅上放置多米诺骨牌，然后配合滑道和小球来进行撞击实验。

滑道

*点击 滑道 后将切换到滑道预览状态，你可以尝试通过 Trigger 键在空间中的合适位置放置倾斜的滑道，然后使小球通过搭建的路径来成功撞击放置的多米诺骨牌。

若你使用的是 PICO 4 Ultra 设备，可以打开 使用网格扫描 选项来开启网格扫描能力。开启后，应用会扫描周围环境并实时生成网格数据。如要继续体验其他功能，请在使用后关闭 使用网格扫描 选项。

在该场景中，你可以在设备中开启空间网格功能，并尝试在空间中进行射击。

共享空间锚点（仅支持 PICO 4 Ultra 设备）

在该场景中，你可以创建空间锚点，并通过 PICO 网络服务将锚点信息共享给同一房间内的其他用户。
*主菜单选项如下：
*Connect To Other Player：当连接网络并成功登录时，进入匹配队列尝试与其他用户匹配进入房间，当匹配成功时会尝试进入同一个房间。使用此功能前需先配置 PICO 网络服务。
*Leave Room：离开房间。
*Create Anchor：创建锚点。
*Load Local Anchors：加载保存过的锚点。
*射线触碰到锚点时将出现如下选项：
*SaveToLocal：将创建的锚点数据保存到 PICO 设备的本地磁盘。下次启动应用时，可以使用 Load Local Anchors 选项加载保存过的锚点。
*Save&ShareToCloud：将创建的锚点数据保存到 PICO 设备的本地磁盘，并将该锚点信息同步给房间内的其他用户。
*Delete Anchor：从应用内存中删除锚点。
*DeleteFromLocal：删除锚点，并清除该锚点在 PICO 设备本地磁盘中的信息。
*AlignForCloud：以该锚点为基准进行空间对齐，主要在多个用户使用同一个共享空间锚点的情况下使用。对同一锚点进行校正将提高其他锚点在空间中的精度。
