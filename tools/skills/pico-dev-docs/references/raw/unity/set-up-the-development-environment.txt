2. 配置开发环境
========================================
*预计阅读和完成时间：5 分钟（不包括 Unity Hub 和 Unity 编辑器安装耗时）
*本文介绍如何配置 PICO 应用所需的开发环境，包括设备端设置和工具安装。正式开始前，先了解 PICO 应用开发的软件和硬件要求。
*第一步：为设备端开启 “开发者” 模式
开发 PICO XR 应用无需额外购买开发机，只需为市售 PICO VR 一体机开启 “开发者” 模式即可将设备转换为开发机使用。
* 
*第二步：登录你的 PICO 账号
*若你使用的是非中国大陆版本的 PICO 设备，你需要在头戴上登录你的 PICO 账号，以便后续在设备上运行 APK 文件。
*点击底部导航栏处的头像图标。
*根据界面提示输入 PICO 账号和密码，然后登录。
*第三步：安装 Unity 编辑器
*前往 Unity 下载页，下载 Unity Hub。
*打开 Unity Hub。
*从左侧导航栏处，选择 安装。
*在 安装 页上，点击 安装编辑器。
*选择目标编辑器版本，点击 安装。关于 PICO SDK 支持的 Unity 编辑器版本，可参考《硬件和软件要求》文档。
*在 添加模块 窗口处，勾选 Android SDK & NDK Tools 和 OpenJDK。
*务必勾选 Android Build Support 下的所有选项，该操作将帮你完成所有 Android 开发所需的环境配置。
* 
*点击 继续。
*阅读相关条款和条件，并勾选 我已阅读并同意上述条款和条件。
*点击 安装。
*安装完成后，前往 偏好设置 > 许可证，点击 添加，然后在 添加新许可证 窗口中激活许可证。
* 
*请勿关闭 Unity Hub，我们接下来将通过它创建项目。
*后续操作
*参考《导入 SDK》文档中的说明，在 Unity Hub 中创建项目，然后往项目中导入 SDK。
