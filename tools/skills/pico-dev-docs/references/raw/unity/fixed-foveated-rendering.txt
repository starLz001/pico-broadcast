静态注视点渲染
========================================
在人类的视觉系统中，人眼视力分为中心视力和周边视力两部分。中心视力提供精确和细节的视觉内容，周边视力提供广角视野范围的画面。两者的视敏度差别催生了 VR 领域常用的注视点渲染（Foveated Rendering）技术。
注视点渲染通过为视野中心提供无损分辨率，同时降低周边视野（人眼焦点区域之外）分辨率的方式来大幅降低计算复杂度，优化 VR 场景渲染效果。
在静态注视点渲染（Fixed Foveated Rendering）中，视野焦点被固定于视口中心位置，分辨率由中心向周围递减。
*关于下采样
自 2.1.5 版本起， SDK 支持下采样（Subsampling）功能。下采样是一种渲染优化技术，需与静态注视点渲染配合使用。开启后，眼部纹理将采用下采样的布局方式，消除 FFR 产生的视野边缘低分辨率区域的视觉伪影，提高应用性能。用户在移动时，设备的画面过渡也将更平滑流畅，从而减少眩晕感。

*设置注视点渲染等级
*在 Unity 编辑器创建或打开一个场景。 
*在 Hierarchy 窗口处，点击 + > XR > XR Origin (VR) ，为场景添加 XR Origin。
*选中 XR Origin。 
*Inspector 窗口展示 XR Origin 挂载的组件和脚本。 
*点击 Inspector 窗口底部的 Add Component 按钮，为 XR Origin 添加 PXR_Manager 脚本。
*在 PXR_Manager (Script) 面板处，完成以下操作：
*将 Foveated Rendering Mode (注视点渲染模式) 设置为 Fixed Foveated Rendering。
*设置 Foveated Rendering Level (注视点渲染等级)。
*None 表示关闭静态注视点渲染。若选择 Low、Med、High 或 Top High，面板上会显示 Subsampling 选框。
*(推荐) 勾选 Subsampling 选框，启用下采样。

*已知问题 
*若在项目内使用通用渲染管线（URP）并开启静态注视点渲染，会导致静态注视点渲染失效。
*原因一：静态注视点渲染能力目前与 Eye Buffer 绑定，由于 URP 引入了 Intermediate Texture，因此会使图像首先被渲染至 Intermediate Texture 上而非 Eye Buffer 上，从而导致静态注视点渲染失效。
*解决方法：禁用后处理（Post-Processing）、HDR 及会用到 Intermediate Texture 的 Renderer Feature。
*原因二：在 URP 10.10.1 版本中，相机的 Clear Flags 设置项行为发生改变，选择 Skybox 时会使 Color Attachment 的 Invalidate 设置丢失，导致静态注视点渲染失效。
* 
*解决方法：在 ScriptableRenderer 的 GetCameraClearFlag 方法中注释掉CameraClearFlags.Skybox 部分，使其也返回 ClearFlag.All，如下图所示。
* 
*若在项目内使用内置渲染管线（Built-in Render Pipeline），也需要禁用后处理，否则会导致静态注视点渲染失效。
*若在项目内同时使用 OpenGLES 图形接口、Gamma 颜色空间和静态注视点渲染，则暂时不支持开启下采样（Subsampling）。
