硬件和软件要求
========================================
本文档介绍 PICO 应用开发的硬件和软件要求。
*PICO 设备
*型号
*使用 PICO Neo3 系列、PICO 4 系列和 PICO 4 Ultra 系列设备。下表为 SDK 各功能的设备型号要求。√ 表示支持该设备型号，ⅹ 表示不支持。
**
*系统版本（OS）
*PICO 4 系列：5.13.0
*PICO 4 Ultra 系列：5.14.0 及以上
*计算机
*PICO Unity Integration SDK 支持 Windows 和 macOS 操作系统，详细系统要求见下表。
*
*Unity 编辑器
*PICO Unity Integration SDK 支持的最低 Unity 编辑器版本为 2021.3.26.，最高为 Unity 6.3。推荐使用 LTS 版本的编辑器。
*若想使用 Unity 2022 开发 PICO 应用，请确保使用的 SDK 为 2.1.5 或更高版本，且 PICO 设备的系统版本为 5.5.0 或更高版本。
*若想使用 Unity 2023 开发 PICO 应用，请确保使用的 SDK 为 3.0.0 或更高版本，且 PICO 设备的系统版本为 5.11.0 或更高版本。
*若想使用 Unity 6 开发 PICO 应用，请确保使用的 SDK 为 3.1.0 或更高版本，且 PICO 设备的系统版本为 5.12.0 或更高版本。
*已知问题
*对于 Unity 2022.1.14 及以上版本，若同时在项目中使用 URP、Linear 色彩空间、四倍抗锯齿和 OpenGL，会出现崩溃。该问题待 Unity 引擎解决。
*对于 Unity 2022，若同时使用 Vulkan 并勾选 Development Build 选项，在设备上运行该 APK 文件时会崩溃。

操作系统

系统要求

Windows

推荐使用 Windows10 操作系统作为 PICO XR 应用的开发环境。部分工具或功能（例如：PDC 工具）需在 Windows 10 上才能运行。PC 系统配置要求如下：
*CPU：Intel i5-4590 / AMD Ryzen 5 1500X 或更高
*显卡：NVIDIA GTX 1060 / AMD Radeon RX 480
*RAM：8GB 或更高
*端口：USB 3.0

macOS

*系统：macOS Sierra 10 以上
*CPU：Intel I5-4590 / Apple M1 或更高
*内存：8GB 或更高
