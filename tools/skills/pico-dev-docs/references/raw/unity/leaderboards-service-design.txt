功能设计
========================================
排行榜是应用内基础且重要的功能之一，可以从多维度展示玩家在应用中的排名，激发玩家间的趣味性竞争。本文为 “排行榜” 服务的功能设计说明文档，涉及排行榜标识、排行榜条目、排行榜超越通知等。
*排行榜标识
API Name 是排行榜的唯一标识，在创建排行榜时进行配置。在获取排行榜信息以及获取和更新排行榜条目时，你可以根据 API Name 指定目标排行榜。
*排行榜条目
每个用户在一个排行榜中仅拥有一个条目，条目与用户 ID 关联，默认保留和展示用户的最好成绩。你可以将排行榜服务与成就服务进行联动，当用户取得特定的成绩或者排名时，为其解锁相应的成就。
*排行榜超越通知
创建排行榜时，你可以选择是否为该排行榜开启好友超越通知。当用户的排名被好友超越时，该用户将在设备端的通知中心收到通知。点击通知区域后，系统将启动相关应用并将用户跳转至该应用。
*排行榜关联 Destination
创建排行榜时，你可以选择为该排行榜关联 Destination。关联后，用户可通过排行榜跳转至所关联的 Destination，你需要自行为排行榜 UI 设计跳转按钮。有关 Destination 的详细信息，参阅《社交互动 - 核心概念》文档。
