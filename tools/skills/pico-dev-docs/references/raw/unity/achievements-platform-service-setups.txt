实现流程
========================================
本文档介绍如何为你的应用接入成就服务。
*重要提示
*目前暂不支持在 Unity 编辑器中测试成就服务。
*前提条件
*已在项目中导入 PICO Unity Integration SDK 并完成项目配置。若未完成，参考以下文档完成该任务：
*导入 SDK
*完成项目配置
*接入流程
*第一步：创建成就
在 PICO 开发者平台上为应用创建一个或多个成就。
*登录 PICO 开发者平台。
*在 我的应用 页面上，点击目标应用卡片，进入其 概览 页。
*在左侧导航栏中，点击 平台服务。
*你将前往 PPS 开发平台。
*在左侧导航栏中，点击 成就。
*你将进入成就管理面板。
*点击 创建成就。
*你将进入成就配置面板。
* 
*选择成就所应用的地区。
*配置成就信息。
**
*(可选) 为成就的显示名称、简介和解锁后的简介添加多语言版本：
*点击 +添加语言，添加所需的语言。
*点击每个语言标签，输入成就信息。
*如果需要批量导入多语言版本信息，使用以下步骤：
*点击右上角的 下载CSV模板 按钮，下载表格模板。
*在模板中填入相应的多语言版本信息，然后删除表格内不需要的多语言行。
*点击 导入CSV 按钮，将填写好的表格上传至平台。
*点击页面底部的 保存 或 提交 按钮。
*若点击 保存 按钮，成就将进入 “草稿” 状态，你仍可以编辑成就信息；若点击 提交 按钮，成就将进入 “审核中” 状态，你无法编辑成就信息。
*(可选) 对于已发布的成就，按需进行以下操作：
*点击 归档，归档已发布成就。归档后，相关成就及用户的成就进度不会被删除，但接口会过滤掉已归档成就，使其对用户不可见。
*点击 激活，重新启用已归档成就。
*请勿关闭网页，接下来需要为应用启用匹配服务。
*第二步：初始化平台服务
*全局初始化平台服务。你可以调用 CoreService.Initialize() 接口同步初始化平台服务，或调用 CoreService.AsyncInitialize() 接口异步初始化平台服务。详细说明和代码示例参考《初始化》一文。
*第三步：实现成就服务
*调用接口，在应用内实现成就服务。
以下为 AchievementsService 类中封装的客户端接口。若想了解入参和返回值等详细说明，可阅读 客户端 API 参考。场景教学和代码示例参考此文档。
*
*以下为服务端接口，详细说明参阅服务端 API 参考。
*创建或更新成就
*获取成就基础信息
*写入用户的成就进度
*获取用户的成就进度
*删除用户的成就进度



字段

说明

显示名称

在应用内，向用户展示的成就名称。

简介

成就简介，可描述如何解锁该成就。

解锁后的简介（可选）

用户解锁该成就后，将看到该信息。

API Name

成就的唯一标识。在 PICO 开发者平台上为成就定义的 API Name 必须与在代码中引用的完全一致。

成就类型

包括简单、计数、完成率类成就。具体说明参考 “成就类型” 说明。

数据写入权限

选项如下：
*客户端可写入：默认选项，客户端应用和服务端都可以更新成就进度。
*仅服务端可写入：仅服务端可以更新成就进度。但可能仍需要从客户端应用处查询成就信息和进度。

是否隐藏

若该成就为隐藏成就，可以勾选该选项。勾选后，该成就的一切信息都对用户不可见，仅当用户解锁该成就后才会向其展示。

是否启用通知

勾选后，当用户解锁成就时，会在应用内收到一条 Toast 通知，同时也会在 “通知” 中心收到通知。

解锁后的图标（可选）

成就解锁后，用户在应用内看到的图标。

未解锁图标（可选）

成就未解锁时，用户在应用内看到的图标。例如，可以将解锁后的图标颜色修改为灰色或加上深色蒙板，作为未解锁图标。



接口

说明

AchievementsService.GetDefinitionsByName

获取指定成就的基础信息，包括成就类型、成就描述、是否解锁等。

AchievementsService.GetAllDefinitions

获取所有成就的基础信息。

AchievementsService.GetProgressByName

获取用户某个成就的解锁进度。

AchievementsService.GetAllProgress

获取用户所有成就的解锁进度。

AchievementsService.AddCount

为成就增加计数。仅计数类成就可调用。

AchievementsService.AddFields

为成就完成某项任务，该任务的状态将不可变更。仅完成率类成就可调用。

AchievementsService.Unlock

解锁一项任意类型的成就。
