太空竞技场
========================================
Space Arena Party 是一个多人社交游戏 Demo，集成了 PICO 平台服务中的 “好友” 服务、“社交互动” 服务以及 “房间&匹配” 服务。你可以在 Demo 中体验以下能力：
*Avatar 和角色移动
*创建和加入虚拟房间
*实时多人互动
*好友系统，包括查看好友列表、邀请好友
*视频展示
以下为 Demo 展示视频。你可以通过视频浏览 Demo 场景并了解 Demo 的主要功能。

*第八步：探索 LaunchPad
LaunchPad 上有三个标签页：World，Room 和 Friends。你可以在 LaunchPad 上创建房间、加入房间、查看房间信息、查看好友列表、邀请好友等。

*调试多人游戏能力
本节介绍多人游戏能力调试方案。
*使用 Unity 编辑器和 PICO 设备
在 Unity 编辑器中运行 Demo 场景，同时将 Demo 的 APK 文件安装至 PICO 设备并运行。需确保编辑器端和设备端登录的是两个不同的 PICO 帐号，且已在 “好友” APP 中添加对方为好友。
*使用多台 PICO 设备
在多台设备上登录 PICO 帐号，并确保各帐号已在 “好友” APP 中互相添加好友。将 Demo 的 APK 文件安装至这些设备，然后运行 APK 文件进行测试。

adb install {APK 文件名}



*模块

*说明

Avatar

Avatar 为用户在游戏内展示的虚拟形象。在 Demo 中，Avatar 可根据头戴和手柄的数据输入来展示不同的姿态，例如抬起手臂、转动头部等。此外，你也可以改变 Avatar 的皮肤颜色。
* 

虚拟房间

虚拟房间通过调用 RoomService.CreateAndJoinPrivate2 接口进行创建。Demo 提供三个房间场景，分别是 Lobby、Blue Room 和 Orange Room，三个房间场景仅颜色不同，其他配置均相同。其中，Lobby 为启动游戏后用户默认加入的私人大厅，用户在体验过程中可加入或创建不同的房间。

控制面板

在游戏内，用户可通过 A/X 键唤起控制面板（LaunchPad），然后在 LaunchPad 上创建房间、加入房间、查看好友列表等。

多人游戏

用户可以在 Demo 内体验多人游戏能力，例如加入好友所在房间。
* 

社交系统

Demo 接入了 PICO “好友” 服务。用户登录后，可在 LaunchPad 上查看好友列表、查看好友在线状态、邀请好友。

操作

移动头显

按住鼠标右键，然后移动鼠标。

控制头显前进和后退

按住鼠标右键，然后滚动鼠标滚轮。

旋转头显

同时按住鼠标右键与鼠标滚轮，然后移动鼠标。

控制角色移动

按住 Shift 键，然后按下 W (前) / S (后) / A (左) / D (右) 键。

更换 Avatar 皮肤颜色

按下 C 键。

移动左/右手柄

*左手柄：按住 Shift 键，然后移动鼠标。
*右手柄：按住 Space 键，然后移动鼠标。

旋转左/右手柄

*左手柄：按住 Shift 键与鼠标滚轮，然后移动鼠标。
*右手柄：按住 Space 键与鼠标滚轮，然后移动鼠标。

唤起 LaunchPad

按下 L 键。

点击 UI 元素

在 LaunchPad 内，使用鼠标点击 UI 元素。
