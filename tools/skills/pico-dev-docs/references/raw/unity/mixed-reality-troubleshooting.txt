错误处理
========================================
本文记录你在使用环境感知套件中可能会遇到的错误并提供理方法。
**




错误码

描述

处理方法

ERROR_VALIDATION_FAILURE = -1

校验错误。

检查传入的参数是否正确。

ERROR_FUNCTION_UNSUPPORTED = -7

不支持所使用的函数。

检查使用的函数是否正确。

ERROR_FEATURE_UNSUPPORTED = -8

不支持所使用的功能。

检查当前设备型号或设备系统版本是否支持此功能。

ERROR_EXTENSION_NOT_PRESENT = -9

不支持所使用的功能。

检查当前设备型号或设备系统版本是否支持此功能。

ERROR_SIZE_INSUFFICIENT = -11

资源数量达到上限。


资源超过上限，例如锚点数量过多。建议提示用户删除无用的锚点。

ERROR_HANDLE_INVALID = -12

无效的 Handle。

检查传入的 Handle 是否正确。

ERROR_ANCHOR_SHARING_NETWORK_TIMEOUT = -601

锚点分享过程中，网络请求超时。

网络超时，建议再次上传锚点。若多次出现该错误，则建议提示用户检查网络连接状态。

ERROR_ANCHOR_SHARING_AUTHENTICATION_FAILURE = -602

用户未登录 PICO 帐户或你的应用未注册。

检查应用是否已在 Unity 编辑器内的 Platform Settings 中配置 AppID。若已配置，则需提示用户在 PICO 设备上登录其 PICO 帐号。

ERROR_ANCHOR_SHARING_NETWORK_FAILURE = -603

锚点分享过程中，网络请求失败。

提示用户检查网络配置。

ERROR_ANCHOR_SHARING_LOCALIZATION_FAIL = -604

锚点分享过程中，找回锚点失败。

提示用户前往锚点分享者相同位置的附近，然后再次尝试找回锚点。

ERROR_ANCHOR_SHARING_MAP_INSUFFICIENT = -605

锚点分享过程中，环境扫描不充分。

提示用户通过环顾四周来尝试找回锚点。

ERROR_SPATIAL_SENSING_SERVICE_UNAVAILABLE = -1005

系统服务异常崩溃。

建议提示用户重启应用。

ERROR_PERMISSION_INSUFFICIENT = -1000710000

权限不足。

提示用户前往设置中心，然后授权应用获取空间数据权限。
