转换并调试 SecureMR 模型
========================================
*本文介绍如何将你的模型转换为 SecureMR 模型并获取模型的性能分析数据用于调试。
*安装 Docker 桌面程序
*Windows
*启用 wsl2。详细说明参考此页面。
*安装终端。详细说明参考此页面。
*安装 Docker。详细说明参考此页面。
*在 Docker 中启用 wsl2。
* 
*macOS
*从此页面安装 Docker 桌面程序。
*运行 Docker 桌面程序。
*Linux
*安装 Docker 桌面程序。详细说明参考此页面。
*运行 Docker 桌面程序。
*获取待转换的模型
*下载以下 SecureMRTools 安装包并解压，内含一个 convert_model.sh 脚本。
* 
*将 /pth/tflite/onnx 模型移动至 convert_model.sh 脚本所在的目录。
*将模型转换为二进制文件
*运行转换脚本以生成 QNN 二进制文件。

*获取模型的性能分析数据
*为你的 PICO 设备开启 “开发者“ 模式并将其连接至 PC。详细说明参考此页面。
*运行 Docker 环境。
* 
*获取模型的性能分析数据。
* 
*你将从 qnn-net-run 处获取日志，包含基本的模型性能分析数据（如下）。
* 

./convert_model.sh --input /path/to/pth_model

./convert_model.sh --input /path/to/tilte_model

./convert_model.sh --input /path/to/onnx_model    

在转换模型时，QNN 支持通过 custom_io 指定输入/输出布局。转换脚本也集成了该功能。有详情参考此页面。

./convert_model.sh --input /path/to/onnx_model --custom_io /path/to/custmo_io.yaml
