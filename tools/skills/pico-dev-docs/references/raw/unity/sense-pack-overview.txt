环境感知套件概览
========================================
环境感知套件（Sense Pack）提供一系列混合现实能力，用于将真实和虚拟场景进行融合，创造一个虚实结合的场景，物理实体和数字对象共存于场景内并能实时相互作用。
*重要提示
*环境感知套件仅支持开发 64 位应用。
*环境感知功能概览
*
*混合现实示例
*PICO 混合现实示例是面向开发者提供的技术示例项目，展示了 PICO Unity Integration SDK 混合现实相关功能，包括视频透视、场景标定、空间网格、空间锚点和共享空间锚点。你可以在示例中体验装饰房间、墙面涂鸦、射击小游戏等混合现实功能的简单示例场景。此外，此示例提供了部分技术示例场景，你可以在 Unity 编辑器中通过模拟数据体验混合现实功能，或打包单独的场景进行体验。
*更多信息参阅此文档。




名称

说明

视频透视

视频透视（Video Seethrough, VST）功能可将真实物理世界画面实时显示在 PICO 头显内。

空间锚点

空间锚点（Spatial Anchor）技术可以将虚拟环境中的位置与真实世界中的位置进行锚定，用于将虚拟对象锚定到现实世界的位置或物体上。锚定后，使用同一设备多次进入相同的空间后，都可以在锚点位置看到虚拟物体。

共享空间锚点

同一物理空间内，当不同的用户体验同一款应用时，共享空间锚点（Shared Spatial Anchors）功能可以让用户们共享场景内容。将普通空间锚点上传至 PICO 云端后，该锚点将变为 “共享空间锚点”。

空间网格

空间网格（Spatial Mesh）主要用于在混合现实体验中提供应用对现实环境的理解。将物理世界重构为空间网格后，可以更好地实现虚拟物体与现实物体之间的交互。

场景标定

Room Capture 是 PICO 提供的系统级 MR 空间标定应用，用户可以通过此应用将现实空间中的墙、门窗、桌椅、沙发等家具标定出来，用于与 MR 虚拟物体进行交互。PICO 开发者可以通过 SDK 获取 Room Capture 创建的空间和标定数据用于自己的应用中。

MR 安全防护

当场景内的物体与 PICO 头戴或手柄间的距离处于一定范围内时，虚拟场景会变为半透明状态，呈现出现实场景。
