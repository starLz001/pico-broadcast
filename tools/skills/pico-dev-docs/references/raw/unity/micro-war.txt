迷你战争
========================================
迷你战争（MicroWar）是使用 PICO Unity Integration SDK 开发的综合游戏示例，使用了交互套件和平台服务中的核心功能。
*预览视频
玩家可以在游戏内进行多人联系对战、解锁成就、查看排行榜等。
 
*APK 安装包
将示例的 APK 文件安装至你的 PICO 设备进行体验。
 
*GitHub 仓库
前往示例的 GitHub 仓库，查看源码、美术资产等资源。
地址：https://github.com/picoxr/MicroWar
