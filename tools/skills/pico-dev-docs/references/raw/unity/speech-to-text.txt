语音转文字
========================================
“语音转文字” 服务中应用了自动语音识别技术（Automatic Speech Recognition，ASR），可以实时识别语音信息，然后将其转换为文本信息。你可将不超过 60 秒的中文或英文语音实时转换为文本。
*功能细节
*
*使用前提
PICO SDK 版本为 2.3.0 及以上。
*使用流程
*流程图
*语音转文字服务的实现流程如下。
 
*第一步：完成通用配置
参考《平台服务概览》文档，完成通用配置，包括信息注册、SDK 导入、项目配置、平台服务初始化等。
*第二步：调用 “语音转文字” 服务接口
按以下步骤调用接口，为应用接入 “语音转文字” 服务。
*调用 SpeechService.InitAsrEngine，初始化 ASR 引擎。
*注册绑定回调函数 SpeechService.SetOnAsrResultCallback 和 SpeechService.SetOnSpeechErrorCallback，用于后续获取语音转文字结果和错误信息。
*调用 SpeechService.StartAsr，开始语音转文字。
*调用 SpeechService.StopAsr，停止语音转文字。
*从回调函数内获取结果。
*Demo
*SpeechToTextDemo 展示 “语音转文字” 服务的相关功能，包括初始化 ASR 引擎、开始/停止语音识别等。若想了解更多信息，参考《语音转文字示例》文档。

*错误处理
*





功能点

描述

支持语种

中文、英文。

支持能力

语音识别、自动标点（可选）。

返回时效

实时，即边说话边输出文字。

输入音频格式

单声道。

时长限制

单次语音识别时长不超过 60 秒。



函数

说明

SpeechService.InitAsrEngine

初始化 ASR 引擎。

SpeechService.StartAsr

开始语音转文字。

SpeechService.StopAsr

停止语音转文字。

SpeechService.SetOnAsrResultCallback

设置语音转文字结果回调。

SpeechService.SetOnSpeechErrorCallback

设置语音转文字错误回调。



错误码

说明

-1 ~ -9 

SDK 内部错误，例如创建实例失败等。

-100 ~ -103

内部网络错误。

-200 ~ -202

内部地址错误。

-402

录音启动失败，无录音权限或录音被占用。

-700

录音被占用。

-601 -605 

内部 ASR 引擎异常。

-900 ~ -903 

内部指令合成异常。

-1000

ASR 引擎内部状态异常， 可以调用 StopAsr 重置状态。

-1100 / -1101 

内部鉴权失败。

1001 ~ 1099 

服务内部异常。

1013 

无效的音频。

1014 

等待音频超时。

1015 

语音音频输入过长。

1022

服务处理异常。

4001

接收数据超时。

4003 

内部网络错误。

4020 ~ 4022

内部信号库异常。

4040 ~ 4042

内部唤醒 ASR 引擎异常。

4050 ~ 4052

播放器异常。

5000 

外部错误。
