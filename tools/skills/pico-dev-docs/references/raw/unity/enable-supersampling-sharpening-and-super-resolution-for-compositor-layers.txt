为合成层开启超采样、锐化、超分辨率
========================================
超采样、锐化和超分辨率可提升合成层的渲染效果，你可以按需设置。
*使用限制
*对于同一个合成层，只能为其开启超采样、锐化和超分辨率中的一种。
*动态设置合成层时，若为同一个合成层同时开启了超采样、锐化和超分辨率，仅超采样生效。
*超采样
*超采样（Supersampling）会更高的分辨率来采样数据，从而防止图像边缘产生锯齿。使用以下步骤开启超采样：
*在 Unity 编辑器中打开你的项目。 
*在 Hierarchy 窗口中，添加一个空物体。

*锐化
*锐化（Sharpening）是一种图像处理方法，可通过增强图像中高频信息，使图像得细节边缘和轮廓更加清晰，增强对比度，从而更加突出图像的重要特征和细节。
*实现原理 
PICO 使用基于微分的空域滤波算法实现锐化。该算法可以根据当前像素与周边像素的颜色对比度来决定对当前像素增强的程度，一般来说，当前像素与周边像素的颜色差值越小，则增强程度越小；反之越大。下图展示使用锐化处理方法前后的对比。
*注意事项 
*图像锐化功能增加了采样次数和计算量，会增加 GPU 功耗。 
*图像锐化功能可能会使图像噪点或摩尔纹更明显。 
*开启锐化 
*在 Unity 编辑器中打开你的项目。 
*在 Hierarchy 窗口中，添加一个空物体。
*选中该物体，然后在 Inspector 窗口中为其添加 PXR_Composition Layer (Script) 组件。 
*在 PXR_Composition Layer (Script) 面板处，选择 Sharpening Mode (锐化模式)。

*超分辨率
超分辨率（Super Resolution）指通过一定算法，基于已知图像信息，获取并补充图像细节和其它数据信息，将低分辨率图像重建为高分辨率图像的技术，提升画面清晰度。
*使用建议 
以 PICO 4 系列设备为例，其屏幕的显示分辨率为 4320 × 2160 像素，但为了平衡功耗与性能，默认的渲染分辨率（即 Eye Buffer 分辨率）为 1504 x 1504 像素。因此，你应用的渲染分辨率通常低于设备屏幕的显示分辨率。在性能受限的情况下，开启超分辨率功能，可以在设备上为用户带来更好的视觉体验。 
若你的应用的渲染分辨率低于默认渲染分辨率，此时不建议开启超分辨率功能，因为使用超分辨率功能将会使图像噪点更加明显。另外，随着应用的渲染分辨率逐渐接近设备屏幕的显示分辨率，使用超分辨率的效果将逐渐减弱。 
与直接提升渲染分辨率相比，使用超分辨率功能消耗的 GPU 资源相对固定。在 GPU 负载较小的场景中，你可选择直接提升渲染分辨率；但在 GPU 负载较大的场景中，推荐你使用超分辨率功能，更合理分配和控制 GPU 资源。 
*注意事项 
*超分辨率会增加合成服务侧 GPU 的压力。对三个以上的图层开启超分辨率可能导致合成服务侧 GPU 资源紧张而产生画面撕裂。 会在 GPU 负载过大时自动关闭超分辨率功能，待 GPU 负载恢复正常后自动开启。 
*开启超分辨率 
*在 Unity 编辑器中打开你的项目。 
*在 Hierarchy 窗口中，添加一个空物体。
*选中该物体，然后在 Inspector 窗口中为其添加 PXR_Composition Layer (Script) 组件。  
*在 PXR_Composition Layer (Script) 面板处，勾选 Super Resolution 选框。

模式

说明

None 

不开启超采样。 

Normal 

普通超采样。该模式下，超采样一个像素只需采样其周边的 2 个像素，总共需完成 3 次采样。与 Quality 模式相比，功耗更低，超采样效果有所下降。 

Quality 

高质量超采样。该模式下，超采样一个像素需要采样其周边的 4 个像素，总共需完成 5 次采样。与 Normal 模式相比，功耗更高，超采样效果更好。 

*仅当将 Supersampling Mode 设置为 Normal 或 Quality 后，面板上才会显示 Supersampling Enhance Mode 参数。
*Blurred Quad 层不支持设置该参数。



模式

说明

None 

不开启超采样增强。 

Fixed Foveated 

静态注视点超采样增强模式。开启该模式后，应用只对用户视野中心注视点区域的图像像素进行超采样，对四周图像像素不做超采样。

说明

None 

不开启锐化。 

Normal 

普通锐化。该模式下，锐化一个像素只需采样其周边的 2 个像素，总共需完成 3 次采样。与 Quality 模式相比，功耗更低，锐化效果有所下降。 

Quality 

高质量锐化。该模式下，锐化一个像素需要采样其周边的 4 个像素，总共需完成 5 次采样。与 Normal 模式相比，功耗更高，锐化效果更好。

模式

说明

None 

不开启锐化增强。 

Fixed Foveated 

静态注视点锐化增强模式。开启该模式后，应用只对用户视野中心注视点区域的图像像素进行锐化，对四周图像像素不做锐化。 

Self Adaptive 

自适应锐化增强模式。开启该模式后，应用只对当前像素与周边像素的颜色对比度超过一定阈值的像素进行锐化，以此减少锐化的像素数，同时减少功耗。 

Both 

同时开启静态注视点锐化模式和自适应锐化模式。
