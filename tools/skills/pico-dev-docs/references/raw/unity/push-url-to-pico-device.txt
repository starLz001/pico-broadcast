推送 URL 到 PICO 设备
========================================
你可以使用 PICO 开发者中心所提供的快捷工具将指定 URL 推送到 PICO 设备，设备中的 PICO 浏览器应用将打开该 URL。
* 
*准备工作
参考《PICO 开发者中心概览》文档，完成准备工作，包括安装 PDC 工具、为 PICO 设备开启 “开发者” 模式、连接 PICO 设备和 PC。 
*操作步骤
*打开 PDC 工具。
*在 快捷工具 卡片的 PICO 浏览器 字段处，输入你想在设备内打开的 URL，点击 运行。
* 
*PICO 设备头戴端将在 PICO 浏览器 应用内打开该网址。
