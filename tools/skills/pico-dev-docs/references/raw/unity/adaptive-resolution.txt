自适应分辨率
========================================
自适应分辨率可以根据设备的 GPU 负载自动调节渲染分辨率，以保证应用始终在稳定的帧率下运行。当设备的 GPU 负载低时，应用的渲染分辨率自动提高，拥有更高的画面质量。当设备的 GPU 负载过高时，应用的渲染分辨率自动降低。你可以为应用开启自适应分辨率，然后设置分辨率调节范围和功耗等级。
*环境要求
*PICO 设备型号：PICO Neo3 系列、PICO 4 系列、PICO 4 Ultra 系列
*PICO 设备系统版本：5.7.0 及以上
*开启分辨率自适应
*在 Unity 中新建一个场景或打开已有场景。
*在 Hierarchy 窗口中，点击 + > XR > XR Origin (VR)，为场景添加 XR Origin。
*选中场景中的主相机对象。
*在 Inspector 窗口中，点击底部的 Add Component 按钮，为主相机对象添加 PXR_Manager 脚本。
*在 PXR_Manager (Script) 面板处，勾选 Adaptive Resolution 选框。
*面板上显示自适应分辨率相关设置项。
* 
*设置自适应分辨率范围：
*在 Min Adaptive Resolution Scale 字段处，设置应用的最低渲染分辨率，取值范围为 0.7 到 1.3，默认值为 0.7。
*在 Max Adaptive Resolution Scale 字段处，设置应用的最高渲染分辨率，取值范围为 0.7 到 1.3，默认值为 1.26。
* 
*在 Power Setting 字段处，选择分辨率自适应模式。
**
*Demo
*AdpativeResolution 示例展示分辨率跟随 GPU 负载变化的效果。详细说明参阅《自适应分辨率示例》文档。
*关于渲染视口调节
渲染视口尺寸（Render Viewport Scale）控制着应该用于渲染的被分配的眼部纹理的比例。尺寸越大，用于渲染的眼部纹理越多，画面越清晰。渲染视口尺寸可以在 Runtime 侧修改，而无需重新分配眼部纹理。因此，可以通过调节渲染视口尺寸来动态地调节眼部渲染像素。更多信息可参考《渲染视口调节》指南。
*已知问题
*在使用通用渲染管线（URP）与自适应分辨率时，URP 的 pipelineAsset.renderScale 设置会覆盖最大自适应分辨率比例。此问题将在 SDK 的未来版本中修复。

默认分辨率为 1504x1504。自适应分辨率计算公式：1504*Adaptive Resolution Scale。例如，1504*0.7 约等于 1100，1504*1.26 约等于 1900。



选项

说明

HIGH_QUALITY

高质量模式。提高分辨率的同时也会增加应用的 GPU 消耗。

BALANCED

平衡模式。平衡 GPU 消耗和分辨率。

BATTERY_SAVING

省电模式。使用较低的分辨率，降低 GPU 消耗。
