使用不同类型的 Operator
========================================
*SDK 提供多种类型的 operator。对于不同的 OperatorType，你需要传入不同的参数，有的 operator 还需要传入额外的配置。本文介绍 SDK 提供的所有 operator 以及使用方法。
*重要提示
*operator 无法被单独销毁，只能跟随其所在的 pipeline 一同被销毁。
*所有的 operator 都可以设置输入与输出。
*operator 相关接口
*CreateOperator：用于创建 operator。
* 
*SetOperand：用于设置 operator 的输入（即 operand）。
* 
*SetResult：用于设置 operator 的输出。
* 
*operator 使用说明
*ArithmeticComposeOperator
*ArithmeticComposeOperator 用于进行算术运算。你可以使用加（+）、减（-）、乘（*）、除（/）、括号和常量自行定义运算。你需要传入字符串形式的运算表达式。在表达式中，{X} 表示序号为 X 的 operand。例如：{0} * 2.0 + ({1} / 6) 表示 operand0 乘以 2.0 加上 operand1 除以 6。
*使用时，需要满足以下条件：
*operator 中输入的 operand 数量不可以超过 10 个。
*凡是在运算表达式里使用的 operand，均为必须，且均须为 Matrix 类型，其余 operand 为可选。
*各个 operand 的名称为 {X}，其中 X 为 operand 的序号。
*此 operator 有且仅有一个必须的 result。
