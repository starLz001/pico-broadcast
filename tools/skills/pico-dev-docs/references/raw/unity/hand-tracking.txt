接入手势追踪
========================================
手势追踪功能将用户的手部动作作为 PICO 设备的输入。开启后，PICO 系统会实时跟踪用户手部 26 个关节点的位置。将手部作为应用的主要输入源时，不同的手部姿态会触发不同的事件，例如：当大拇指指尖与食指指尖捏合时，会启用射线指针（即 Ray Pointer，作用等同于手柄射线）。用户可使用射线指针进行点击、选中、拖放等操作。你可以使用手势生成器为应用创建不同的手势，例如：戳、捏、握等，并为手势配置不同的事件，丰富交互体验。
*环境要求
*PICO 设备型号：PICO Neo3 系列、PICO 4 系列 和 PICO 4 Ultra 系列（手部模型自适应功能仅支持 PICO 4 Ultra 系列设备）
*PICO 设备系统版本：5.11.0 及以上
*手部关节定义
PICO SDK 的 “手势追踪” 功能遵循 OpenXR 标准所提出的手势定义规范并支持以下 26 个手部关节点。从掌骨关节（Metacarpal）开始，每一个关节点的 Z 轴都指向下一个关节点。

*高频手势追踪（60Hz）
高频手势追踪支持以 60Hz 追踪用户的手部动作，以捕捉更快速的手部移动，从而提升手势追踪的准确性，带给用户更加自然流畅的交互体验。
通常情况下，普通手势追踪模式已经可以达到追踪准确性和速度之间的平衡。高频追踪模式会带来更大的性能消耗。若你的应用类型（健身应用、音乐舞蹈类应用等）需要追踪更加快速的手部移动，则可以选择开启高频追踪模式。开启前，建议先测试普通的手势追踪模式可否达到预期追踪效果。
在 PXR_Manager (Script) 面板上，勾选 High Frequency Tracking (60Hz) 选框，启用高频手势追踪。

*输入源切换事件说明
*当输入源发生变化时，你会收到 PXR_Plugin.System.InputDeviceChanged 事件通知。事件内返回当前的输入源对应的值：0 (头戴)、1 (手柄)、2 (手)。例如，由手柄控制切换至手势控制时，会收到返回值 2，表明当前的输入源为手。
*Unity XR Hands 套件说明
*PICO Unity Integration SDK 支持 Unity 官方的 XR Hands 套件。套件中定义了一套 API，允许你从支持手部追踪的设备中访问手部追踪数据。关于如何使用该套件来自定义手势，参考 Unity 官方文档。
*API 参考
*若想了解手势追踪接口的详细信息，包括参数说明、返回值说明等，查阅 API 参考。
