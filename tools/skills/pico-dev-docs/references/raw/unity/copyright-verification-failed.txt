“版权校验不通过：签名非法” 如何处理？
========================================
遇到 ”版权校验不通过“ 问题时，参考以下思路进行排查。
若应用的 APK 文件未上传至 PICO 开发者管理平台，参考以下排查思路：
*检查应用包名，如果使用了 Unity 模板工程默认包名，比如 com.UnityTechnologies.com.unity.template.urpblank 和 com.DefaultCompany.VR，请修改包名后再打包应用进行测试。
*在 Unity 编辑器里打开你的项目，前往 Edit > Project Settings > Player，将 Scripting Backend 参数设置为 IL2CPP，然后重新打包应用进行测试。
*可能触发了 “相同签名下不同包名应用的数量达到上限” 的问题，此时需要将应用的 APK 文件上传至 PICO 开发者管理平台。仅需上传 APK 文件，使其保持 “草稿” 状态，无需提交审核。
若应用的 APK 文件已上传至 PICO 开发者管理平台，参考以下排查思路：
*对于已上传至 PICO 开发者管理平台的应用，需要在头戴端登录组织内的开发者帐号进行测试。检查测试时登录 PICO 设备的开发者帐号是否为组织内的帐号。
*检查新 APK 文件和已上传的 APK 文件的包名和签名是否一致。若不一致且需要使用新的包名或签名，则需要重新上传 APK 文件后再测试。
*检查填写的 appID 是否与所创建应用的 appID 一致。
