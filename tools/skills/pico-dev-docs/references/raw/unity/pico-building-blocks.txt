PICO Building Blocks
========================================
PICO Building Blocks 系统可以帮助你在项目里一键完成功能配置，包括 PICO Unity Integration SDK 和 Unity 官方提供的功能。
*XR Interaction Toolkit 版本
*3.x.x
*支持配置的功能
PICO Building Blocks 支持配置以下功能。
*
*打开 PICO Building Blocks
*
*使用 PICO Buidling Blocks 配置功能
你可以使用 PICO Building Blocks 系统一键配置所需的功能。
*PICO 手柄追踪（PICO Controller Tracking）
在场景中配置 PICO Unity Integration SDK 提供的手柄模型预制体和输入事件。预期效果如下：
* 
在 XR Building Blocks 菜单或 PICO Building Blocks 菜单中，选择 PICO Controller > PICO Controller Tracking，以下操作将被自动完成：
*检测项目内是否已安装 XR Interaction Toolkit 提供的 Starter Assets 示例。若未安装，则自动安装。
*检查场景中是否已添加 XR Origin 对象。若未添加，则自动生成 [Building Block] XR Origin (XR Rig) 对象。
*为 XR Origin 对象挂载 PXR_Manager (Script) 组件。
*找到 XR Origin 对象下的 Left Controller 和 Right Controller 对象，为它们挂载的 XR Controller (Action-based) 组件配置输入事件（XRI Default Input Actions）且分别在 Model Prefab 参数处配置对应的 PICO 手柄模型预制体（LeftControllerModel 和 RightControllerModel）。
*为 XR Origin 对象挂载的 Input Action Manager 组件的 Action Assets 参数添加 Element 0 对象，并将其设置为 XRI Default Input Actions。
若想了解如何手动配置 PICO 手柄追踪，参考此文档。
*手柄&画布交互（Controller Canvas Interaction）
 
将场景中的 Canvas 配置成可以在 PICO 设备上显示的 3D Canvas，并配置交互事件。预期效果如下：
* 
在 XR Building Blocks 菜单或 PICO Building Blocks 菜单中，选择 PICO Controller > Controller Canvas Interaction，以下操作将被自动完成：
*检查场景中是否已添加 XR Origin 对象。若未添加，则自动生成 [Building Block] XR Origin (XR Rig) 对象。
*为 XR Origin 对象挂载 PXR_Manager (Script) 组件。
*配置 EventSystem。
*添加 Building Block Controller Canvas Interaction Canvas 对象，将它的 Event Camera 设置为主摄像机，并配置 Tracker Device Graphic Raycast 组件。
*如果 Canvas 的 RenderMode 非 WorldSpace，则将其设置为 RenderMode.WorldSpace，并根据主摄像机的位置设置 Canvas 的显示位置。确保手柄射线可以和画布正常交互。
此外，你可以在 Canvas 对象下添加 Button - TextMeshPro 和 Dropdown - TextMeshPro 等 UI 对象，然后配置 PICO Controller Tracking 功能，以体验手柄与画布间的交互效果。
若想了解如何手动配置手柄和画布交互，参考此文档。
*PICO 手势追踪（PICO Hand Tracking）
在场景内添加 PICO 提供的手部模型预制体，并启用手势追踪。预期效果如下：
* 
在 XR Building Blocks 菜单或 PICO Building Blocks 菜单中，选择 PICO Hand > PICO Hand Tracking，以下操作将被自动完成：
*检查场景中是否已添加 XR Origin 对象。若未添加，则自动生成 [Building Block] XR Origin (XR Rig) 对象。
*在 XR Origin 对象下添加 PICO 提供的手柄模型.
*为 XR Origin 对象挂载 PXR_Manager (Script) 组件。
*勾选 PXR_Manager (Script) 组件面板上的 Hand Tracking 选框，启用手势追踪能力。
若想了解如何手动配置 PICO 手势追踪，参考此文档。
*XR 手势追踪（XR Hand Tracking）

*XR Interaction Toolkit 3.x.x 带来的变更及解决方案
PICO Unity Integration SDK 3.1.0 及更高版本中的 PICO Building Blocks 系统基于 XR Interaction Toolkit 3.x.x 版本开发。与基于 XR Interaction Toolkit 2.x.x 版本开发的 Building Blocks 系统相比，发生以下变更。
*XR Origin 不再包含左右手柄。
 
*因此，手柄配置以及依赖手柄射线的 PICO Controller Tracking 和 Controller Canvas Interaction 项会受到影响，需使用 XR Interaction Toolkit 3.x.x 中的 XR Origin (XR Rig).prefab 替换原先的 XR Origin。XR Origin (XR Rig).prefab 位于 /Assets/XR Interaction Toolkit/{version}/prefabs 目录下。
*XRI DefaultInputActions.inputactions 中的 Action Maps 的名称去掉了 “Hand” 字样。
**
 
*需将手势相关功能使用的主相机 XR Interaction Hands Setup 替换为XR Origin Hands (XR Rig)。
 
*在 XR Interaction Toolkit 3.x.x 中使用 Canvas 并与手柄进行交互时，需隐藏 EventSystem。
