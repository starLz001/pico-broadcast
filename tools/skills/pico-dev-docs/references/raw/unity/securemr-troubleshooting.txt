问题排查
========================================
本文介绍了如何处理在使用 SecureMR 时可能遇到的错误。
*Server Err: [INVALID PARAMETER]
错误信息：
 
解决方案：
*根据第一行的错误，第二十三个 Operator 是 XR_SECURE_MR_OPERATOR_TYPE_RECTIFIED_VST_ACCESS_PICO。2464x3248 与 256x256 之间的不匹配是由于框架中设置的 VST 图像分辨率与 RECTIFIED_VST_ACCESS 操作符提供的结果形状不一致所导致的错误。
*Server Err: [HANDLE NOT INITIALIZED]
错误信息：
 
解决方案：
*检查是否有未注册到 Pipeline 中的 Tensor。该 Pipeline 的 ID 是 b40000776b92e718。
*Server Err: [HANDLE NOT INITIALIZED]
错误信息：
 
解决方案：
有未注册到 Pipeline 中的 Tensor。Tensor 通过 xrCreateSecureMrPipelineTensorPICO 注册到 Pipeline 中。你需要检查代码，以确认是否存在变量命令错误，导致 Pipeline 中使用的 Tensor 未通过 xrCreateSecureMrPipelineTensorPICO 注册。
