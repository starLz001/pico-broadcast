空间音频
========================================
相较于传统立体声技术，空间音频渲染赋予声音更强大的空间感，可覆盖听者四周的所有声源，包括水平面上的声源和上下方的声源。此外，空间音频场景下，用户感知到的声音变化更加贴合实际，例如：当用户靠近声源时，音量将会变大。
*环境要求
*设备型号：PICO Neo3、PICO 4 和 PICO 4 Ultra 系列
*设备系统版本：5.12.0 及以上
*Unity 版本：经测试，空间音频渲染器在以下 Unity 版本中可用：
*2021.1.9f1c1
*2020.3.21f1 LTS
  若你在其他 Unity 版本中成功使用空间音频渲染器，请告知我们，谢谢。

*混合现实空间音频
* 
*PICO 4 Ultra 系列设备支持实时动态扫描现实场景，然后将场景中的内容转换成空间网格。PICO 空间音频插件将该能力与空间音频渲染能力相结合，使虚拟声源可以与用户所处的真实环境交互，产生以下效果：
*虚拟声波从真实环境的表面（即实时空间网格的表面）反射回来；
*虚拟声波穿过真实世界的表面（即实时空间网格）时，音量衰减。
*使用以下步骤配置混合现实空间音频模式：
*在 PXR_Manager (Script) 组件面板上，勾选 Spatial Mesh 选框，开启空间网格能力，然后选择所需的 LOD。
* 
*在场景中的任意 GameObejct 上，挂载 PXR_Spatial Mesh Manager (Script) 组件，然后在 Mesh Prefab 处添加任何带有MeshFilter 组件的预制体（可以参考 /SpatialAudio/Samples/Resources/MeshPrefab 目录下的预制体）。
* 
*在场景中的任意 GameObject 上，挂载 PXR_Audio_Spatializer_MR Scene Geometry Manager 组件。
* 
*若你需要参考 PICO 提供的示例场景，可在 /SpatialAudio/Samples/SpatialMesh_with_SpatialAudio.unity 目录下获取。

*使用技巧
*Unity 设置
修改 C# 代码后，即使当前正在播放音频，Unity 编辑器也会默认即刻进行编译。对于 PICO 的空间音频渲染功能来说，若在播放音频时进行编译，会导致编辑器崩溃。为避免此问题，你可以通过以下步骤更改 Unity 设置：
*从上方菜单栏处，选择 Edit > Preferences。
*你将看到 Preferences 窗口。
*从左侧导航栏处，选择 General。
*将 Script Changes While Playing 设置为 Recompile After Finished Player 或 Stop Playing And Compile。
* 
*声源数量
环境声学模拟和多普勒效应模拟会造成较大的 CPU 负载。因此，在使用环境声学模拟时，请确保同时发声且开启多普勒效应模拟的声源数量在 20 以内。
*多普勒效应
为声源开启多普勒效应模拟后，声源的直达声和反射声将具有更高的真实感，但是音频线程 CPU 消耗变高；若关闭，声源的直达声和反射声的真实感降低，但是音频线程CPU 消耗相比打开多普勒效应时大幅减低。
若希望实现多普勒效应，同时保证较少的 CPU 和内存消耗的话，可以尝试以下方法：
*选择一些可接受的、声音真实感稍差的声源。
*为声源关闭 Enable Doppler 选项。
*将声源的 Spatial Blend 选项的值置为 1。
*此时，音频信号输入音频渲染器时，会重新转换成 mono 格式，而不会被空间化。这样，在不使用 Unity 的方向感空间化算法的同时，使用了 Unity 自带的多普勒效应，从而在声源数量庞大的情况下，实现了音质和性能之间的平衡。
*环境声学模拟 Mesh 最佳实践
*不同材质的场景物体，其 Mesh 需要被分割。这样，在它们的 GameObject 上挂载 PXR_Audio_Spatializer_SceneMaterial 组件之后，可以更方便地设置不同的声学材质，从而最精确地模拟环境声。
*环境声学模拟场景中，若听者处于一个闭塞的小角落，可能会听不到场景中某些声源的环境反射声。当你使用我们最新的 Unity 插件时，这种情况非常罕见。 
*如果你碰到了这个问题，首先建议升级 Pico Spatializer 插件至最新版本。如此问题仍然存在，尝试以下解决方案：
*在游戏流程上进行规避，避免让玩家进入到会出错的场景区域。
*将场景中的 Mesh 分组成多个 GameObject，只在室内的大型墙面上挂载 PXR_Audio_Spatializer_Scene Geometry 组件，而不要在过多的细节形状（比如桌椅、柱子等）上挂载。
*若无声问题依然存在，可以在想要反射声音的场景处，手动添加一些 Pico Sound Reflection Object，如下图白色线框中所示。Pico Sound Reflection Object 位于 /Pico Spatial Audio/Prefabs 目录下。

参数

说明

Source Attenuation Mode

用于设置声源音量随距离衰减的特性，选项有：
*None：声源的音量不随着距离变化而变化；
*Fixed：声源的音量不随着距离变化而变化；
*Inverse Square：声源的音量与声源和听者之间的距离的平方成反比；
*Custom（请勿使用该选项）

Min Attenuation Distance

用于设置声源音量的最近衰减距离。当听者与声源的距离小于 Min Attenuation Distance 时，声源音量不会随着距离的变化而衰减，即：衰减 = 0dB。
提示：请勿输入大于 Max Attenuation Distance 的数值，否则会形成反常的音量衰减曲线。

Max Attenuation Distance

用于设置声源音量的最远衰减距离。当听者与声源的距离大于 Max Attenuation Range 时，声源音量不会再随着距离的增长而衰减。
提示：请勿输入小于 Min Attenuation Distance 的数值，否则会形成反常的音量衰减曲线。

Material Preset

包含了 PICO 为不同物体预设的 Absorption，Scattering 和 Transmission 参数值。 
若需自行设置参数值，选择 Custom；若需使用预设参数值，从列表中选择对应物体。

Absorption band XXXX Hz

环境材质的吸收率。

Scattering

环境材质的散射率。高散射率环境中，反射声听上去更像混响；低散射率环境中，反射声听上去更像一个个独立的回声。简单来说： 
*Scattering 的值越大，混响越大，回声越小 
*Scattering 的值越小，混响越小，回声越大 

Transmission

环境材质的透射率。透射率越高，穿过该几何形状的声音强度越大；反之则越弱。 
提示：Scattering 率越大的材质，Tranmission 率越低。

设置声源音量的最大衰减距离。当听者与声源的距离大于 Max Attenuation Range 时，声源音量不会再随着距离的增长而衰减。 
提示：请勿输入小于 Min Attenuation Distance 的数值。

GetMaxAttenuationRange

获取声源音量的最大衰减距离。

SetDirectivity

设置声源的辐射指向性（Polar Pattern）。
*alpha：定义指向性图案的形状
*order：表示源极坐标图的锐度
