面部追踪
========================================
面部追踪，即在检测到人脸的前提下，在后续帧中持续捕捉人脸位置和面部表情等信息的技术。在现实世界中，面部表情可以表现人物内心的情绪和情感，是十分重要的非语言社交手段。同样地，在虚拟世界中，若面部模型能及时且准确的根据用户的实际面部表情变化而做出相应的面部动作，将能使应用内互动更加逼真，提升应临场感。
面部追踪相机可检测和捕捉用户的面部表情。面部追踪接口会将相机捕捉到的表情数据抽象成 BlendShapes 数据，然后透传给应用来执行面部追踪能力。面部追踪接口支持 52 维 BlendShapes 以及 20 维 Viseme，覆盖眼部、唇部、舌部、鼻部、面颊、额头和下巴区域，可驱动人脸模型做出微笑、眨眼、皱眉等各种动作。
*效果展示
在以下视频中，Avatar 面部可根据用户的实际表情变化来做出相应的动作，包括移动眼球、眨眼和张开嘴巴。

*启用面部追踪
*应用端
按以下步骤为你的应用开启面部追踪能力：
*在 Unity 编辑器中创建一个场景或打开已有场景。
*在 Hierarchy 窗口中，为场景添加 XR Origin。若已添加，可跳过此步骤。
*选中 XR Origin。
*Inspector 窗口中将展示 XR Origin 挂载的组件和脚本。
*点击 Inspector 窗口底部的 Add Compoent 按钮，为 XR Origin 添加 PXR_Manager 脚本。
*在 Face Tracking Mode 处，选择面部追踪模式。

*启动 VR 一体机。
*前往 设置 > 实验室 > 表情模拟。
*打开 表情模拟 开关。

*调用面部追踪接口
根据实际需求，调用面部追踪接口。
*表明当前应用需要面部追踪能力
在调用所有面部追踪相关接口前，需要调用 WantFaceTrackingService 接口，表明当前应用需要使用面部追踪能力。
*查询当前设备是否支持面部追踪
调用 GetFaceTrackingSupported 接口，查询当前设备是否支持面部追踪。接口返回当前设备支持的面部追踪模式数量以及具体支持的模式。
*动态开始和停止面部追踪
*调用 StartFaceTracking 接口，传入所需的面部追踪模式，开始面部追踪。调用该接口后，系统会通过弹窗向用户申请面部追踪权限。
*调用 StopFaceTracking 接口，停止面部追踪。若将 FaceTrackingStopInfo 中的 pause 设置为 0，则实际操作为暂停面部追踪。
*切换面部追踪模式
若想切换面部追踪模式，可以先调用 StopFaceTracking 接口，然后再调用 StartFaceTracking 接口。为了快速切换模式，在调用 StopFaceTracking 接口时可以将实际操作设置为暂停面部追踪，即将 FaceTrackingStopInfo 中的 pause 设置为 0，然后再调用 StartFaceTracking 接口选择一个新的模式。此方式可减少面部追踪启停的耗时，更快获取面部追踪数据。
 
*查询面部追踪状态
调用 GetFaceTrackingState，查询面部追踪状态，包括面部追踪是否正常工作中、面部追踪模式、状态码。
*获取面部追踪数据
调用 GetFaceTrackingData 接口，获取面部追踪数据。接口的返回中包含一个 72 定长的数组，对应 52 维 BlendShapes 数据和 20 维 Viseme 数据。参阅 “BlendShape & Viseme 参考” 部分了解每个值对应的含义。调用 GetFaceTrackingData 接口前，必须先调用 StartFaceTracking 接口，开启面部追踪。

    private FaceTrackingMode[] supportedModes = { };
    private FaceTrackingMode supportedMode;
    private bool supported = false;
    private int modeCount = 0;
 
    void Start()
    {
        // 查询当前设备是否支持面部追踪
        int ret = PXR_MotionTracking.GetFaceTrackingSupported(ref supported, ref modeCount, ref supportedModes);
 
        if (supported)
        {
            // 开始面部追踪
            FaceTrackingStartInfo info = new FaceTrackingStartInfo();
            info.mode = FaceTrackingMode.PXR_FTM_FACE;
            PXR_MotionTracking.StartFaceTracking(ref info);
        }
 
    }
 
    void Update()
    {
        if (supported)
        {
            // 获取面部追踪状态
            bool tracking = false;
            FaceTrackingState faceTrackingState = new FaceTrackingState();
            PXR_MotionTracking.GetFaceTrackingState(ref tracking, ref faceTrackingState);
 
            // 获取面部追踪数据
            FaceTrackingDataGetInfo info = new FaceTrackingDataGetInfo();
            info.displayTime = 0;
            info.flags = FaceTrackingDataGetFlags.PXR_FACE_DEFAULT;
            FaceTrackingData faceTrackingData = new FaceTrackingData();
            PXR_MotionTracking.GetFaceTrackingData(ref info, ref faceTrackingData);
        }
    }
 
    private void OnDisable()
    {
        if (supported)
        {
            // 停止面部追踪
            FaceTrackingStopInfo info = new FaceTrackingStopInfo();
            PXR_MotionTracking.StopFaceTracking(ref info);
        }
    }
