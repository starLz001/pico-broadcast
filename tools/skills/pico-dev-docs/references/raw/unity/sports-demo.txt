运动数据授权示例
========================================
你可以在 PICO Github 上获取 “SportCenter” Demo，然后使用该 Demo 调试运动数据授权接口。Demo 的图形化界面如下：
* 
按以下说明使用 Demo：
*点击 GetUserInfo，获取用户的基础信息和运动计划信息。
*拖动滑块设置时间范围，时间范围不超过最近 24 小时，然后点击 GetSummary，获取用户的今日运动数据汇总。
*拖动滑块设置时间范围，时间范围不超过最近 90 天，然后点击 GetDailySummary，获取用户某段时期内的每日运动数据汇总。
