功能

命令

开启/关闭 Wi-Fi

开启：adb shell svc wifi enable
关闭：adb shell svc wifi disable

开启/关闭静音

开启：adb shell media volume --stream 3 --set 0
关闭：adb shell media volume --stream 3 --set 8
*提示：PICO 4 Ultra 及 Project Swan 系列设备不支持直接调用静音控制命令，可通过多次调用 adb shell input keyevent 24 和 adb shell input keyevent 25 命令来达到开启/关闭静音的效果。

设备关机

adb shutdown

设备重启

adb reboot
