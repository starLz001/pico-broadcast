挑战
========================================
挑战（Challenge）可在玩家间创造趣味性竞争，增强玩家之间的互动。开发者和玩家都可以为应用创建挑战，配置挑战信息（包括名称、可见性、开始和结束时间），然后邀请好友参与挑战，玩家也可以参与平台所创建的官方挑战。挑战为异步进行，即参与者无需同时上线进行挑战。
*功能说明
*获取挑战信息
创建挑战时，可配置挑战的可见性。若挑战为公开可见，创建后将在应用中进行展示。用户可浏览挑战列表和具体的挑战信息。相关接口如下：
*主动加入/离开挑战
创建挑战后，用户可浏览挑战，并选择感兴趣的挑战加入。若不想继续某一挑战，可退出。
*邀请好友加入挑战
用户可邀请好友加入挑战，包括未开始和进行中的挑战。用户发送挑战邀请后，被邀请人会在 PICO IM 中收到邀请通知。接受邀请后：
*若该挑战对应的排行榜关联了 Destination，会启动相关应用并进入对应的 Destination；
*若该挑战对应的排行榜未关联 Destination，会启动相关应用并进入首页。
你可以自行设计邀请面板，或调用相关接口来使用“PICO 好友”应用提供的系统邀请面板（下图所示）。
* 
*成绩管理
挑战附属于排行榜，并沿用排行榜的排序方式和成绩种类。挑战与排行榜的成绩条目分别存储。若用户退出挑战，其成绩将被删除。成绩更新分为以下两类：
*仅更新挑战条目
*若最新挑战成绩等于或高于现有挑战成绩，但低于现有排行榜成绩，则仅将最新成绩更新至挑战条目中。
*同时更新挑战和排行榜条目
*若最新挑战成绩等于或高于现有挑战成绩和挑战对应的排行榜成绩，则将最新成绩同时更新至挑战和排行榜条目中。
*流程概览
*挑战附属于排行榜，你必须基于已创建排行榜来创建挑战，并负责显示、管理和验证挑战相关数据（例如：用户的挑战成绩）此外，用户也可以创建挑战并邀请好友加入。流程图如下：

方法一：

方法二：
你可以在 PICO 开发者平台为指定排行榜创建挑战，步骤如下：
*登录 PICO 开发者平台。
*在左侧导航栏中，点击 我的应用。
*你将前往 我的应用 页。
*点击目标应用，进入其 概览 页。
*在左侧导航栏中，点击 平台服务。
*你将前往 PPS 开发平台。
*在左侧导航栏中，选择 排行榜。
*你将进入排行榜管理面板。
*在排行榜列表中，找到目标排行榜，然后点击 操作 栏中的 挑战。
*你将进入该排行榜的挑战管理面板。
*点击 创建挑战。
*你将进入挑战配置面板。
* 
*配置挑战。
*点击 保存。
*你创建的挑战将被添加至 我的挑战 列表。用户挑战 列表用于展示用户创建的挑战。
*第四步：初始化平台服务和游戏模块
*全局初始化平台服务。你可以调用 CoreService.Initialize() 接口同步初始化平台服务，或调用 CoreService.AsyncInitialize() 接口异步初始化平台服务。
*调用 CoreService.GameInitialize 接口初始化游戏模块。
*详细说明和代码示例参考《初始化》一文。

接口
说明
ChallengesService.Get
获取指定挑战的信息。除基本信息外，还支持获取该挑战的已邀请用户、已加入用户、推荐邀请用户列表。
ChallengesService.GetList
获取挑战列表，需指定返回的页码和每页返回的挑战数量。你可以通过设置 ChallengeOptions 来设置筛选条件，例如挑战的时间范围、所属排行榜、可见性，从而获得指定挑战。
// 点击获取挑战列表按钮
void OnGetListBtnClick()
{
    ChallengeOptions options = new ChallengeOptions();
    options.SetTitle("your challenge title");
    options.SetVisibility(ChallengeVisibility.Public);
    options.SetLeaderboardName("your leaderboard name");
    options.SetViewerFilter(ChallengeViewerFilter.AllVisible);
    options.SetIncludeActiveChallenges(true);
    options.SetIncludeFutureChallenges(true);
    options.SetIncludePastChallenges(true);
    
    var task = ChallengesService.GetList(options, 0, 5);
    // 添加 OnComplete 函数
    task.OnComplete(OnGetListComplete);
}

void OnGetListComplete(Message<ChallengeList> msg)
{
    if (msg.IsError)
    {
        Debug.Log($$"OnGetListComplete error: {msg.GetError().Code}, {msg.GetError().Message}");
        return;
    }
    // 处理回包数据（ChallengeList）
}



接口
说明
ChallengesService.Join
允许用户主动加入挑战。用户加入挑战后，将出现在该挑战的已加入用户列表中，用户离开挑战后，将被从该列表中移除。
ChallengesService.Leave
允许用户主动退出挑战。 退出后，用户的分数条目将被删除。
ChallengesService.Join(challengeID).OnComplete(OnJoinComplete);

ChallengesService.Leave(challengeID).OnComplete(OnLeaveComplete);

接口
说明
ChallengesService.Invite (不带系统邀请面板)
邀请好友加入指定挑战，同时会将 challengeID 发送给好友。
注 ：若使用该接口，你需要自行设计邀请面板。
ChallengesService.LaunchInvitableUserFlow (自带系统邀请面板)
邀请好友加入挑战，同时会将 challengeID 发送给好友。该接口会拉起系统邀请面板（如下图所示），面板中会展示用户的全部好友，用户可从中选择好友进行邀请。如果好友未安装该应用，点击该应用邀请卡片后，会跳转至该应用在 PICO 商店中的详情页。
// ChallengesService.Invite
string[] userIds = new string[]{"userid1", "userid2"};
ChallengesService.Invite(challengeID, userIds).OnComplete(OnInviteComplete);

// ChallengesService.LaunchInvitableUserFlow
var task = ChallengesService.LaunchInvitableUserFlow(challengeID).OnComplete((Message message) =>
{
    if (!message.IsError)
    {
        Debug.Log($$"OnLaunchInvitableUserFlowComplete no error");
    }
    else
    {
        var error = message.GetError();
        Debug.Log($$"OnLaunchInvitableUserFlowComplete error: {error.Message}");
    }
});



接口
说明
LeaderboardService.WriteEntry
将用户的成绩写入挑战对应的排行榜。
ChallengesService.GetEntries
获取成绩条目。可使用 filter 参数对返回结果进行过滤，其中：
*None：不进行过滤，返回所有条目。
*Unknown & UserIds：无效类型，不返回条目。
*Friends：同时返回好友和自己的条目。
注 ：如果想通过 User ID 过滤条目，也可以直接使用 ChallengesService.GetEntriesByIds 接口。
ChallengesService.GetEntriesAfterRank
获取某个排名后的成绩条目。
ChallengesService.GetEntriesByIds
获取指定用户的成绩条目。
var task = ChallengesService.GetEntries(challengeID, 
    LeaderboardFilterType.None,
    LeaderboardStartAt.Top, 
    0,
    5).OnComplete(OnGetEntriesComplete);

string[] userIds = new string[]{"your userid1", "your id2"};
var task = ChallengesService.GetEntriesByIds(challengeID, 
    LeaderboardStartAt.Top, 
    userIds, 
    0,
    5).OnComplete(OnGetEntriesComplete);

var task = ChallengesService.GetEntriesAfterRank(challengeID,

    0,

task.OnComplete(OnGetEntriesComplete);
