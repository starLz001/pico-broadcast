Demo
========================================
你可以在 PICO Github 上获取 “GameAPITest” Demo。Demo 包含成就服务的全部接口，可用来进行接口调试。Demo 拥有图形化界面（如下图所示），相关部分位于 DebugPanel 文件夹中。此外，Log 文件夹中包含用于输出日志的脚本文件。
* 
按以下步骤使用 Demo：
*启动 Demo。
*在 Function type 下，选择 Achievement。
*列表中将展示成就服务的所有可用接口。
*选择具体的接口。
*在 set parameters here 下，将列出需为该接口配置的参数。
*配置参数。
*点击 Execute。
*右侧日志面板处将显示执行结果。
*(可选) 点击单条日志，查看日志详情。
