SpatialMP4 白皮书
========================================
空间视频结合了立体RGB、深度和姿态数据，以实现沉浸式3D体验（例如，AR/VR、机器人、3D重建）。本文档介绍一种基于MP4的容器格式，用于有效地同步和存储这些数据流。
*主要特点
*多种数据轨道：除音视频轨道外，提供立体图像深度、位姿等轨道，便于业务侧应用。
*同步：图像帧、深度图和姿势数据轨均配备了各自的时间戳基准，便于业务方据此做数据同步。
*兼容性：支持传统的双目3D并排格式和MV-HEVC编码格式。
*MP4容器扩展
*立体声RGB轨道
立体声RGB轨道用于保存来自左右RGB摄像机的视频流。此轨道是强制性的。
*基本的
*编解码器：AVC/HEVC/MV-HEVC
*布局：多层（MV-HEVC）/并排（左/右或上下）
*比特深度：8/10位
*VideoExtendedUsage Box（vexu）
这个盒子是强制送货的。
此框由Apple提出，与Apple空间视频格式一致。我们主要关注这些新增的框。其他请参阅Apple白皮书：
https://developer.apple.com/av-foundation/Stereo-Video-ISOBMFF-Extensions.pdf

*IntrinsicCameraParametersBox（icam）
此框是可选的，用于MR和ML开发人员场景。
此框指定了将图像点的像素坐标与相机参考帧中的相应坐标联系起来的内在相机参数。ISO/IEC 14496-10附件H中给出了焦距和与相机光学引起的几何失真相关的参数的规范。有关详细信息，请参阅ISO/IEC 14496-15:2024：https://www.iso.org/standard/89118.html

*ExtrinsicCameraParametersBox
此框是可选的，用于MR和ML开发人员场景。
本条款规定了定义摄像机参考帧相对于已知世界参考帧的位置和方向的外部摄像机参数。ISO/IEC 14496-10附件H中给出了包括平移向量和旋转矩阵在内的外部摄像机参数的规范。有关详细信息，请参阅ISO/IEC 14496-15:2024：https://www.iso.org/standard/89118.html

*语义

*旋转矩阵（R）：表示相机坐标系相对于世界坐标系的旋转，矩阵元素通过指数和尾数与精度参数相结合来计算，以确保旋转姿态的准确表示。
*平移向量（T）：表示摄像机坐标系原点在世界坐标系中的位置，分量由指数和尾数计算，并与旋转矩阵一起定义摄像机的外部参数。

class ExtrinsicCameraParametersBox extends FullBox ('ecam', version=0, flags) {
    unsigned int(6) reserved=0;
    unsigned int(10) ref_view_id;
    unsigned int(8)prec_rotation_param;
    unsigned int(8)prec_translation_param;
    for (j=1; j<=3; j++) { /* row */
        for (k=1; k<=3; k++) { /* column */
              unsigned int(8)exponent_r[j][k];
              signed   int(64)mantissa_r [j][k];
        }
        unsigned int(8)exponent_t[j];
        signed   int(64)mantissa_t[j];
    }
}
