平台服务概览
========================================
本文介绍平台服务的应用场景、PICO 提供的平台服务、平台服务使用流程以及异步接口调用相关信息。
*应用场景
平台服务提供应用内不可或缺的基本能力。通过单独使用某个平台服务，或组合使用多个平台服务，你可以为用户带来独一无二的游戏体验。平台服务的核心使用场景如下：
*安全
* 通过身份认证和用户权限校验等手段，保护你的应用和用户。
*营收
*通过应用内购、订阅等能力，为你拓宽盈利渠道。
*社交
*支持添加好友、匹配组队等能力，让用户在应用中体验社交的乐趣。
*活跃度
*通过成就、排行榜等能力，在应用内创造趣味性竞争氛围，调动玩家的积极性。
*重要提示
*平台服务仅支持开发 64 位应用。

*平台服务使用流程
*注册开发者信息、配置开发环境、导入 PICO Unity Integration SDK、完成项目配置。详细说明《快速开始》指南。
*初始化平台服务。若你需要使用游戏相关服务（房间&匹配、排行榜、成就、挑战），则还需初始化游戏模块。详细说明参考《初始化》指南。
*为应用接入所需服务。详细说明参考对应功能的使用指南和客户端API 参考。若应用需要访问 PICO 的服务端，你需要使用到服务端接口，详见服务端 API 参考。
*关于异步接口调用 
自 2.1.4 版本开始，你可以使用 async/await 方法异步调用平台服务接口。在多请求串行执行场景下，该调用方式可让代码更加清晰。 
以获取当前登录用户接口 UserService.GetLoggedInUser 为例，若不使用 async/await 方式，则需在 Task<T>.OnComplete() 函数中设置回调函数。 
 
若使用 async/await 方法，调用 Task<T>.Async() 后将得到异步任务 System.Threading.Tasks.Task<Message<T>>，执行 await 表达式后即可得到最终的请求结果。
 




服务名称

说明

账号&好友

账号&好友服务提供了账号获取、好友关系管理等功能，包括获取指定账号信息、获取当前登录用户的好友列表、发送好友申请等。

账号关联

通过账号关联服务，你可以将用户的 PICO 账号与自己的自有账号体系关联起来，获取用户的 PICO 账号信息，从而允许用户使用 PICO 账号登录你的应用。

语音聊天

语音聊天服务由实时音视频技术（real-time communication，RTC）实现。同一个房间内的用户可以互相通信。

语音转文字

“语音转文字” 服务中应用了自动语音识别技术，可以实时识别语音信息，然后将其转换为文本信息。

房间&匹配


多人游戏服务提供了联网游戏、在线匹配、房间管理、房间内用户互动等能力，主要包括房间功能、匹配功能、和消息收发功能。

社交互动

社交互动是应用体验的重要组成部分。通过社交互动服务，用户可以找到兴趣相投的人一起体验应用，邀请好友加入当前应用，查看好友所在位置并主动加入。

排行榜

排行榜是应用内基础且重要的功能之一。排行榜从多维度展示玩家在应用中的排名，可以激发玩家间的趣味性竞争。

成就

成就系统可以帮助你在游戏中建立一个正反馈机制。玩家在游戏中取得阶段性成果后，系统可以向玩家发放奖品。

挑战

挑战可在玩家间创造趣味性竞争，增强玩家之间的互动。你和玩家都可以为应用创建挑战。

高光时刻

“高光时刻” 服务用于记录用户使用应用过程中的精彩时刻，并将这些时刻以图片或视频的形式保存下来，供用户回顾和分享。

应用内购

你可以在应用内提供皮肤、道具、金币/钻石等付费商品，丰富用户的应用体验，拓宽盈利渠道。

可下载内容

DLC 为应用内可下载的内容/文件，如游戏的后续拓展包，可为你带来新的收益途径。

订阅

订阅是一种周期性支付的机制，可让用户购买应用中的付费内容。

运动数据授权

PICO 系统上的运动类应用可以通过运动数据来分析用户的运动情况，从而为用户提供更好的定制化体验。

云存档

云存档服务可用来备份用户设备上的应用数据，例如用户在应用内的身份、自定义设置、偏好设置、游戏进度等。

UserService.GetLoggedInUser().OnComplete(m =>

    if (m.IsError)
