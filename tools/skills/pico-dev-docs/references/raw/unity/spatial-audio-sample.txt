空间音频示例
========================================
PICOSpatialAudioSample 展示了 PICO Unity Integration SDK 所提供的空间音频功能。你可以在该示例之中配置空间音频参数、在场景内移动、播放声源等。

*APK 文件
使用 USB 数据线连接 PICO 设备和你的 PC，然后使用以下 ADB 命令将示例的 APK 文件安装至设备进行体验。

你可以克隆该示例的 GitHub 仓库，查看源代码、图形资产、脚本文件等。

*PICO 设备系统版本：5.9.2
*PICO Unity Intergration SDK 版本：2.5.0

在 Unity 编辑器中，可以通过 XR Simulator 中设置的按键进行以上操作。如下图所示，你可以按下键盘上的 T 或者 Y 键切换到左或者右手柄进行控制，也可以按下 B 键打开参数设置面板。

*在场景中移动
*通过左摇杆进行平滑移动，在场景的不同地面会产生不同的脚步音效。
*通过右摇杆进行传送移动。
*建议选择对自己来说眩晕度小的移动方式进行体验。
* 
*如果在使用左手柄摇杆进行前后移动时感到眩晕，可以采取以下方法:
*方法一：向前推动右手柄的摇杆可以标记位置，然后松开即可传送到该位置。通过左右移动右手柄的摇杆可以调整场景中的视角。
*方法二：按住左手柄上的扳机键，指向目标传送位置，然后松开即可传送到该位置。通过左右移动右手柄的摇杆可以调整场景中的视角。
* 
*播放声源
场景中有光晕的物体都是可交互发声的物体，其光晕代表物体的播放状态，点击可发声物体可以播放/停止播放该物体的声音。
* 
*配置指定声源的参数
*点击发声物体上方的齿轮按钮，可直接唤起对应声源的参数配置面板。
* 
*你也可通过按下手柄上的 A 键，呼出参数配置面板，选择 Audio Srouce Settings 面板，然后在 Audio Source 下拉菜单中选择想要调整参数的声源。
* 
*配置全局音频参数
*按下手柄上的 A 键，呼出控制面板，然后在 Global Settings 面板上配置全局音频参数。
* 
*场景交互
光标移到门上，单击板机键，可以开/关门。声波在房间中的传播会受门开/关的影响。
* 
*控制背景音乐
电视屏幕上展示音乐播放器界面，你可以在界面上进行以下操作：
*点击播放/暂停按钮，从而播放/暂停背景音乐
*点击快进/快退按钮，从而播放后一首/前一首背景音乐
*点击歌名（BGM1、BGM2、BGM3、etc.）从而播放指定背景音乐

参数名称

说明

*Master Volume

用来统一调节设置全局音量的大小（dB）。

Background Volume

用来统一调节设置 BGM 类音量的大小（dB）。本场景主要用于管理脚步声，开关门声等的音量大小。

Spatial Audio Volume

用来统一调节设置空间音源类音量的大小（dB）。本场景主要用于管理可交互音源的音量大小。

Ambisonic Volume

用来统一调节设置环境音音量的大小（dB）。本场景主要用于管理全局环绕风雨声的音量大小。

Controller Guide Tips

用来隐藏或显示手柄模型处的提示。



参数名称

说明

Audio Source

选择场景中的声源，修改其空间音频参数。

Source Gain (dB)

*设置声源的增益，单位是分贝（dB）。增大/减小增益后，该声源的总音量会随之增大/减小。

Reflection Gain (dB)

设置声源反射声的增益，单位是分贝（dB）。增大/减小 Reflection Gain 后，声源的反射声音量会在 Source Gain 的基础上进一步增大/减小。

Source Radius (m)

设置这声源的半径长度，单位是米。Source Radius 大于 0 时，声音的宽度会随着用户与声源间距离的缩短而变宽。Source Radius 越大，用户与声源间距离同等的情况下，声源听上去越宽。

Doppler

用于设置是否声源开启多普勒效应模拟。
*若开启，声源的直达声和反射声将具有更高的真实感，但是音频线程 CPU 消耗变高；
*若关闭，声源的直达声和反射声的真实感降低，但是音频线程CPU 消耗相比打开多普勒效应时大幅减低。

*以下参数为声源指向性（Directivity）相关参数。现实中，声源向四周散发的声波能量不是各向同性的，而是用一个与声波出射角相关的极坐标函数表示的，我们称之为声源的 Polar Pattern（坐标原点在声源处，0 度方向同声源正方向）。在使用 PICO SDK 时，我们可以通过设置以下参数来模拟声源指向性。
