实时预览场景
========================================
基于串流能力，你可以通过 PDC 工具在头戴上实时预览应用内场景。
*支持预览的内容
*虚拟场景
*手势追踪
*支持的操作系统
*仅支持 Windows。
*注意事项
*使用 “PICO 互联” APP 会导致 PDC 串流服务异常。因此，使用 PDC 工具前，请确保 PC 端和头戴端都已退出 “PICO 互联” APP。
*同时使用 PDC 工具和 “PICO 互联” 软件会导致 PDC 工具运行异常。因此，使用 PDC 工具前，请确保 PC 端和头戴端都已退出 “PICO 互联” 软件。
* 
*准备工作
*参考《PICO 开发者中心概览》文档，完成准备工作，包括安装 PDC 工具、为 PICO 设备开启 “开发者” 模式、连接 PICO 设备和 PC。 
*操作步骤
*Project Swan 设备
*按以下步骤，使用 PDC 工具来实时预览场景：
*下载 PICO Unity SDK (OS-6 Preview)。
*参考此文档，实时预览场景。
*PICO 4 Ultra 及其他设备
*按以下步骤，使用 PDC 工具来实时预览场景：
*下载并解压 PICO Unity Live Preview Plugin。
*你将得到一个 package.json 文件。
*使用串流线连接电脑和头戴。
*在 Unity 编辑器中打开你的项目。
*前往 Window > Package Manager > + > Add package from disk，然后导入解压插件包后得到的 package.json 文件。
*前往 Edit > Project Settings > XR Plug-in Management > PC Standalone Settings，勾选 PICO Live Preview。
* 
* 
*打开目标场景，然后点击场景上方的 播放 按钮。
* 
*PDC 界面上的设备状态将显示为 “串流中”，表明预览能力生效中，头戴将同步显示应用画面。
*问题排查
参阅《PDC 问题排查》文档。
*


PICO 4 Ultra 或 Project Swan 系列设备无此限制。

*若列表中有 PICO 选项，需取消勾选。
