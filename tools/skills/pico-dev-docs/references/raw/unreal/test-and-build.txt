调试与预览
========================================
在搭建 XR 场景文档中，你已经构建了一个简单的场景。接下来你可以通过 PICO 提供的 PDC 工具来查看场景搭建效果，方便调试。你也可以将项目打包成为 APK 文件，传输到 PICO 设备中实机运行。
*开启开发者模式
在进行调试前，你需要为 PICO 设备开启开发者模式，让你的电脑可以在 PICO VR 一体机中读取/写入数据。步骤如下：
*开启 PICO VR 一体机。
*前往 设置 > 通用 > 关于本机。
*光标移至 软件版本号 并连续点击多次，直到左侧导航栏下方出现 开发者 选项。
* 
*点击 开发者，进入开发者选项界面。
*打开右上角的 USB调试开关。
* 
* 
*预览场景
PICO SDK 不支持直接使用 UE 编辑器中的 VR 预览（VR Preview）功能。你需先下载安装 PICO 开发者中心（即 PDC 工具）和 PICO Live Preview Plugin 插件，再实时预览应用内场景。具体说明可参考实时预览应用场景。
*(可选) 配置用户权限检查
PICO 内置了版权保护机制，应用上架后，只有获得权限的用户设备才可正常使用应用。在当前的应用调试阶段（应用尚未上架），你可以使用 SDK 提供的用户权限校验模拟功能，用于开发测试。更多详情可参考启动版权验证。

如果你需要关闭开发者模式，重复步骤 1、2 的操作，直到左侧导航栏最下方 开发者 选项消失。
