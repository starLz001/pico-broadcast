成就 Demo
========================================
本文档介绍 PICO Unreal Integration SDK 提供的成就服务 Demo。要了解成就服务，查看成就文档。
*前提条件
确保你 PICO 设备的 PUI（ROM）版本为 4.8.0 及以上。
*使用说明
你可以前往 PICO GitHub 获取对应引擎版本的成就 Demo。成就 Demo 位于 Content\Maps\GameMaps\Game_Achievements 中。Demo 的图形化界面如下：
 
Demo 包含成就服务的所有接口，你可以参照以下步骤来进行接口调试。
*启动 Demo。
*获取所有成就的基础信息或用户的所有成就解锁进度：
*若点击左下角 GetAllDefinitions，所有成就的基础信息将在右侧 DefinitionData 下显示。
*若点击左下角 GetAllProgress，用户的所有成就解锁进度将在右侧 ProgressData 下显示。
* 
*获取指定成就的基础信息或用户的某个成就解锁进度：
*点击左侧的 GetDefinitions 或 GetAllProgress。
*右侧 DefinitonData 和 ProgressData 下将显示对应信息。
*在右上角 GetByName 右侧输入框输入成就名称，点击 Get。
*DefinitonData 和 ProgressData 下将显示对应信息。
* 
*更新成就进度：
*点击右下角 AddCount。根据 CurAchievementName 和输入参数，获得的执行结果将显示在 AchievementUpdate 下方。
*点击右下角 AddField。根据 CurAchievementName和输入参数，获得的执行结果将显示在 AchievementUpdate 下方。
*点击右下角 Unlock。根据CurAchievementName和输入参数，获得的执行结果将显示在AchievementUpdate下方。
* 
* 
*API 参考
成就相关 API 详情，可参考 API 文档。


pageIndex 和 pageSize 为 GetAllDefinitions 和 GetAllProgress 的参数，点击 GetAllDefinitions或 GetAllProgress 按钮后，在左侧列表中会出现按钮列表，title 为 Achievement name。

GetByName 右侧输入框可以输入多个 Name，用逗号分隔，点击 Get 后，会返回各个 Name 的对应信息。

CurAchievementName 表示当前设置的成就名称。点击左侧列表中的成就按钮将修改CurAchievementName 的值，在GetByName 右侧输入成就名称将修改 CurAchievementName 的值。
