线程优化
========================================
要优化应用性能，你可采取以下方式优化应用的 Game、Draw、和 GPU 线程。
*获取线程参数
你可以在 Unreal 编辑器中输入 stat unit 控制台指令，查看硬件渲染某一帧所需的实际时间。结合获取到的线程参数来对帧率进行分析，以便于进一步的优化。
*在非调试模式下，启动你的应用。
*按 ~ 键，然后输入stat unit 指令。
*你会看到硬件渲染某一帧所需的实际时间。
* 
*下文是对几个线程数字的解释：
*Frame：显示硬件渲染某一帧所需的总时间。
*Game：CPU 游戏逻辑线程，是 C++ 或者蓝图游戏运行的时间。
*Draw：CPU 渲染线程，是 CPU 去采取需要渲染的东西所花的时间。
*GPU：GPU 渲染当前场景所花费的时间。
详情参考VR 性能测试。
*优化 Game 线程
*减少资源占用较大的程序：如 Forloop、GetallActorsOfClass、SpawnActor 和 Tick。如有必要使用时，遵循以下规则来减少开销：
*ForLoop：涉及循环尤其是多重循环时，及时中断循环。
*SpawnActor：在生成 Actor 时，需要占用当前平台的 IO 接口，因此会占用很多资源。如果你需要在运行以上程序时，频繁生成 Actor，可以把场景中的 Actor 保存在缓存池中。
*Tick：用它来调用复杂算法或运算时，尽量使用 C++ 来完成这个复杂运算，即将复杂计算那部分移到 C++ 里实现，然后把它作为函数公开给蓝图，再让 Tick 调用。
*适当使用软引用（Soft Reference）
*软引用即对象 A 通过间接机制（例如字符串形式的对象路径）来引用对象 B。它有如下优点：
*可以减少加载负担，缩短程序启动时间。
*不会主动加载到内存中，仅在需要时加载，用完释放内存。
* 
更多信息，参考游戏运行的性能分析和如何改善虚幻引擎中的游戏线程 CPU 性能表现。
*优化 Draw 线程
以下几点因素将影响绘制调用时间：
*模型数量：模型数量太多，会导致性能下降。建议进行模型合并来减少模型数量（合并前一定要考虑物品剔除是否方便）。
*材质数量：灵活运用材质实例，尽量减少母材质数量，从而缩减绘制调用开销。除此之外，你还可以参考 按图元存储自定义数据，来减少绘制调用时间。
*Actor 中的组件数量：尽量缩减 Actor 中的组件（Component）数量。各类组件的应用，参考组件。
*SceneCaptureActor 的调用：SceneCaptureActor 主要用于场景反射捕捉（小地图的制作、镜子模拟、三维背包、场景截图等等），建议尽量不要调用。若有需要，注意控制生命周期，减少模型面数。参考反射内容示例。
*优化 GPU 线程
以下几点因素将影响显卡渲染时间：
*着色器的复杂程度：在虚幻引擎里，着色器（Shader）的复杂程度主要与材质挂钩。尽量减少材质球内的函数节点，尽量使用不透明的材质。在性能开销上，不透明的材质 < 蒙版材质 < 透明材质。
*模型的面数：在保证显示的情况下，可以参考 减少模型面片&顶点数 中的方法给模型减面。
*灯光的调用：允许的灯光数量将直接影响 GPU 的工作量，因为每次灯光接触时，场景中的每个对象都必须渲染。建议尽量减少不必要的灯光存在，并且保证灯光均匀分布且不重叠。
更多 GPU 分析与优化细节，参考 GPU 分析。
