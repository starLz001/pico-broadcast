透视背景下实现半透明效果
========================================
在透视（Seethrough）背景下，半透明物体如果不经过处理，通常无法正常显示。本文档介绍如何在透视背景下实现物体的半透明效果。
*透视画面与虚拟场景的合成方式
要实现半透明效果，你需要先了解透视的画面与虚拟场景的合成方式。
在透视画面与虚拟场景合成时，透视画面的纹理会通过 PICO SDK 的合成服务与引擎渲染到 Eye Buffer 的画面进行合成。合成过程中，透视画面图像会覆盖 Eye Buffer 中每个 Alpha 通道值为 0 的像素。由于 Eye Buffer 中 Alpha 通道值默认为 1，因此通常需要实现一个“抠洞”材质，即在材质中留出空白，对材质开启 Write Only Alpha 选项，确保材质中的 Alpha 能够写入 Eye Buffer。之后，将材质应用于场景中的面片或者天空球中，与透视画面进行合成，以显示透视画面。
*实现半透明效果方式
要实现场景元素与透视背景的半透混合效果，同样需要将场景元素的 Alpha 值通过 Write Only Alpha 选项写入到 Eye Buffer 中。但需要注意的是，勾选 Write Only Alpha 选项后，该材质将不再向 RGB 通道写入数据。因此，你需要额外实现一个材质来向 RGB 通道写入数据。最终，你需要两个材质来实现半透混合效果，材质一负责写入 RGB 通道相关数据，材质二负责写入 Alpha 通道数据。
 
*实现示例
*本小节提供实现半透明网格体和实现半透明 Niagara 粒子特效的示例和步骤。
*实现半透明网格体（Mesh）
 
*透视背景下半透明手柄效果演示
对于网格体，你同样需要通过两个材质分别实现 RGB 通道和 Alpha 通道的写入。以下为实现半透明 Skeletal Mesh 的步骤。
*在 UE 编辑器中，找到需要设置 Alpha 通道写入的材质，在材质编辑器的细节面板中，勾选 Write Only Alpha 选项。
* 
*选择要实现半透明效果的 Skeletal Mesh，复制该 Mesh。
* 
*在细节面板的 Transform 选卡下，将复制的 Mesh 的 Scale 设置为 1.01。复制的 Mesh 略大于原 Mesh 是为了防止两个 Mesh 完全重合引起的渲染瑕疵。
* 
*对复制后的 Mesh 添加 Alpha 通道写入的材质。
*
