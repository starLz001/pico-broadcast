成就-平台接入
========================================
使用 “成就” 服务前，你需要在 PICO 开发者平台上为你的应用创建成就，并根据实际需求配置成就参数字段。
*前提条件
创建排行榜前，你需要先为 UE 项目配置平台服务。参考配置平台服务。
*创建成就
你可以在 PICO 开发者平台上为应用创建一个或多个成就，并根据实际需求配置成就参数。步骤如下： 
*登录 PICO 开发者平台。
*在 我的应用 页面上，点击目标应用卡片，进入其 概览 页。
* 
*在左侧导航栏中，点击 平台服务。
*你将前往 PPS 开发平台。
*在左侧导航栏中，点击 成就。
*你将进入成就管理面板。
*点击 创建成就。
*你将进入成就配置面板。
* 
*选择成就所应用的地区。
*配置成就。字段说明如下： 
**
*点击页面底部的 保存 或 提交 按钮：
*若点击 保存 按钮，成就将进入 “草稿” 状态，可以再次编辑；
*若点击 提交 按钮，成就将进入 “审核中” 状态，无法再次编辑。 
*（可选）为成就添加语言
*你可为成就的显示名称、简介和解锁后的简介添加多语言版本，步骤如下：
*点击 +添加语言，添加所需的语言。
*点击每个语言标签，输入成就信息。
*如果需要批量导入多语言版本信息，使用以下步骤：
*点击右上角的 下载CSV模板 按钮，下载表格模板。
*在模板中填入相应的多语言版本信息，然后删除表格内不需要的多语言行。
*点击 导入CSV 按钮，将填写好的表格上传至平台。
*（可选）归档成就
你可在成就页面归档已发布的成就，也可再次激活已归档成就。步骤如下： 
*点击 归档，归档已发布成就。归档后，相关成就及用户的成就进度不会被删除，但接口会过滤掉已归档成就，使其对用户不可见。 
*点击 激活，重新启用已归档成就。

确保你选择应用的 APP ID 与你在 UE 编辑器上为你应用项目设置的 APP ID 一致。



字段

说明

显示名称

成就在玩家端的名称。如等级新手、战力新手等。

简介

成就介绍，可描述如何解锁该成就。

解锁后的简介（可选）

用户解锁成就后看到的介绍。

API Name 

成就的唯一标识，即接口中涉及的 Name 参数。 

成就类型

包括以下三种类型：
*简单：事件类成就。以单个事件的完成度为解锁标准，完成该事件则可解锁对应的成就。
*计数：当计数器达到目标定义值时，则可解锁对应成就。
*完成率：须定义一个目标任务完成数和任务总数，当玩家的实际任务完成数达到目标任务完成数时，即可解锁对应成就。

数据写入权限

指定数据写入权限：
*客户端可写入：客户端和服务端都可以写入数据。 
*仅服务端可写入 ：只有服务端可以写入数据。 

是否隐藏 

勾选后，该成就的一切信息都对用户不可见，仅当用户解锁该成就后才会向其展示。 

是否启用通知 

勾选后，若用户解锁成就，则会在应用内和通知中心收到通知。成就解锁图示可前往成就解锁通知查看。

解锁后的图标（可选） 

成就解锁后，用户在应用内看到的图标。 

未解锁图标（可选） 

成就未解锁时，用户在应用内看到的图标。例如，可以将解锁后的图标颜色修改为灰色或加上深色蒙板，作为未解锁图标。
