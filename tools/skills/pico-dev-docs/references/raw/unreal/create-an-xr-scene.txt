搭建 XR 场景
========================================
本文档介绍如何搭建一个简单 XR 场景。在这个场景中，你将学习如何添加一个蓝图 Pawn 类。Pawn 是一种可以被“控制”的 Actor，且可以接收来自控制器的输入。要了解更多信息，参考 UE 官方文档 Pawn。
*当你将项目打包安装至 PICO VR 设备后，你的相对位置会根据设备头戴和手柄输入实时刷新，完成头部跟踪、手柄跟踪与立体渲染。
*前提条件
开始搭建场景前，你已在 UE 项目中导入 PICO SDK 并完成项目配置。
*添加 PICO SDK 内置的 Pawn
*PICO SDK 内有 BP_PICO_XR_Pawn 的 Pawn 类，该 Pawn 类下有一个摄像机组件（Camera）和两个手部组件（Hand Component）。SDK 会自动使摄像机和手部组件绑定 VR 设备输入。你可参考以下步骤在你的项目中添加 BP_PICO_XR_Pawn。
*在内容浏览器右下角，点击 View Options。在出现的下拉列表中，勾选 显示插件内容。
* 
*在左下角项目文件夹下，选中 PICOXR Content，将 BP_PICO_XR_Pawn 拖入场景中。
* 
*在右侧 细节（Details） 面板的 Pawn 选卡下，将 自动控制玩家（Auto Possess Player） 设为 玩家 0（Player 0）。
* 
*添加自定义的 Pawn
*如果你想自定义一个 Pawn 自行添加摄像机组件和手柄模型，可参考以下步骤添加一个自定义 Pawn 类。
*在编辑器左下角 内容浏览器（Content Browser） 的 内容（Content）目录下，点击 添加/导入（Add/Import） > 蓝图类（Blueprint Class） > Pawn。
* 
*Pawn 将会出现在内容文件夹内。
*将 Pawn 拖入场景。
* 
*在右侧 细节（Details） 面板的 Pawn 选卡下，将 自动控制玩家（Auto Prossess Player）设为 玩家 0（Player 0）。
* 
*添加摄像机组件
*你需要自行为新建的 Pawn 类添加摄像机组件（Camera），使 Pawn 接收来自摄像机组件的输入。参考以下步骤添加一个摄像机组件。
*选中新建的 Pawn 类蓝图，在 UE 编辑器右侧 细节（Details） 面板下，点击 添加组件（Add component），在搜索框中，输入“场景组件（scene）”，然后点击将其添加到 DefaultSceneRoot 下。
*选中 Scene，点击 添加组件（Add component），在搜索框中，输入“摄像机组件（Camera）”，然后点击将其添加到 Scene 下。
* 
*添加手柄模型
Pawn 也可以接收来自手柄（Controller）的输入。在新建的 Pawn 中，你可添加 PICO 为你提供的默认手柄模型，也可以使用你自定义的手柄模型，如枪、法杖、拳套等等，使玩家有更多的沉浸感。参考以下步骤添加手柄模型来操控 Pawn。
*选中新建的 Pawn 类蓝图，在左侧 组件（Components）面板下，选中 Scene，点击 添加组件（Add component），在搜索框中输入“运动控制器组件（Motion Controller）”，添加到 Pawn 的组件目录下。你需添加两个组件，并将其命名为 MotionController_R 和 MotionController_L，分别代表右手柄与左手柄的运动控制器。
* 
*分别选中两个运动控制器（下图以 MotionController_L 为例），在下方 运动控制器（Motion Controller） 选卡下，将 运动源（Motion Source） 设置为对应的手柄输入。
* 
*分别选中两个运动控制器（下图以 MotionController_L 为例），点击 添加组件（Add component）。
* 
*根据 PICO 设备型号和实际需求，在搜索框中输入 静态网格体组件（Static Mesh）或 骨骼网格体组件（Skeletal Mesh），将其分别添加至 MotionController_R 和 MotionController_L 下，并自定义命名。
* 
* 
*分别选中两个网格体组件，在右侧 细节（Details）面板的 网格体（Mesh）选卡下，点击 静态网格体（Static Mesh） 或 骨骼网格组件（SkeletalMesh） 右侧下拉菜单，选择手柄模型。下图以 PICO 4 为例。
* 
* 
*手柄模型本身的枢轴位置不一定在模型中心，所以在添加完模型后，你需要要按照实际位置来调整手柄模型在 Pawn 中对于父组件 运动控制器组件 的相对位置，使模型位置处于父组件 运动控制器组件 的原点，且旋转朝向父组件正方向即可。
* 
*此时，你已经搭建好了一个简单的 XR 场景。你可以参考调试与预览文档通过 PICO 提供的 PDC 工具来查看场景搭建效果，方便调试。你也可以参考打包与安装文档将项目打包成为 APK 文件，传输到 PICO 设备中实机运行。

*如果在下拉菜单中，没有 PICO 相关网格体。你需在内容浏览器右下角，点击 View Options。在出现的下拉列表中，勾选 显示插件内容（Show Plugin Content）。
