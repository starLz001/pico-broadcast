成就-核心概念
========================================
要使用成就服务，你需要了解以下相关概念。
*成就标识
成就标识指你在开发者平台创建成就时，为该成就设置的 API Name。在获取成就信息、解锁成就进度时，你可以根据 API Name 指定某个成就。
*成就类型
你可以在 PICO 开发者平台上为应用创建以下类型的成就： 
*
*隐藏成就 
隐藏成就的一切信息对用户不可见，仅当用户解锁该成就后才可看到相关信息，可以为用户带来惊喜体验。在 PICO 开发者平台上创建成就时，你可以选择是否将该成就设置为隐藏成就。
*成就解锁通知
在开发者平台创建成就时，你可以选择是否启用成就解锁通知。开启后，若用户解锁成就，则会在应用内和通知中心收到通知。成就解锁通知图示如下：

场景示例

简单

即事件类成就。以单个事件的完成度为解锁标准，完成该事件则可解锁对应的成就。

完成新手教程后，即可解锁一个简单成就。 

计数

当计数器达到目标定义值时，则可解锁对应成就。

总击灭敌方数达到 100 后，即可解锁一个计数类成就。 

完成率

须定义一个目标任务完成数和任务总数，当玩家的实际任务完成数达到目标任务完成数时，即可解锁对应成就。

收集 10 个宝石中的任意 7 个即可解锁一个完成率成就。
