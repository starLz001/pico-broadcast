硬件和软件规格要求
========================================
要在 PICO 设备上开发应用，你需要了解开发所需的硬件和软件规格要求。本文档主要使用 PICO SDK 开发 XR 应用所需的硬件和软件规格要求。要了解使用虚幻引擎开发的环境要求，参考 UE 官方文档硬件和软件规格。
*计算机
*推荐使用 Windows10 操作系统作为 PICO XR 应用的开发环境。部分工具或功能（例如：PDC 工具）需在 Windows 10 上才能运行。PC 系统配置要求如下：
*CPU：Intel i5-4590 / AMD Ryzen 5 1500X 或更高 
*显卡：NVIDIA GTX 1060 / AMD Radeon RX 480 或更高
*RAM：8 GB 或更高 
*端口：USB 3.0
*软件要求
*以下为开发 PICO 应用所需的软件及其要求。
**
*PICO 设备
*PICO Unreal Integration SDK 支持开发运行在 PICO 设备上的应用，包括 PICO Neo3 系列、 PICO 4 系列以及 PICO 4 Ultra。其中，不同 SDK 版本对设备系统版本要求不同；具体功能对设备的型号要求可能有所不同。
*型号
*下表为 SDK 各功能对 PICO 设备型号的具体要求。√ 表示支持该设备型号，ⅹ 表示不支持。
*
*系统版本
*建议将系统版本升级至最新版本。可在 PICO 设备中，前往 设置 > 通用 > 系统版本 查看设备系统版本。 
**

*要求

虚幻引擎

PICO Unreal Integration SDK 适用的游戏引擎。

支持 UE 4.27、5.5 和 5.6。

操作系统

*点击此处下载 Windows 10 操作系统。 

目前 PICO SDK 尚未支持 macOS 操作系统。推荐使用 Windows10 操作系统作为 PICO XR 应用的开发环境。部分工具或功能（如 PDC 工具）需在 Windows 10 上才能运行。

Visual Studio

Visual Studio 提供了适用于 Windows 的集成开发环境（IDE），你需要用该工具编写、调试、测试、部署代码，安装该工具是成功编译打包项目的必要条件。点击此处下载。

参考 UE 官方文档设置 Visual Studio 查看不同引擎版本所需的 Visual Studio 版本要求。
注意：安装 Visual Studio 2017 及以上版本时，在 工作负载 选项卡下，移动到 游戏 部分，必须勾选 使用 C++ 的游戏开发。

Android Studio

Android Studio 用于虚幻引擎安卓项目的开发、编译与打包，贯穿整个项目开发流程。点击此处下载。

参考 UE 官方文档 Android 开发要求选择合适的 Android Studio 版本，参考设置虚幻的Android SDK 和 NDK 配置环境。建议使用 arm64-v8a 作为打包选项。
