账号&好友 Demo
========================================
本文档介绍 PICO Unreal Integration SDK 提供的账号&好友服务 Demo。要了解账号&好友服务，查看账号&好友文档。
*前提条件
确保你 PICO 设备的 PUI（ROM）版本为 4.8.0 及以上。
*使用说明
你可以前往 PICO GitHub 获取账号&好友 Demo。账号&好友 Demo 位于 Content\Maps\WindowMaps 中。Demo 的图形化界面如下：
 
*Identity (账号)
点击 IdentityLogin 或 PicoGetUser，Pico Nickname 和 Pico User ID 字段将展示目前登录的用户昵称和 UserID。
 
*Friend (好友)
*点击 ReadFriendList 以读取 Default 字段好友列表。
*点击 SelectFriend 下拉菜单，将展示所有好友昵称。
*选择好友后， Select Friend ID 字段将展示好友的 UserID。
* 
*用户权限
*点击 GetAuthorizePermissions 获取用户已授予当前应用的权限列表；
*点击 RequestUserPermissions，在 Permission 右侧点击 +，在 Permissions List 处输入要申请的权限，包括 user_info，friend_relation，sports_userinfo，sports_summarydata，然后点击 RequestUserPermissions 向该用户申请。
* 
*API 参考
*账号功能相关 API 详情，可参考 API 文档。
*好友功能相关 API 详情，可参考 API 文档。
