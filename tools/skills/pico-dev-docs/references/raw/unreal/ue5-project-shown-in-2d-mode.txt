为何 UE5 项目在 PICO 设备中显示为 2D 模式？
========================================
如果你的 UE5 项目打包后，在 PICO 设备上以 2D 模式运行，同时出现以下弹窗，这可能是因为你的 UE5 项目为蓝图项目。
* 
你需参考以下步骤将你的蓝图项目转为 C++ 项目：
*在编辑器左上角，点击 工具（Tools） > 新建 C++ 类（New C++ Class）。 
* 
*在 添加C++类（Add C++ Class） 弹窗中，直接点击 下一步（Next）> 创建类（Create Class）。 
* 
*你已将该项目转换为 C++ 项目。
