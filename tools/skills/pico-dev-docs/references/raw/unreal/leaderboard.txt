排行榜-概述
========================================
PICO Unreal Integraion SDK 提供应用内排行榜的相关能力。该能力可多维度展示用户游戏排名，实现玩家间趣味性竞争，从而提升玩家活跃度。本文档介绍 PICO SDK 排行榜服务的应用场景、主要功能和相关概念。
*应用场景
排行榜有以下多个应用场景：
*竞技对抗：玩家可以通过排行榜查看竞争排名，激发竞争心态。
*社交互动：玩家可以在排行榜中查看自己在好友或全球范围内的排名，与其他玩家交流切磋，组队合作。
*数据分析：你可以通过排行榜获取玩家游戏数据并分析，了解玩家行为模式和趋势，从而获得游戏与应用优化和改进的方向。
*主要功能
PICO 排行榜服务主要提供创建排行榜、获取排行榜数据、更新排行榜数据等功能。
*创建排行榜
*你可以在 PICO 开发者平台为应用创建排行榜。
*获取排行榜信息和条目数据
*你可以调用相关接口获取排行榜显示名称、排序方式、数据统计周期、总条目数等信息。 
*你也可以调用相关接口获取具体条目数据。每个排行榜都由一系列条目数据组成。单个条目对应单个玩家在应用中的排名、最佳成绩等数据。
*更新排行榜条目
*当玩家在应用内获得新的成绩时，你可调用相关接口更新该玩家在排行榜中的条目数据。
*相关概念
要使用排行榜服务，你需要了解以下相关概念。
*排行榜标识
排行榜标识指你在开发者平台创建排行榜时，为该排行榜设置的 API Name。在获取排行榜信息、更新排行榜条目时，你可以根据 API Name 指定某个排行榜。
*排行榜条目
单个排行榜条目对应单个玩家在应用中的排名、最佳成绩等数据。每个玩家在一个排行榜中仅拥有一个条目，条目与用户 ID 关联，默认保留和展示用户的最好成绩。
*关联 Destination
在真实世界中，人们的社交活动通常需要一个具体的聚会场所，例如餐馆、音乐厅等。在 VR 应用里，这种聚会场所被称为 Destination，即跳转目的地。Destination 可以是游戏大厅、游戏关卡、房间等地点。
你可在 PICO 开发者平台中为应用创建多个 Destination。创建排行榜时，你可以选择为该排行榜关联某个 Destination。关联后，用户可通过排行榜跳转至所关联的 Destination，你需要自行为排行榜 UI 设计跳转按钮。
*好友超越通知
在开发者平台创建排行榜时，你可以选择是否为该排行榜开启好友超越通知。开启后，当某一玩家的排名被其好友超越时，该玩家将在设备端的通知中心收到通知。玩家点击该通知后：
*若该排行榜关联了某个 Destination，并且你已经为排行榜 UI 设计了跳转按钮，系统会启动相关应用并进入对应的 Destination； 
*若该排行榜未关联某个 Destination，系统会启动相关应用并进入应用首页。
