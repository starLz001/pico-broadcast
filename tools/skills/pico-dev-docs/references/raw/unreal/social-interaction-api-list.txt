备注

PresenceSet

设置用户的所有 Presence 信息，包括 Destination、可加入状态、Lobby Session ID、Match Session ID 和额外信息。

-

PresenceSetDestination

设置用户的 Destination。

-

PresenceSetIsJoinable

设置用户的可加入状态。

-

PresenceSetLobbySession

设置用户的 Lobby Session ID。

-

PresenceSetMatchSession

设置用户的 Match Session ID。

-

PresenceSetExtra

设置用户额外的 Presnece 信息。

-

PresenceClear

清空用户的 Presence 信息。

-

ReadInvitableUser

获取可邀请好友。

-

LaunchInvitePanel

邀请好友加入应用内的某个位置。

三个接口皆使用 “好友” App 提供的系统默认邀请面板。

SendSessionInviteToFriend

邀请好友加入私人房间。



Invite

邀请好友加入挑战。



PresenceSendInvites

邀请好友加入应用内的某个位置。

三个接口皆使用自定义邀请面板。

Room->InviteUser

邀请好友加入私人房间。



Challenges->Invite

邀请好友加入挑战。



*PresenceReadSendInvites
*GetSendInvitesList
