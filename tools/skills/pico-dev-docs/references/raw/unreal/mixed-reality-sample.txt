混合现实示例
========================================
PICO 混合现实示例是面向开发者提供的技术示例项目，展示了 PICO Unreal Integration SDK 混合现实相关功能，包括视频透视、场景标定、空间网格、空间锚点。你可以在示例中体验锚点创建、发射小球等简单示例场景。此外，房间标定示例场景，你可以在 Unreal 编辑器中通过模拟数据体验混合现实功能，或打包单独的场景进行体验。
*开发环境 
*SDK 版本：3.2.0 及以上 
*PICO 设备：PICO 4 系列和 PICO 4 Ultra 系列
*PICO 设备系统版本：5.12 及以上
*Unreal Engine 版本：5.4 及以上
*工程配置 
*
*GitHub 仓库 
你可以前往 PICO 开发者 GitHub 上的 MRSample-Unreal 仓库，克隆示例项目。该项目包括源代码脚本、艺术资产和其他资源。

*房间标定示例

将 BeginPlay 连接至 Preview 逻辑，在 Editor 中点击 Play 按钮即可进行离线模拟数据预览。
* 
将 BeginPlay 连接至 Runtime 逻辑，则可以打包 APK，安装至头戴运行。
