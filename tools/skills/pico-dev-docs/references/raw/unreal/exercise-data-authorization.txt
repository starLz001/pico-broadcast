运动数据授权
========================================
“PICO 运动”是 PICO VR 一体机的内置应用，用于采集用户使用 PICO 设备时所产生的运动数据，包括运动时长、运动消耗、应用偏好等。此外，用户可通过 PICO 运动来制定和管理运动计划。
* 
运动数据授权服务提供了从 “PICO 运动” 获取用户运动数据的接口。你可以通过 PICO 运动数据来分析用户的运动情况，从而为用户提供更好的定制化体验。
*基本概念
*
*功能说明
*获取用户授权
调用运动数据授权相关接口需要获取用户授权。若未取得授权，调用接口时，调用接口时会弹窗提示用户进行授权。你可以调用 RequestUserPermissions 来向用户申请访问其运动中心数据的权限，也可以调用 GetAuthorizePermissions 来查看已获得的权限列表。
*获取基础信息和运动计划
调用 GetSportUserInfo 来获取用户的基础信息和运动计划信息，包括：性别、年龄、身高、体重、运动级别、计划每日运动时长、计划每周运动天数、运动目标。
*获取今日运动数据
调用 GetSummary 获取 最近 24 小时内 任意时间段（查询的起始时间距离当前时间不得超过 24 小时）产生的运动数据，包括实际运动时长和实际消耗卡路里。
*获取每日运动数据
调用 GetDailySummary 来查询用户 最近 90 天内 任意时期（查询起始时间不得早于 90 天前）产生的每日运动数据，包括实际运动时间、计划运动时间、计划卡路里消耗量和实际卡路里消耗量。
*准备工作
使用运动数据授权服务前，需完成以下准备工作。
*申请权限
运动数据授权服务目前为实验性功能。若想使用该服务，需向 PICO 团队提交应用 ID 进行权限开通。开通权限后，方可使用。
*完成前期配置
详细步骤，参考配置平台服务。
*Demo
*前置条件
确保你 PICO 设备的 PUI（ROM）版本为 4.8.0 及以上。
*使用说明
你可以前往 PICO GitHub 获取对应引擎版本的运动数据授权 Demo。运动数据授权 Demo 位于 Content\Maps\WindowsMaps 中。Demo 的图形化界面如下：
 
*点击 GetSportUserInfo 按钮，来获取用户的基础信息和运动计划信息。
*获取用户今日的运动数据汇总： 在 BeginTime and EndTime 右侧输入框填入起止时间范围（不超过 24 小时），然后点击 GetSummary。
*获取用户某段时期内的每日运动数据汇总： 在 BeginTime and EndTime 右侧输入框填入起止时间范围（不超过 90 天），然后点击 GetDailySummary。

概念

说明

运动中心

PICO 系统的内置应用，帮助用户管理运动计划。

运动计划

用户在运动中心设置的运动计划，包括运动时长、卡路里目标、每周运动天数等。

运动级别

用户的运动强度偏好，分为“低”、“中”、“高”三个级别。

运动目标

用户想要达到的运动目的，目前有“减脂”和“保持健康”两个选项。
