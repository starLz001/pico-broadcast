应用设计优化
========================================
当前，针对 PICO 应用有以下优化方法：
*在保证显示的情况下，减少面数&顶点数。
*尽量共用材质、动画。
*尽量使用压缩纹理格式。
*尽量使用静态批处理。
*尽可能少地使用灯光特效。
*脚本优化，减少不必要的内存、计算等资源消耗。
*使用 LOD/HLOD 进行性能优化。
下文将对以上优化方法进行详细说明。更多优化方法，参考 Epic 官方文档测试并优化你的内容与移动端的渲染优化技巧。
*优化模型导出与加载
*对于体量比较大的模型，你可以将模型分批量导出成若干个小容量模型。
*对于移动端 VR 应用，你可以分批加载模型，以减少延迟等待，也方便后期做局部修改。分批加载模型资产的方法，参考资源注册表。
*减少模型面数&顶点数
建议在保证显示的情况下，减少模型面数、顶点数。参考以下优化方式。
*删除场景中多余的面
看不见的地方可不用建模，看不见的面也可以删除，例如：紧贴地面的静态 Box 的底面、物体紧贴墙壁的表面等。这样可以降低整个场景的面数、提高贴图利用率，从而提高交互场景的运行速度。
 
*使用专业工具进行面数优化
为了降低成本、提高效率，建议使用减面工具，保证由工具自动化完成优化。推荐使用以下减面工具：
*InstaLOD 模型优化工具
*InstaLOD 提供了制作和自动优化 3D 内容所需的一切工具。InstaLOD 有独立程序，以插件的形式支持 3dsmax、Maya、Unity、Unreal、Blender。详情参考此处。
* 
*Polygon Cruncher
*Polygon Cruncher 可在保持模型精度的前提下，尽量减少模型的面数。点击 此处 下载。
* 
*优化材质与贴图/纹理
此部分介绍如何从贴图和纹理层面对 PICO 应用进行优化。通用优化指南，参考写给美术师和设计师的性能指南和移动平台的纹理。
*优化贴图尺寸
*贴图的尺寸必须为 2 的 N 次方。因为 OpenGL 仅支持分辨率为 2m*2n 的纹理；非 2 的 N 次方的图片会被强制转化为 2 的 N 次方的图片，该转化过程十分耗时。
*一般情况下，移动端 VR 的贴图尺寸使用 512*512，最好不要超过 1024*1024。你也可以在保证贴图尺寸必须为 2 的 N 次方的前提下，将大尺寸贴图优化为更小尺寸的贴图。
*选取纹理压缩格式
纹理压缩（Texture Compression）可以减少任何时候需要加载的纹理数据量和运行中的纹理数据总量，从而减少加载用时和内存占用，提升性能。你可以根据纹理贴图的作用以及特性来选择对应的纹理压缩格式。详细说明，参考纹理压缩设置。
*合并纹理
为了更好地提升移动端 VR 应用的性能、节省内存，你可以通过以下步骤对贴图进行合并：
*将不同的贴图信息分别保存在 RGBA 通道中（例如，R 通道保存金属度贴图、G 通道保存高光度贴图、B 通道保存粗糙度贴图、Alpha 通道保存环境光遮挡贴图）。
*按需将不同的通道组合。

*按图元存储自定义数据
使用 自定义图元数据（CPD） 工作流时，利用材质将自定义数据存储在可通过蓝图和代码访问的索引数组中，以影响场景图元的修改。其功能与动态材质实例类似，可在应用运行时通过标量和向量参数动态控制材质图表的各部分。区别在于，CPD 的优势是将数据存储在图元自身而非材质实例上，减少了关卡中类似几何体（如墙壁、地板或其他重复几何体）的绘制调用次数。详细步骤，参考在材质中按图元存储自定义数据。
*优化灯光和特效
本部分介绍如何从灯光和特效的角度优化 PICO 应用。更多虚幻引擎光照应用与细节详解，参考光照环境。
*尽量不使用动态灯光
打开动态灯光可以直观提升阴影和反射，但会让场景处于一个非常不稳定的状态，损失很多性能。
*用视频特效代替粒子特效
*如果粒子特效一直占用画面只是为了烘托场景气氛，建议使用视频、动画类资产（比如，用 Media Texture 直接播放视频，或制作模拟粒子效果的二维材质）来代替粒子特效，以减小对场景的性能消耗。在视频特效中，你只需要把视频特效分为黑、白蒙版跟正常特效，并在材质中做一个切割，把它变成一个透明的材质。此外，取消 HDR 和 ES3.1 用户端渲染对视频特效的影响很小。
*尽量不要使用粒子去模拟雾效。
*减少绘制调用
建议使用 分层细节级别（HLOD） 系统减少绘制调用。
*什么是 HLOD？
HLOD（Hierarchical Level of Detail）系统可以使用单个经过合并的静态网格体 Actor 替换远距离上多个静态网格体 Actor，有助于减少场景中需要渲染的 Actor 数量。
*HLOD 功能
*生成集群（Clusters）；
*生成代理网格体（Proxy Meshes）。
*注意事项
*HLOD 适合静态物体的合并，无法很好支持破坏的物体的合并。
*HLOD 系统自带的一键分组功能会自动对场景中的网格体进行划分和代理网格体生成。但有时会把相距较远的网格体划为一组，反而降低了性能。因此：
*尽量不使用下图 HLOD 系统界面的 Generate Clusters 一键分组功能。
* 
*建议手动将需要的物体拖到 HLOD Window 中，然后生成代理网格体。
*HLOD 生成的新网格体在视觉上或多或少都会与原物体有区别。降低屏占比可以减少视觉效果的区别。你可以根据实际的视觉效果来自行调整 Transition Screen Size 的值，以达到满意的视觉效果，推荐数值 0.2。
* 
*为了提升绘制调用的优化效果，生成时务必勾选 Merge Materials（合并材质）（该选项默认已勾选）。
* 
更多 HLOD 的详细用法，参考 HLOD 使用指南。
