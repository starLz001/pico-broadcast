账号&好友
========================================
账号&好友服务提供了账号获取、社交关系管理等功能，包括获取指定账号信息、获取当前登录用户的好友列表、发送好友申请等。参考 Unreal 官方文档：身份接口和好友接口。
*基本概念
*
*应用场景
*使用 PICO 账号授权登录
在应用中获取系统中已登录的 PICO 账号，实现授权登录，而无需在应用内单独实现注册、登录等功能；若用户首次打开应用，未在系统中未登录任何 PICO 账号，会调起授权登录。
账号授权登录时会进行应用包签名校验，只有已在 PICO 开发者平台上传版本的应用才能够获得账号授权，要了解如何为应用上传版本，参考上传版本。
*使用 PICO 账号获取好友列表
在应用中获取系统中已登录的 PICO 账号的好友列表，可查看好友在线状态、邀请好友一起玩。
*在应用里添加好友
在应用中发送交友邀请，对方接受后即建立好友关系。互为好友的玩家可在 PICO 好友 App 中聊天。
*用户授权管理
你可通过调用 API 查询用户已授权的权限列表，或向用户申请授权。部分接口需要用户授权才能访问，未经授权访问会返回错误信息。
*功能说明
*申请权限和查看已获取权限
调用账号&好友相关接口需要获取用户授权，你还可以查看已从用户处获取的权限，参考下表中的接口。
*
调用 RequestUserPermissions 可以申请的权限包括以下 5 个。其中权限枚举指你在虚幻引擎中调用接口时需要输入的字符串参数。
*
*获取用户信息和好友列表等
获取用户授权后，你可以调用以下接口获取用户信息和好友列表、发送好友申请、查询社交关系等。

*Identity (账号)

*点击 GetAuthorizePermissions 获取用户已授予当前应用的权限列表；

术语

说明

PICO 账号

可在 PICO 官网、PICO VR 一体机、PICO VR 助手 中登录的账号。用户可实现自定义昵称、头像等操作。

openID

基于 PICO 账号授权生成的用户唯一标识。每位用户在不同应用（app_id）中的 openID 是唯一且固定的。

AccessToken

基于 PICO 账号和 APP ID 生成的 Token。验证成功的 Token 可以访问 PICO SDK 提供的服务，如游戏服务。

用户授权

应用访问用户私有数据时需要向用户申请授权，授权权限包括个人信息、好友信息、运动数据等。

void UPicoGameInstance::PicoLogin(FString LocalUserNum, FString InType, FString ID, FString InToken)
{
    if (IdentityInterface.IsValid())
    {
        FOnlineAccountCredentials Credentials;
        Credentials.Id = ID;
        Credentials.Token = InToken;
        Credentials.Type = InType;
        IdentityInterface->OnLoginCompleteDelegates->AddUObject(this, &UPicoGameInstance::OnLoginComplete);
        IdentityInterface->Login(0, Credentials);
    }
}

PICOUserInterface = PICOSubsystem->GetPICOUserInterface();
GetAccessTokenDelegate.BindDynamic(this, &UPICOGameInstance::OnGetAccessTokenComplete);
PICOUserInterface->GetAccessToken(GetAccessTokenDelegate);

void UPICOGameInstance::OnGetAccessTokenComplete(bool bIsError, const FString& ErrorMessage, const FString& AccessToken)
{
    if (bIsError)
    {
        UE_LOG(LogTemp, Error, TEXT("OnGetAccessTokenComplete Failed : %s"), *ErrorMessage);
    }
    UE_LOG(LogTemp, Display, TEXT("OnGetAccessTokenComplete AccessToken : %s"), *AccessToken);
}
