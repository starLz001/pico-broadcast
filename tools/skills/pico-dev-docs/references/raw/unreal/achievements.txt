成就-概述
========================================
成就指玩家成功达到游戏中特定目标后，作为奖励获得的可收集物品，例如奖杯、徽章等。PICO Unreal Integraion SDK 支持你定义玩家在游戏中可获得的成就，提升游戏的趣味性和玩家的参与度。
本文档介绍 SDK 成就服务的应用场景、主要功能和相关概念。
*应用场景
成就有以下多个应用场景：
*游戏激励：玩家通过成就可获得游戏一系列目标，从而在游戏中进行更多的探索和尝试。例如，完成特定任务、解锁隐藏关卡或收集特定物品等成就，可以鼓励玩家全面体验游戏内容。
*竞技对抗：玩家可以通过展示与比较彼此成就，激发竞争心态。
*社交互动：玩家可以展示自己的成就给其他玩家，与好友之间进行竞争和挑战。
*主要功能
SDK 的成就服务主要提供创建成就、获取成就数据、更新成就数据等功能。
*创建成就
  你可以在 PICO 开发者平台为应用创建成就。详见创建成就。
*获取成就信息和解锁进度
*你可以调用相关接口获取成就的基础信息，包括成就的 API Name、类型、描述、是否解锁等。
*你也可以调用相关接口获取成就的解锁进度。
*更新成就进度
  当玩家在应用内获得新的成绩时，你可调用相关接口更新该玩家在成就中的条目数据。
