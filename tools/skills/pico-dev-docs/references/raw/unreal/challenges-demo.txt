挑战 Demo
========================================
本文档介绍 PICO Unreal Integration SDK 提供的挑战服务 Demo。要了解挑战服务，查看挑战文档。
*前提条件
确保你 PICO 设备的 PUI（ROM）版本为 4.8.0 及以上。
*使用说明
你可以前往 PICO GitHub 获取对应引擎版本的挑战 Demo。挑战 Demo 位于 Content\Maps\GameMaps\Game_Challenges 中。Demo 的图形化界面如下：

编号

说明

1

用于定义 pageIndex 和 pageSize 参数。在此处可输入想查询的挑战页。

2（Options）

用于配置查询筛选条件，包括挑战所属的排行榜名称、挑战名称、挑战可见性等。

3（Challenge List）

用于展示挑战。配置完 pageIndex、pageSize 和 ChallengeOption 后，点击 GetList。系统将执行 GetList 接口，获取符合条件的挑战，并在 Challenge List 列表中以挑战 ID 的形式展示。同时，在 ExecuteResult 下将可以查看执行结果。
点击列表中的某条挑战后，系统将执行 Get 接口，获取该挑战的详细信息并在 ChallengeInfo 下展示。
点击 Join，加入指定挑战；点击 Leave，退出指定挑战。

4

用于邀请好友加入挑战。步骤如下：
1. 点击 Challenge List 中的某个挑战。
2. 在输入框中输入好友的 ID，支持输入多个。
3. 点击 Invite。
系统将执行 Invite 接口向指定好友发送邀请。同时，在 ExecuteResult 下可以查看邀请的执行结果。

5（SearchParams）

用于配置挑战条目查询条件。步骤如下：
1. 点击 Challenge List 中的某个挑战。
2. 配置查询条件。
*若配置了 afterRank，则执行 GetEntriesAfterRank，获取某个排名后的条目。
*若配置了 userIds，则执行 GetEntriesByUserIds，获取指定用户的条目。
*若未配置 afterRank 和 userIds，则执行 GetEntries，获取所有条目。

6（Challenge Entry List）

用于展示符合条件的挑战条目。点击任一条目后， ChallengeEntryInfo 下将展示该条目的详细信息。

7（ExecuteResult）

用于展示接口调用结果。
