说明

RenderDoc for PICO

RenderDoc for PICO 是一款图像分析和调试工具，可以帮助你调试应用中目标帧、追踪渲染阶段、分析绘制调用等。

PICO CLI

PICO CLI 命令行工具（PICO Command Line Utility）可以帮助你更轻松地管理 PICO 开发者平台的文件，包括：
*上传 APK、OBB文件、资源文件 
*管理 DLC 文件 
*下载 APK 文件 
*跨渠道复制 Build
