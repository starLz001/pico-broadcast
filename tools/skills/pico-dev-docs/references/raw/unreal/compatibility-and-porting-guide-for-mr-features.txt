MR 功能兼容性和迁移说明
========================================
本文为 MR 功能兼容性和迁移说明。你可以参考本文档将项目中 2.5.0 及更早版本的 MR 接口升级为 3.0.0 版本。
*相关提示
由于 SDK 3.0.0 版本中的 MR 功能重构不涉及视频透视，所以本文不讨论视频透视功能的兼容性。
*兼容性说明
以下为 PICO 4 和 PICO 4 Ultra 设备对 SDK 2.5.0 或更早版本及 3.0.0 版本中 MR 接口的支持情况。

*空间锚点功能迁移说明
以下为空间锚点功能的迁移说明。功能使用说明参考以下文档：
*2.5.0 及更早版本：空间锚点指南、API 参考
*3.0.0 版本：空间锚点指南、API 参考
*启用空间锚点能力
*在编辑器左上角，点击 编辑（Edit） > 项目设置（Project Settings） > 插件（Plugins） > PICOXR Settings。 
*移动到 Mixed Reality 选项卡下启用空间锚点能力。
