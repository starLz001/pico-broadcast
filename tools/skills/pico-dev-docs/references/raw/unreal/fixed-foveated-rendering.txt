注视点渲染
========================================
注视点渲染（Foveated Rendering） 可以优化渲染场景的能力。该技术通过为视野中心区域提供全分辨率（无损），降低边缘区域（人眼焦点区域之外）的分辨率，能够极大降低 HMD 设备的渲染负载，实现渲染优化。
*PICO SDK 支持眼动追踪注视点渲染（Eye Tracked Foveated Rendering，简称 ETFR）、静态注视点渲染（Fixed Foveated Rendering，简称 FFR）和下采样（Subsampled Layout）功能，帮助你提升应用性能和画面显示的质量。本文档介绍如何为应用开启 ETFR、FFR 和下采样功能。

以下为注视点渲染相关功能的环境要求。

*基本概念
*在人类的视觉系统中，人眼视力分为中心视力和周边视力两部分。中心视力提供精确和细节的视觉内容，周边视力提供广角视野范围的画面。两者的视敏度差别催生了 VR 领域常用的注视点渲染（Foveated Rendering）技术。 注视点渲染通过为视野中心提供无损分辨率，同时降低周边视野（人眼焦点区域之外）分辨率的方式来大幅降低计算复杂度，优化 VR 场景渲染效果。你可以通过以下说明进一步了解注视点渲染相关概念。
*静态注视点渲染（FFR）
FFR 将注视点固定在视口中心位置，通过降低周边视野清晰度，从而降低 GPU 负载，提升应用性能。
*眼动追踪注视点渲染（ETFR）
ETFR 根据眼球的注视方向动态调整注视点，以全分辨率渲染眼球注视区域的图像，以低分辨率渲染边缘区域图像。随着眼球的移动，全分辨率渲染区域也会相应地变化。
与 FFR 相比，ETFR 可以追踪用户当前真实的注视点位置，在眼球周围区域分辨率的降低上可以比 FFR 的浮动更大。因此，使用 ETFR 可以为应用降低更多 GPU 负载。以下为开启超高级等级的 ETFR 与 FFR 后的性能数据对比。数据来源于 PICO 内部测试，实际使用中可能存在误差。

*下采样
下采样是一种优化渲染技术，需与 FFR 或 ETFR 配合使用。开启下采样功能后，眼部纹理将采用下采样的布局方式，消除注视点渲染产生的视野边缘低分辨率区域的视觉伪影，提高应用性能。用户在移动时，设备的画面过渡也将更平滑流畅，从而减少眩晕感、提升沉浸感。
*使用限制
*如果你的项目使用的图形接口为 Vulkan，则必须使用 UE PICO 分支引擎版本才可使用 ETFR 功能。
*要使用下采样功能，你必须同时在编辑器中开启 Mobile Multi-View 选项。具体步骤参考多视图渲染。

*启用下采样
PICO 的下采样功能同时支持 Vulkan 和 OpenGLES 渲染接口，必须与 FFR 或 ETFR 同时使用。启用下采样功能会增加 Timewarp 的 GPU 成本。因此，建议你在启用 Med、High、Top High 等级的 FFR 或 ETFR 时再启用下采样功能。你可参考以下方式启用下采样功能。
