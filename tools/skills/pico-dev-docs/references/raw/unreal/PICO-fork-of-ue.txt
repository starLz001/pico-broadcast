虚幻引擎 - PICO 分支使用指南
========================================
虚幻引擎 - PICO 分支是 PICO 基于 Epic Games 虚幻引擎仓库 Fork 的分支仓库，正式发布了虚幻引擎 4.27、5.1、5.2、5.3、5.4、5.5 和 5.6 版本的 PICO 分支，并集成了最新版本的 PICO XR 插件。其中，虚幻引擎 4.27、5.1、5.2、5.3 和 5.4 版本的 PICO 分支均为历史版本。你可在开发 PICO 应用时使用虚幻引擎 - PICO 分支以获取最新功能。 
本文档介绍 PICO 分支提供的新特性、修复项和使用步骤。

*环境要求
*要使用虚幻引擎 - PICO 分支，你需要安装 Visual Studio。对于不同版本的引擎，你需要安装不同版本的 Visual Studio 并安装不同的组件：
* 
*使用 PICO 分支
*完成相关配置，确保你可以在 GitHub 上访问虚幻引擎源代码。具体步骤，参考在 GitHub 上访问虚幻引擎源代码。
*前往虚幻引擎 - PICO 分支仓库，切换到你需要的引擎版本的分支，然后 Fork 并克隆该分支。你也可以选择直接下载 ZIP 压缩包。
*前往源码工程根目录，运行 Setup.bat 文件下载引擎所需要的二进制文件，并安装引擎运行的先决条件。
* 
*运行 GenerateProjectFiles.bat 文件，以创建引擎所需的工程文件。
*双击 UE4.sln 或 UE5.sln 文件打开 Visual Studio 工程。
*在 Visual Studio 中，将解决方案的配置设置为 Development Editor，解决方案的平台设置为 Win64。
*右击解决方案管理器中的 解决方案 'UE4' 或 解决方案 'UE5'，然后单击 生成解决方案，开始引擎编译。
* 
*（可选）编译完成后，你可在 Visual Studio 中将启动项目设置为 UE4 或 UE5，然后按 F5 键调试 Unreal 编辑器。
*使用 SetupAndroid_AGDE 工具
SetupAndroid_AGDE.bat 是基于安卓 Android Game Development Extension（AGDE）的批处理工具，可以帮助你快速配置 UE5 的安卓开发环境，而无需安装 Android Studio。
使用 SetupAndroid_AGDE.bat 工具自动配置 UE5 的安卓开发环境的步骤如下：
*参考虚幻引擎文档下载和安装 AGDE 扩展。
*前往 PICO 5.1 分支下的 UnrealEngine/Engine/Extras/Android 目录下，找到 SetupAndroid_AGDE.bat 文件。
* 
*下载并运行 SetupAndroid_AGDE.bat 文件，即可自动配置 UE5 的安卓开发环境。

特性

支持版本

描述

*应用空间扭曲（AppSW） 

UE4.27 及以上

以实际屏幕刷新率的一半刷新率来渲染画面，而不会影响显示质量。可降低渲染延迟。

*延迟锁定（Late latching） 

UE4.27 及以上

可降低运动到光子延迟（Motion-to-Photon Latency）。 

眼动追踪注视点渲染（ETFR） 


UE4.27 及以上

根据眼球的注视方向动态调整注视点，以全分辨率渲染眼球注视区域的图像，以低分辨率渲染边缘区域图像。

自适应分辨率

UE4.27 及以上

根据眼球的注视方向动态调整注视点，以全分辨率渲染眼球注视区域的图像，以低分辨率渲染边缘区域图像。

色调映射特效（Tone mapping effects）


UE4.27 及以上


PICO 支持部分虚幻引擎提供的色调映射（Tone mapping）特效，包括颜色分级（Color Grading）、晕映（Vignette）效果、电影（Film）等。由于 PICO 是基于 Vulkan 子通道（Vulkan subpasses）而不是一个额外的渲染通道来渲染特效，因此基于虚幻引擎 - PICO 分支使用这些特效，可降低性能开销和耗时。

贴花特效（Decal Effect）支持多视图模式

UE5.3 及以上


虚幻引擎的贴花特效（Decal Effect）是一种可以在场景中添加细节和效果的技术，它可以在模型或角色的表面上投射贴花材质，比如血迹、弹孔、裂痕等。虚幻引擎5.3 - PICO 分支已支持在多视图（Multiview）模式下开启贴花特效（Decal Effect）。

延迟着色（Deferred Shading）支持多视图模式


UE5.3 及以上


虚幻引擎的延迟着色（Deferred Shading）是一种渲染技术，它将渲染过程分为两个步骤：几何处理和光照处理。通过将光照和几何处理分开，提供了更高效的材质和高级光照特性的实现。虚幻引擎5.3 - PICO 分支已支持在多视图（Multiview）模式下开启延迟着色（Mobile Deferred Shading），并且实现了支持 Multiview 的 FXAA 抗锯齿，在 Deferred Shading 不支持 MSAA 的情况下，可以开启 FXAA。
注意：Deferred Shading 与 MSAA 抗锯齿不兼容，因此在开启了 Deferred Shading 后，建议选用 FXAA 抗锯齿。

Mobile HDR Bloom 特效支持多视图模式

UE 5.4 及以上

启用 Mobile HDR 后，即可使用虚幻引擎所有的后处理（Post Process）能力。
*注意：
*启用 Mobile HDR 功能后，如果需要开启 Stereo Layer 的 Support Depth 选项或开启视频透视（Video Seethrough，VST）功能，必须在项目的配置文件 DefaultEngine.ini 中添加以下设置：r.Mobile.PropagateAlpha=1。否则，渲染管线中可能会丢失 Alpha 信息，从而导致 Depth Layer 或 VST Layer 渲染失败。
*如果需要同时使用 Bloom 特效和视频透视功能，必须将配置文件中的 r.Mobile.PICO.BlendModeSetting 设置为 2，否则 Bloom 效果将无法正常显示。

新增 r.Mobile.PICO.BlendModeSetting 设置

UE 5.4 及以上

*r.Mobile.PICO.BlendModeSetting 设置预设了以下三种混合模式：
*r.Mobile.PICO.BlendModeSetting=0：VST 层会叠加到 Eye Buffer，适用于 VST 层与 Eye Buffer 同时显示的场景。
*r.Mobile.PICO.BlendModeSetting=1（默认）：VST 层与 Eye Buffer 均会根据 Alpha 值做裁剪。该模式下，透明度混合的特效可能存在混合问题。
*r.Mobile.PICO.BlendModeSetting=2：Eye Buffer 会叠加到 VST 层，且只有 VST 层会根据 Alpha 值做裁剪。该模式下，包含透明度的特效可以与 VST 层正常混合。

*Unreal Engine 安装程序

*C++ 分析工具
*C++ AddressSanitizer（可选）
*Windows 10 SDK（10.0.18362 或更高版本）
*Unreal Engine 安装程序

安装 Visual Studio 2022。确保勾选 使用 C++ 的游戏开发。在右侧的 "安装详细信息" 部分，选择以下组件：
*C++ 分析工具
*C++ AddressSanitizer（可选）
*Windows 10 SDK（10.0.18362 或更高版本）
*Unreal Engine 安装程序

若提示路径或文件名太长，移动文件夹至较短路径即可
