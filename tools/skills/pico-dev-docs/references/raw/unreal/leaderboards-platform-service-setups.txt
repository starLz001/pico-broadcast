排行榜-平台接入
========================================
使用 “排行榜” 服务前，你需要在 PICO 开发者平台上为你的应用创建一个或多个排行榜，并根据实际需求配置排行榜参数字段。
*前提条件 
创建排行榜前，你需要先为 UE 项目配置平台服务。参考配置平台服务。
*创建排行榜
你可以在 PICO 开发者平台上为应用创建一个或多个排行榜，并根据实际需求配置排行榜参数。步骤如下： 
*登录 PICO 开发者平台。
*从左侧导航栏中，选择 我的应用。
*在 我的应用 页面上，点击目标应用卡片，进入其 概览 页。
* 
*在左侧导航栏中，点击 平台服务。 
*你将前往 PPS 开发平台。
*在左侧导航栏中，点击 排行榜。
*你将进入排行榜管理面板。
*点击 创建排行榜。
*你将进入排行榜配置面板。
* 
*选择排行榜所应用的地区。 
*选择排行榜的展示语言。 
*根据界面提示配置排行榜字段。字段说明如下： 
**
*点击 保存。
*你已在本应用中创建了一个排行榜。

提示
确保你选择应用的 APP ID 与你在 UE 编辑器上为你应用项目设置的 APP ID 一致。



字段

说明

显示名称

排行榜在玩家端的名称。如周榜、总榜、好友排行榜、全球排行榜等。

API Name 

排行榜的唯一标识，即接口中涉及的 leaderboardName 参数。 

排序方式 

排序策略。用于指定排行榜排名的规则。 
*越高越好（默认）：数值越高，排名越靠前。常用于积分类应用。 
*越低越好：数值越低，排名越靠前。常用于竞速类应用。 

排序字段类型 

排序字段类型。用于指定排行榜上用于排名的分数的格式。 
*距离：常用于竞速类应用。例如：时间恒定的赛车游戏。 
*百分比：可用来对胜率、击杀率、命中率等进行排序。 
*得分：常用于积分类应用，例如：卡牌游戏。 
*时间：常用于竞速类应用。例如：距离恒定的赛车游戏。 

数据写入权限 

指定数据写入权限。 
*客户端可写入 （默认）：客户端和服务端都可以写入数据。 
*仅服务端可写入 ：只有服务端可以写入数据。 

关联 Destination 

是否将排行榜与 Destination（某个关卡、地图等）关联。关联后，该排行榜仅展示该 Destination 的排名数据。点击 Destination，出现的下拉选项有： 
*否 （默认），不关联。 
*为当前应用所配置的所有 Destination 的显示名称，按首字母排序。若未配置 Destination，则下拉项仅为 否。了解如何配置 Destination，参考创建 Destination。

是否启用好友排行

若启用，用户将能够在此排行榜上看到好友的排名。

是否启用通知

启用好友排行后，可选择是否启用排行榜超越通知。启用后，当某一玩家的排名被其好友超越时，该玩家将在设备端的通知中心收到通知。
