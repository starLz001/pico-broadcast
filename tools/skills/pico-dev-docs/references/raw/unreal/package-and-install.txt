*在 UE 项目上完成 PICO 应用的项目开发后，你可以将其打包为 APK 文件并安装到 PICO 设备上运行和调试。本文档介绍如何打包和安装 UE 项目到 PICO 设备。要了解更多 UE 项目打包知识，参考 UE 官方文档打包Android项目。
*前提条件
在打包项目前，你需要确保已配置好安卓的开发环境。详情参考准备安卓开发环境。
*打包 UE 项目
*如果你想要打包项目后将应用上传到 PICO 商店，你需要了解文件的大小限制：应用的 APK 包不可超过 2GB，单个 OBB 文件不可超过 4GB。参考以下步骤打包 UE 项目并安装。
* 
*安装 UE 项目
将项目打包完成后，你可将项目安装到 PICO 设备上进行运行或调试，步骤如下：
*使用 USB-Type C 连接线连接 PICO 设备与 Windows 电脑。
*确认 PICO 设备进入开发者模式。具体步骤参考开启开发者模式。
*双击打包目录中 Install_{项目名称}-arm64.bat 文件即可将应用安装到 PICO 设备中。
* 
*关于安卓清单文件
对于基于安卓系统的 PICO VR 一体机来说，任何运行在设备上的应用都必须包含 安卓清单文件（AndroidManifest.xml）。该文件包含安卓应用的重要元信息，包括配置信息、权限、软硬件支持、安卓版本支持等。
若使用虚幻引擎来生成 PICO XR 应用，APK 文件内会自动生成安卓清单文件。基于你的应用配置，安卓清单文件内会自动生成相应的配置内容。例如，当你在 Unreal 编辑器中为应用配置眼动追踪能力后，相应的配置元数据将被自动添加至安卓清单文件。因此，你无需手动为文件添加任何内容，直接编译和运行即可。
如需自定义安卓清单文件，可参考 UE 文档 Android Manifest 控制。若想了解更多安卓清单文件相关信息，可参考安卓官方文档应用清单概览。
*故障排查
*若导入 PICO SDK 后 UE 项目打包失败，你可参考以下内容排查问题：
*已参考 Android 开发要求 正确设置了 Android Studio。
*已参考配置 Android SDK 正确填写了 Android SDK 路径。
*已取消勾选编辑器中 编辑（Edit） > 插件（Plugins） > 内置（Built-In）下，Virtual Reality 和 Input Devices 下除 XRBase 外的所有插件，包括 OpenXR、Google 相关插件等。这是因为 PICO SDK 可能会与其它 VR 插件不兼容而出错。
*若安装 APK 文件至 PICO 设备时失败，并出现类似 Requires newer sdk version #30 (current version is #29) 的报错信息，你需参考配置 Android SDK 将 SDK API Level 设为 matchndk，将 NDK API Level 设为android-29。
*使用虚幻引擎 5 打包的 Shipping 模式的 .apk 文件装到 PICO 设备中打开后，如果该应用亮灭屏后闪退，有可能是你在 编辑（Edit） > 项目设置（Project Settings） > 插件（Plugins） > AndroidFileServer 的 打包（Packaging）选卡下，取消勾选了 使用 AndroidFileServer（Use AndroidFileServer）。你需勾选该选项后重试。

*（可选）为方便调试，你可在编辑器左上角，点击 编辑（Edit）> 项目设置（Project Settings），在左侧面板 平台（Platforms） > Android > APK 打包 （APK Packaging）选卡下，勾选 将游戏数据打包至 .apk（Package game data inside .apk）。
* 
*在编辑器上方工具栏中，点击 平台（Platforms）> Android >  打包项目（Package Project）。确保你选择了 Android(ASTC) 作为打包方式。要了解安卓不同的纹理格式，参考 UE 文档 Android开发参考-Android纹理格式一节。
* 
*打包完成后，在项目文件夹下可以看到生成的 APK 文件。
