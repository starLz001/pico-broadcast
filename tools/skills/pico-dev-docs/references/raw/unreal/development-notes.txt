开发注意事项
========================================
当你使用 PICO Unreal Integration SDK 开发应用时，需注意以下事项：
*请勿用中文命名项目或路径
*若用项目名称或路径出现中文，可能会导致 PICOXR 插件出现打包失败。
*请勿使用 UE 命令关键字命名项目
*如下图，“Test” 是 UE 中的 命令行参数（Command-Line Arguments），用这类关键字的字符串命名项目可能会导致 PICO 插件出现打包失败。
* 
*查阅更多 UE 的命令行参数，参考 此处。
*不建议使用 UE4 提供的默认格子地形
*该地形比较复杂，包含噪点、法线等的处理，不适用于 VR 应用。
