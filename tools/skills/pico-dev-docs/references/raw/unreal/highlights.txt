高光时刻
========================================
高光时刻（Highlights）服务允许应用自动捕捉、记录玩家在游戏过程中的精彩时刻，并将这些时刻以图片或视频的形式保存下来，供玩家回顾和分享。主要功能如下：
*捕捉高光时刻内容：提供高光时刻录屏、截屏接口帮助生成游戏高光时刻的图片和视频；
*展示高光时刻预览界面：提供高光时刻预览分享接口。在自定义游戏场景展示高光时刻预览界面，玩家可以保存图片或视频，分享到抖音、或跨端分享到移动端的 PICO VR App 、再分享到微信平台中。
* 
*环境要求
SDK 版本为 2.3.0 及以上。
*应用场景
高光时刻在游戏应用中有多个应用场景：
*游戏回顾：高光时刻可以让玩家回顾游戏中的重要时刻和成就，并激发再次游玩的兴趣。
*成就分享：玩家可以将应用中的高光时刻分享给好友或展示在社交媒体平台，增加玩家成就感，提升游戏社交属性。
*游戏教学：玩家或开发者可以利用高光时刻功能记录游戏玩法、技巧、战术等，帮助新手玩家更快提升游戏水平。
*体验展示：开发者可以利用高光时刻展示游戏精彩画面和特色亮点，吸引潜在玩家关注和体验。

概念

描述

Session

你必须在某个 Session 中使用高光时刻截屏、录屏相关接口。你也可以在某个 session 中，调用接口获取和保存录制的图片和视频。

Job ID

每一次截屏、录屏得到的文件都有一个全局唯一的 Job ID。

跨端分享

将 PICO 设备头戴端的图片或视频分享到移动手机端的 PICO VR 应用内，称为跨端分享。



函数

说明

StartSession()

开始一个新的 Session。异步返回一个 string 类型的 sessionID。你必须在某个 Session 中使用高光时刻截屏、录屏相关接口。

CaptureScreen()

截取当前屏幕为一张图片。截屏之后返回图片的路径和 Job ID。

StartRecord()

开始录屏。

StopRecord()

主动调用以结束录屏。录屏之后，返回视频的路径、Job ID、时长等信息。

ListMedia()

列出当前 Session 下所有的图片和视频文件。

SaveMedia()

将某个图片或视频保存到本地相册。每次仅能分享一张图片或一个视频。

ShareMedia()

将某个图片或视频分享到其它平台或移动端的 PICO VR App 中。

HighlightRecordStopCallback

视频最长录制时间为 15 分钟。调用 StartRecord() 接口开始录屏后，若你没有在 15 分钟之内主动调用 StopRecord() 接口或由于其它原因导致录屏终止，系统会主动结束录屏，并返回视频的路径、Job ID、时长等信息。
