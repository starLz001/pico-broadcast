监测设备性能
========================================
PDC 工具支持在 PC 端实时监测设备的性能指标。你可以选择需监测的指标，为指标配置阈值预警规则。其中，阈值预警是 PDC 工具提供的指标数据异常提示机制。为指标配置阈值预警规则后，当该指标满足预警规则时，阈值预警 面板处将显示该指标、报警次数、对应的预警规则。本文档介绍如何检测设备的性能。
*前提条件
*你已经安装了 PDC 工具并连接到你的 PICO 设备。详细步骤可参考安装 PDC 并连接设备。
*具体步骤 
打开 PDC 工具，参考以下步骤完成对设备的监测。
*第一步：启用需监测指标 
选择需在 性能监测 面板上展示的指标。
*在左侧导航栏处，点击 性能监测，打开指标监测面板。 
* 
*点击面板右上角的 设置 图标，打开 设置 窗口。 
*在 显示设置 面板处，启用需监测的指标。 
*启用后的指标将在指标监测面板中显示。 
* 
*第二步：配置阈值预警规则
在 预警设置 面板处，为指标配置阈值预警规则。 
*在红框所示区域，添加阈值预警规则： 
* 
*选择需配置阈值预警的指标。 
*选择阈值预警条件。选项有： 
*Above：高于阈值时报警 
*AboveOrEqual：高于或等于阈值时报警 
*Below：低于阈值时报警 
*BelowOrEqual：低于或等于阈值时报警 
*Equals：等于阈值时报警 
*设置阈值（正整数）。 
*点击 添加。 
*    新添加的阈值预警规则会自动启用。 
*按需执行以下操作： 
*滑动开关，启用/禁用阈值预警规则。 
*点击 删除 图标，删除阈值预警规则。 
*第三步：开始监测 
配置完毕后，开启设备并运行应用，然后点击 性能监测 面板上方的 运行 按钮。性能监测 和 阈值预警 面板上将实时展示设备的性能数据以及报警情况。性能监测过程中，请停留在性能监测界面，切换至其他 PDC 功能界面将导致性能监测中断。
 
以下图红框区域为例： 
*FPS 为触发阈值预警的指标。
*x30 为报警次数，即已报警 30 次。 
*Below 50 为所配置的预警规则，即当 FPS 低于 50 时进行报警。 
 
若需下载日志，可先点击 暂停 按钮，然后点击 性能监测 面板处的 下载 按钮。

*了解更多

指标名称

说明

GPU Utilization (GPU U) 

总 GPU 占用率（单位：%）。 

CPU Utilization (CPU U) 

总 CPU 占用率（单位：%）。 

FPS (FPS) 

帧速率（单位：帧/每秒）。 
提示：正常情况下，应用的帧速率应等于屏幕刷新率。 

Available Memory (A MEM) 

剩余可用内存（单位：MB）。 

Performance Score (Perf S) 
 

设备当前的整体性能状况： 
*<80：性能良好 
*[80,100]：某些情况下可能会降帧，例如：长时间运行、部分重载场景、低电量场景限频、断电等 
*>100：频繁降帧 

Foveation Level (FRL) 

注视点渲染等级。等级越高，GPU 占用率越低，但是周围的模糊程度越明显。取值范围为 -1 至 3： 
*-1：关闭 
*0：Low 
*1：Medium 
*2：High 
*3：TopHigh 

Eye Buffer Width (EBW)  

引擎所渲染的纹理的宽度。 
分辨率对 GPU 渲染时间有直接影响。在碎片着色器中，分辨率要求越高（即像素越多），渲染时间越长。 

Eye Buffer Height (EBH) 

引擎所渲染的纹理的高度。 
分辨率对 GPU 渲染时间有直接影响。在碎片着色器中，分辨率要求越高（即像素越多），渲染时间越长。 

Used Memory (U MEM) 

已使用的内存（单位：MB）。 

Singlepass (SLP) 

是否开启多视图渲染（Multiview）： 
*0：未开启 
*1：开启 

CPU Temperature 

设备 CPU 的温度（单位：°C）。 

GPU Temperature 

设备 GPU 的温度（单位：°C）。 

CPU Level (CPU L) 

为应用设置的 CPU 级别。级别越高，CPU 占用越高。默认值为 0，表示系统自动调节应用的 CPU 等级。 

GPU Level (GPU L) 

为应用设置的 GPU 级别。级别越高，GPU 占用越高。默认值为 0，表示系统自动调节应用的 GPU 等级。 

Display Refresh Rate (DRR) 

设备的屏幕刷新率。 

Battery Level (BAT) 

设备的剩余电量（单位：%）。 

Battery Temperature (B TEM) 

设备的电池温度（单位：°C）。 

Power Voltage (POW V) 

设备电压（单位：毫伏）。 

App VSS (VSS) 

应用向系统申请的虚拟内存。 

App PSS (PSS) 

*应用实际使用的物理内存。 

App RSS (RSS) 

应用实际保存的物理内存。 

Battery Current ( BAT C) 

来自电池的电流（单位：毫安）。 

GPU Frequency ( GPU F) 

GPU 时钟速度。时钟速度越高，GPU 运行速度越快。 

CPU Frequency ( 0-7 核数据，包括：CPU0 F、CPU1 F、CPU2 F、CPU3 F、CPU4 F、CPU5 F、CPU6 F、CPU7 F) 

单个 CPU 内核的时钟速度。时钟速度越高，CPU 运行速度越快。应用运行于内核 5、6 和 7 上。 
 

CPU Utilization（0-7 核数据，包括：GPU0 U、GPU1 U、GPU2 U、GPU3 U、GPU4 U、GPU5 U、GPU6 U、GPU7 U） 

单个 CPU 内核的利用率。应用运行于内核 5、6 和 7 上。
