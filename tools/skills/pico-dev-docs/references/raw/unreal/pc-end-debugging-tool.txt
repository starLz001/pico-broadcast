PC 端调试工具
========================================
*功能描述
PC 端调试工具简化了 PICO 平台服务的调试流程。通过使用该工具，你可以直接在 PC 上调试大部分 PICO 平台服务，而无需反复构建 APK 文件并安装到设备上进行调试。目前支持调试以下服务:
*账号&好友
*语言聊天
*社交互动
*多人游戏
*应用内购（IAP）
*环境要求
Windows 操作系统。
*注意事项
若需在短时内进行多次调试，为保证上一次调试所创建的进程完全退出，请确保在关闭调试界面至少 5 秒后再次点击 运行 按钮开启。
* 
*准备工作
使用 PC 端调试工具前，你需要完成前期配置工作，并配置 PC 调试模式。
*导入 PICO Unreal Integration SDK
首先，你需要在 Unreal 编辑器中创建项目，然后在项目中导入 PICO Unreal Integration SDK。详细步骤参考准备工作。
*获取 Access Token
然后，你需前往 PICO 开发者平台获取 Access Token。步骤如下：
*登录 PICO 开发者平台。
*点击目标应用卡片，进入其 概览 页。
*在左侧导航栏中，点击 API 测试。
*你将进入 API 页面。
* 
*从 授权管理 列表中选取所需权限：
*若需要调试 “账号&好友” 服务或 “社交互动” 服务，选择 你的好友关系，寻找与你共同使用此应用的好友，发现彼此 和 你的头像、昵称。
*若需要调试 “多人游戏” 服务或 “应用内购” 服务，选择 你的头像、昵称。
*点击 获取Access Token。
*你将看到一个展示 Access Token 的窗口，如下图所示：
* 
*点击 复制，复制生成的 Access Token。
*配置 PC 调试模式
配置 PC 调试模式，步骤如下：
*打开 Unreal 编辑器。
*在编辑器左上角，点击 编辑 > 项目设置 > 插件 > OnlinePico Settings。
*在 Windows Debug > AccessToken 中，填写获取的 Access Token。
* 
*在左侧导航栏处，点击 平台 > Android。
*在 APK 打包 选卡下，填写以下信息：
*安卓包名称：产品的官方名称（与 PICO 商店使用的名称相同），包含公司名称和项目名称两部分，以英文句号连接，且独一无二。
*保存版本：用于在 PICO 商店中显示的版本号。
*版本显示名称：向终端用户显示的可视版本。
* 
*完成 SDK 初始化。
*重新启动项目，点击 窗口 > 开发者工具 > 输出日志 即可打印日志。
*日志中显示 PICO Platform SDK initialize success! 即表示初始化成功。
* 
*在 Plugins > OnlineSubsystemPico > WindowsDebug 路径下，你可以查看自动生成的输出日志 output.log 和 PicoWindowConfig.json 配置文件。

*调试平台服务
完成配置后，你可以通过 PlatformSample 调试平台服务。此处以 “账号&好友” 服务为例，具体调试步骤如下：
*前往 PICO GitHub，获取 PlatformSample 压缩包。
*解压后，打开对应引擎版本的 PlatformSample 文件夹。
*在 Unreal 编辑器中打开 UIInteractionDemo.unproject 文件。
*点击编辑器左下角 内容浏览器 目录下的 Newworld 地图。
*点击编辑器右上角的 运行 按钮。

*参考 账号&好友 说明文档，调试服务。
