系统启动画面
========================================
在用户点击一款 PICO 应用的图标后，引擎需要一段时间初始化渲染线程和其它资源。自 2.1.5 版本起，PICO SDK 缩短了这一段初始化所花费的时间，并支持添加自定义图片作为应用启动时加载的画面，该画面即为系统启动画面。
*你可以通过在 UE 编辑器中添加 OS Splash Screen，例如你的应用图标图片，作为系统启动画面，提示用户应用正在正常加载，优化等待体验。你也可观看此视频了解如何设置自定义应用内启动画面。
*环境要求
*SDK 版本：2.1.5 及以上版本
*PICO 设备：Neo3 和 PICO 4 系列
*PICO 设备系统版本：5.5.0 及以上版本
*操作步骤
参考以下步骤，使用自定义图片作为 PICO 系统启动画面：
*在 UE 编辑器中打开项目。
*在上方工具栏，点击 编辑（Edit） > 项目设置（Project Settings） > 插件（Plugins） > PICOXR Settings。
*移动到 Mobile 选项卡下，在 OS Splash Screen 字段添加自定义图片的路径。图片需为 PNG 格式，大小不可超过 1024px * 1024px。推荐宽高比例为 16：9、4：3 或 1：1。
* 
*添加图片后，该图片会被命名为 pico_splash.png  拷贝至工程目录下，允许被 Git 管理。打包应用时，该图片会被打包至 APK 文件中。
* 
*故障排查
*在编辑器中添加 OS Splash Screen 后，若打包后的 APK 文件中包含该图片且格式与大小正确，但图片未生效，可参考以下步骤解决：
*打开 UE 工程中的 DefaultEngine.ini 配置文件。
*搜索 bUsingOSSplash 字段，查看配置文件中是否包含以下字段：
* 
*若不存在以上字段或 bUsingOSSplash 字段值为 False，则说明该图片未被启用。
*你可选择在 UE 编辑器中重新添加图片或直接修改以上字段来修复该问题。
*常见问题
*OS Splash Screen 支持呈现图片的半透明效果吗？
*不支持。PICO SDK 暂未支持图片混合（Blend）模式，因此对于半透明的 PNG 格式图片，暂无法实现半透明效果。

OSSplashScreen=(FilePath="The path of your picture")
bUsingOSSplash=True
