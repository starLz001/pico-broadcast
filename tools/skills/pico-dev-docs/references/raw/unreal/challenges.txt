挑战
========================================
挑战（Challenge）可在玩家间创造趣味性竞争，增强玩家之间的互动。开发者和玩家都可以为应用创建挑战，配置挑战信息（包括名称、可见性、开始和结束时间），然后邀请好友参与挑战，玩家也可以参与平台所创建的官方挑战。挑战为异步进行，即参与者无需同时上线进行挑战。

*整体流程

*成绩管理
挑战附属于排行榜，并沿用排行榜的排序方式和成绩种类。挑战与排行榜的成绩条目是分别存储的，成绩更新分为以下两种情况：
*情况一：仅更新挑战条目
*若最新挑战成绩等于或高于现有挑战成绩，但低于现有排行榜成绩，则仅将最新成绩更新至挑战条目中，而不更新到排行榜条目中。
*情况二：同时更新挑战和排行榜条目
*若最新挑战成绩等于或高于现有挑战成绩和挑战对应的排行榜成绩，则将最新成绩同时更新至挑战和排行榜条目中。

*创建排行榜
挑战附属于排行榜（Leaderboard），并沿用排行榜的设置，例如：排序方式、成绩种类（分数、距离等）、是否展示好友数据。创建步骤参考排行榜。
*创建挑战
方法一
你可以调用服务端接口来为指定排行榜创建挑战。此外，用户也可以在应用内创建挑战。
方法二
你可以在 PICO 开发者平台为指定排行榜创建挑战，步骤如下：
*登录 PICO 开发者平台。
*在左侧导航栏中，点击 我的应用。
*你将前往 我的应用 页。
*点击目标应用，进入其 概览 页。
*在左侧导航栏中，点击 平台服务。
*你将前往 PPS 开发平台。
*在左侧导航栏中，选择 排行榜。
*你将进入排行榜管理面板。
*在排行榜列表中，找到目标排行榜，然后点击 操作 栏中的 挑战。
*你将进入该排行榜的挑战管理面板。
*点击 创建挑战。
*你将进入挑战配置面板。
* 
*配置挑战。
*点击 保存。
*你创建的挑战将被添加至 我的挑战 列表。用户挑战 列表用于展示用户创建的挑战。
*最佳实践
Destination 为跳转目的地。用户可以通过 Deep Link 直接跳转至 Destination 中定义的位置。创建步骤参考社交互动。创建完成后，为排行榜关联该 Destination。

接口

说明

Get

获取指定挑战的信息。除基本信息外，还支持获取该挑战的已邀请用户和已加入用户。

GetList

获取挑战列表，需指定返回的页码和每页返回的挑战数量。你可以通过设置 ChallengeOptions 来设置筛选条件，例如挑战的时间范围、所属排行榜、可见性，从而获得指定挑战。



接口

说明

Join

允许用户主动加入挑战。用户加入挑战后，将出现在该挑战的已加入用户列表中，用户离开挑战后，将被从该列表中移除。

Leave

允许用户主动退出挑战。退出后，用户的分数条目将被删除。



接口

说明

WriteEntry

将用户的成绩写入挑战对应的排行榜。


GetEntries


获取成绩条目。
可使用 filter 参数对返回结果进行过滤，其中：
*None：不进行过滤，返回所有条目。
*Unknown & UserIds：无效类型，不返回条目。
*Friends：同时返回好友和自己的条目。
注 ：如果想通过 User ID 过滤条目，也可以直接调用 GetEntriesByIds 接口。

GetEntriesAfterRank

获取某个排名后的成绩条目。

GetEntriesByIds

获取指定用户的成绩条目。



编号

说明

1

用于定义 pageIndex 和 pageSize 参数。在此处可输入想查询的挑战页。

2（Options）

用于配置查询筛选条件，包括挑战所属的排行榜名称、挑战名称、挑战可见性等。

3（Challenge List）

用于展示挑战。配置完 pageIndex、pageSize 和 ChallengeOption 后，点击 GetList。系统将执行 GetList 接口，获取符合条件的挑战，并在 Challenge List 列表中以挑战 ID 的形式展示。同时，在 ExecuteResult 下将可以查看执行结果。
点击列表中的某条挑战后，系统将执行 Get 接口，获取该挑战的详细信息并在 ChallengeInfo 下展示。
点击 Join，加入指定挑战；点击 Leave，退出指定挑战。

4

用于邀请好友加入挑战。步骤如下：
1. 点击 Challenge List 中的某个挑战。
2. 在输入框中输入好友的 ID，支持输入多个。
3. 点击 Invite。
系统将执行 Invite 接口向指定好友发送邀请。同时，在 ExecuteResult 下可以查看邀请的执行结果。

5（SearchParams）

用于配置挑战条目查询条件。步骤如下：
1. 点击 Challenge List 中的某个挑战。
2. 配置查询条件。
*若配置了 afterRank，则执行 GetEntriesAfterRank，获取某个排名后的条目。
*若配置了 userIds，则执行 GetEntriesByIds，获取指定用户的条目。
*若未配置 afterRank 和 userIds，则执行 GetEntries，获取所有条目。

6（Challenge Entry List）

用于展示符合条件的挑战条目。点击任一条目后， ChallengeEntryInfo 下将展示该条目的详细信息。

7（ExecuteResult）

用于展示接口调用结果。
