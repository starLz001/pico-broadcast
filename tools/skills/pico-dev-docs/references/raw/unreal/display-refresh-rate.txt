屏幕刷新率
========================================
屏幕刷新率 是 VR 屏幕在每秒钟刷新的次数。刷新率越高，用户在每秒钟内就能看到越多的画面，画面也就更加流畅、清晰。刷新率越低，用户看到的图像闪烁、停顿和抖动就越厉害，越容易造成视觉疲劳。
*应用场景
目前市面上大部分 VR 头显的刷新率在 72-90 Hz 间，能够保持基本的画面流畅。如果是你开发的是第一人称射击游戏（FPS）、赛车类游戏，用户快速的头部或视野转动可能导致画面模糊或者出现画面撕裂，使用高刷新率可以使画面更加平滑，在高速位移下减少画面延迟、重影，降低眩晕感。
 
*设置步骤
*SDK 默认支持 72 Hz 的屏幕刷新率（采用 70 Hz 以上的刷新频率才能基本消除闪烁）。你也可以更改默认值，为项目设置更高的刷新率。你可参考以下步骤设置屏幕刷新率：
*方式一：在编辑器中设置
*在编辑器左上角，点击 编辑（Edit） > 项目设置（Project Settings） > 插件（Plugin） > PICOXR Settings。
*移动到 Feature 选项卡下， 点击 Display Refresh Rates 右侧下拉菜单，选择合适的屏幕刷新率。

*



选项

说明

*Default

保持当前系统环境设置的刷新率。

*Refresh Rate 72

设置刷新率上限为 72 Hz。

*Refresh Rate 90

设置刷新率上限为 90 Hz。

*Refresh Rate 120

设置刷新率上限为 120 Hz。



接口

描述

PXR Get Current Display Frequency

获取当前设备支持的最大屏幕刷新率。

PXR Get System Display Frequency

获取当前设备使用的屏幕刷新率。

PXR Set System Display Frequency

设置屏幕刷新率。
