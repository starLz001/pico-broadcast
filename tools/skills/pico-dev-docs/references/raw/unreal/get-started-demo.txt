入门 Demo
========================================
入门 Demo 包含室内（Indoor）和室外（Outdoor）两个场景。你可以在 Demo 中体验视角转动、连续运动、传送和场景切换功能。进入场景后，默认为 Indoor 场景，按 Y 切换 Outdoor 场景。
*开发环境
*SDK 版本：2.3.0
*PICO 设备系统版本：5.7.0
*虚幻引擎版本：4.27
*图形接口：OpenGLES 3.1
*应用架构：64 位
*体验 Demo
你可以直接将 Demo 的 APK 文件安装到设备上进行体验。也可以前往 GitHub 下载 Demo 工程。
 
以下为 Demo 内场景展示：
*
*参考以下操作探索 Demo：
*视角转动：左右推动左手柄的摇杆
*连续运动：上下推动右手柄的摇杆
*回到初始方向：B 键
*跳跃：A 键
*场景切换：按下左手柄的 Y 键
