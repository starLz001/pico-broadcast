订阅 Demo
========================================
本文档介绍 PICO Unreal Integration SDK 提供的订阅服务 Demo。要了解订阅服务，查看订阅文档。
*前提条件
确保你 PICO 设备的 PUI（ROM）版本为 4.8.0 及以上。
*使用说明
你可以前往 PICO GitHub 获取对应引擎版本的 IAP Demo。IAP Demo 位于 Content\Maps\WindowsMaps 路径下。以下为 Demo 的图形化界面，具体使用说明可参考应用内购 Demo 文档。其中， OuterID 仅适用于订阅服务，为订阅周期的唯一标识； LaunchCheckoutFlow_V2 用于发起订阅类 Add-on 的购买流程。
 
*API 参考
*SDK 接口：为了适配订阅服务，我们扩充了 IAP 服务部分接口的入参和返回，同时新增了 LaunchCheckoutFlowV2 接口用于发起订阅商品的购买流程。SDK 接口详情可参考 API 文档。
*S2S 接口：为了适配订阅服务，我们扩充了 IAP 服务 S2S 接口的部分字段，具体参考此文档。
