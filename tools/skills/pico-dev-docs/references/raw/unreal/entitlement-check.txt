用户权限校验
========================================
用户权限校验用于验证用户是否有权限使用你的应用，即用户是否购买该应用或是否通过其它合法手段（如兑换码、赠送分发渠道等）获得该应用的使用权。用户权限校验功能为你的应用提供版权保护，防范非 PICO 渠道的破解版应用的传播。
*SDK 要求
*SDK 版本为 2.1.5 及以上。若你仍在使用 2.1.4 及更早版本的 SDK，可参考《开启用户权限校验（Legacy）》文档为应用开启该能力。
*重要提示
*用户权限校验只会保护在 PICO 商店上架的应用。若应用未上架，未登录用户直接跳过权限校验，登录用户则直接通过权限检验。应用上架后，未获得应用使用权的用户将不会通过权限校验。
*应用的开发组织成员可以跳过用户权限校验，方便应用测试。详情可参考本文档应用测试说明一节。
*若你的应用为付费应用，则需要为其开启用户权限校验，否则将无法通过审核。对于免费应用，我们也建议为其开启用户权限校验，以更好地保护版权。
*应用的目标 API 等级应当不低于 23（即 targetSdkVersion>=23），且推荐及时更新适配安卓新版本的 API 等级。
*应用场景
*应用上架后，系统自动进行用户权限校验
*PICO 为已上架 PICO 商店的应用提供了自动校验用户权限的能力，具体的应用覆盖范围为：
*用户从 PICO 商店内下载和安装的应用。
*用户通过兑换码、赠送、运营直充等合法方式获得使用权的应用。
*对于以上应用，PICO 系统会在应用启动时进行用户权限校验，校验通过后，应用才可以正常启动；若校验不通过，系统会弹窗提示用户并关闭应用。系统也会在应用运行过程中在后台定期对用户进行静默的权限校验。
*在应用关卡内，主动调起用户权限校验
*你可以选择在应用内合适的时机（比如每个新场景加载时），调用权限校验接口校验用户。校验通过后，用户可以继续使用应用；若校验不通过，你可选择设置相应 UI 提示，也可设置关闭应用。 
*启用用户权限校验
调用EntitlementCheck()接口为应用在合适的时机（例如：每个新场景加载时）开启用户权限校验。调用接口时需要传入 bKillApp 参数：
*若 bKillApp 参数传入的值为 true，当校验不通过时，系统会弹窗提示用户，然后退出应用。
*若 bKillApp 参数传入的值为 false，你需要自行处理校验结果。若校验不通过，你可以自定义弹窗引导用户安装正版应用。

测试方法

*应用未上架 PICO 商店

无论设备是否登录 PICO 账号，你可直接在设备上安装 APK 文件测试。

*应用已上架 PICO 商店

*你可通过以下方式跳过权限校验：
*将 PICO 设备的系统升级为 5.6.0 或以上版本。
*邀请 PICO 设备的测试账号为应用的开发组织内成员。具体步骤可参考管理组织成员。
*否则，你需要通过测试渠道安装 APK 文件测试应用。
