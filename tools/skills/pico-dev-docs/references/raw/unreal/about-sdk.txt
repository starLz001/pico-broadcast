PICO Unreal Integration SDK
========================================
PICO Unreal Integration SDK（以下简称 SDK）是 PICO 官方提供的、基于虚幻引擎研发的一组工具包。你可以用该 SDK 在虚幻引擎编辑器上开发运行在 PICO VR 一体机上的应用程序。在游戏本身的设计和制作上，使用 SDK 开发应用与普通的 3D 开发有很大相似性和共通性。
SDK 封装了一系列功能，如渲染、输入&追踪、混合现实、平台服务等，给 PICO VR 应用带去沉浸式体验。此外，开发者平台提供的支付与数据体系以及 PICO 团队提供的专业技术支持服务，将让你的 XR 应用开发之旅变得轻松又高效。
你可点击此链接下载并解压最新版 PICO Unreal Intergration SDK 包。SDK 本质上是虚幻引擎插件。因此，在开发前，推荐你阅读 UE 官方文档了解 UE 开发相关信息。
