手柄&头戴输入映射
========================================
手柄和头戴是用户与应用交互的媒介。通过操作手柄或头戴，用户可在系统或应用内完成一系列操作，例如：按下返回键，退出当前场景；点击按钮，确认相关设置。每个手柄/头戴操作都会被映射为输入事件。PICO Unreal Integration SDK 使用 Unreal 官方键值进行手柄和头戴的输入事件映射。本文介绍如何在 UE 编辑器中设置 PICO 设备的输入映射，你也可参考虚幻引擎官方文档设置输入了解相关内容。
*支持设备
PICO Neo3，PICO 4 以及 PICO 4 Ultra 系列。
*前提条件
在输入映射之前，确保你已为 Pawn 定义了运动控制器组件并添加了对应的 PICO 手柄模型。详情参考搭建 XR 场景。

*一键配置手柄输入映射
*导入的 PICO SDK 会默认为你创建的项目添加手柄的输入映射。如果你使用的是 UE4，你可使用 PICOXRInput Toolbar Button 一键清除或添加默认的手柄映射。
*前往 编辑（Edit）>项目设置（Project Settings）> 编辑器（Editor）>PICOXR Settings，勾选 Show PCIOXRInput Toolbar Button。
* 
*在 UE 编辑器上方工具栏，将出现 PICOXR 图标。
*在 UE 编辑器上方工具栏，点击 PICOXR 图标 > Clear/Add Sample Inputs，一键清除或添加 PICO SDK 预置的输入映射。
* 
*手动配置手柄输入映射
*参考以下步骤，基于你使用的虚幻引擎版本，配置手柄输入映射。
*在 UE5 中配置手柄输入映射
*虚幻引擎 5 提供了 Enhanced Input 插件来帮助你配置输入映射，原有的输入映射配置已废弃。参考以下步骤完成输入映射。
*前往 世界场景设置（World Settings） > 游戏模式（Game Mode），确认 默认Pawn类（Default Pawn Class） 为 VRPawn。
* 
*前往 编辑（Edit） >  插件（Plugins） > 内置（Built-In） >Input，勾选 Enhanced Input 插件，并重启编辑器。
* 
*前往 内容浏览器（Content Drawer） > 内容（Content） > VRTemplate > Input，根据场景需要，对 输入映射上下文 的数据资产进行 PICO 手柄的按键映射。
