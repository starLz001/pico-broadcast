语音转文字
========================================
本文档介绍 PICO Unreal Integration SDK 提供的语音转文字服务 Demo。要了解语音转文字服务，查看语音转文字文档。
*前提条件
确保你的 PICO 设备的系统版本为 5.7.0 或以上。
*使用说明
你可以直接下载该 Demo 到本地，再使用 ADB 命令将该 Demo 安装到 PICO 设备上体验：
 
 
Demo 的图形化界面如下。其中每一个按钮，代表一个可接入调用的 API 接口。

要获取语音转文字 Demo 的项目文件，前往 PICO GitHub。项目中提供了蓝图接口的调用示例，你可以根据引擎版本下载示例。语音转文字的蓝图接口调用示例位于 Content\UMG\Speech\UI_Speech.uasset 中。
