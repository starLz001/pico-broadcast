CLI 命令行工具
========================================
PICO CLI 命令行工具（PICO Command Line Utility）是面向开发者的一款命令行工具，以帮助 PICO 开发者更轻松地管理 PICO 开发者平台的文件。使用 CLI 工具，你可以：
*上传 APK、OBB文件、资源文件
*管理 DLC 文件
*下载 APK 文件
*跨渠道复制 Build
*更新历史
*
*准备工作
使用 CLI 工具前，你需要：
*在 PICO 开发者平台创建应用；
*根据系统环境下载并安装 CLI 工具；
*获取 CLI 工具凭证。
*安装 CLI 工具
请参考以下表格下载并安装 CLI 工具：
*
如果你的设备是 macOS 系统，可能需要更改 CLI 工具的访问权限才可使用，步骤如下：
*在终端输入 cd/{CLI 工具所在目录}。
*输入 chmod +x ./pico-cli。
*若出现弹窗提示 “无法打开“pico-cli”，因为无法验证开发者”，你可以：
*点击桌面左上角苹果图标，选择 系统偏好设置 > 安全性与隐私 > 通用。
*点击 通用 面板中的 仍要允许 按钮，并输入你的 Mac 密码。
*输入 ./pico-cli 和一条指令（如：pico-cli help）可运行 CLI 工具。
*获取 CLI 工具凭证
使用 PICO CLI 工具时，你会用到：
*App ID 和 App Secret：用于验证 CLI 工具的应用管理权限。参考查看 App ID 和 App Secret 获取。
*Build ID：用于下载指定 Build。获取步骤如下：
*登录 PICO 开发者平台。
*选择已创建的组织。
*前往 我的应用，点击目标应用卡片，进入其 概览 页。
*在左侧导航栏处，点击 分发渠道，进入 分发渠道 详情页。
*找到目标分发渠道，然后点击 操作 栏处的 编辑。
*你将进入该渠道的版本列表页。
*找到目标版本，然后点击 操作 栏处的 查看。
*你将进入以下页面，在 版本信息 选卡下可查看 版本 ID （Build ID）。
* 
*核心功能
你可以通过指令来管理 CLI 工具和 PICO 开发者平台文件。有关指令的更多信息，参考指令详解。

*
*平台文件管理
在 CLI 工具内输入相应指令，可管理 Build 文件及其分发渠道。

句法

是否必填

说明

 --app-id <ID> 或 -a <ID>

是

应用的唯一标识，即 App ID，用于指定应用。

--app-secret <AppSecret> 或 -s <AppSecret>

是

应用程序密钥，即 App Secret，用于指定应用权限。

--region <cn｜noncn> 或 -r <cn｜noncn>

是

指定命令行请求的服务器所属的地区。

 --info <device-type|release-channel|build-id|all>


是


指定需获取的 Build 信息，参数包括（四选一）：
*device-type：获取设备信息（如：PICO 4、PICO Neo3）。
*release-channel：填入分发渠道参数，可获取相应分发渠道中的 Build 信息。参数及对应渠道如下：
*1：PICO Store (Mainland China)
*2：PICO Store (Outside Mainland China)
*3：Beta
*4：Alpha
*5：Release Candidate
*6：PICO Enterprise Store(Mainland China)
*7：PICO Enterprise Store(Outside Mainland China)
*build-id：填入 Build ID，可获取对应 Build ID 的 Build 信息。
*all：返回以上三项信息。
