房间&匹配 Demo
========================================
本文档介绍 PICO Unreal Integration SDK 提供的房间&匹配服务 Demo。要了解房间&匹配服务，查看房间&匹配文档。
*前提条件
确保你 PICO 设备的 PUI（ROM）版本为 4.8.0 及以上。
*使用说明
你可以前往 PICO GitHub 获取对应引擎版本的房间&匹配 Demo。房间&匹配 Demo 位于 Content\Maps\GameMaps\Game_PicoGameInstance_Demo 中。Demo 的图形化界面如下：
 

接口测试步骤如下：
*选择具体的接口，如 Create Session。
* 
*Params 部分将列出你需要为该接口配置的参数。
*根据输入框提示配置参数。
*配置完成后，点击 Execute。
*右侧 Execute Log 将显示执行结果。
*API 参考
房间&匹配相关 API 详情，可参考 API 文档。

部分接口具有特定使用条件。例如，开发者需处于某一房间中，才能获取当前房间的信息。
