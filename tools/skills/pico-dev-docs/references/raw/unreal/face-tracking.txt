面部追踪
========================================
面部追踪（Face Tracking），即在检测到人脸的前提下，在后续帧中持续捕捉人脸位置和面部表情等信息的技术。该技术通过实时采集或离线接收图像数据，预测面部表情动画系数（BlendShape），可驱动 3D 角色的面部表情动画。
*在现实世界中，面部表情可以表现人物内心的情绪和情感，是十分重要的非语言社交手段。同样地，在虚拟世界中，若面部模型能及时且准确的根据用户的实际面部表情变化而做出相应的面部动作，将能使应用内互动更加逼真，提升临场感。
PICO 4 Pro 和 PICO 4 Enterprise 一体机安装了面部追踪相机，可检测和捕捉用户的面部表情。PICO SDK 的面部追踪接口会将相机捕捉到的表情数据抽象成 52 维面部表情动画系数（BlendShapes）数据和 20 维 Viseme 数据，覆盖眼部、唇部、舌部、鼻部、面颊、额头和下巴区域，可驱动人脸模型做出微笑、眨眼、皱眉等各种动作。

*使用面部追踪
要在应用中使用面部追踪功能，你需要在 UE 编辑器中启用该能力，并在应用中配置接口。
*前提条件
你已在项目中导入 PICO Unreal Integration SDK。详情参考详情参考 导入 PICO SDK。
*在编辑器中为项目启用面部追踪能力
*在 Unreal 编辑器中创建一个项目或打开已有项目。
*在编辑器左上角，点击 编辑（Edit）> 项目设置（Project Settings）> 插件（Plugins）> PICOXR Settings。
*移动到 Feature 选项卡下，勾选 Enable Face Tracking。
* 
你已为应用开启面部追踪能力。
*查询当前设备支持的面部追踪模式
不同 PICO 设备支持不同的面部追踪模式。你可使用 GetFaceTrackingSupported 接口查询用户的设备是否支持面部追踪能力及支持哪些模式。
* 
*动态启停面部追踪并切换面部追踪模式
你可使用 StartFaceTracking 和 StopFaceTracking 接口动态开启和停止面部追踪能力。要切换面部追踪模式，可在调用 StopFaceTracking 时选择 Pause，再调用 StartFaceTracking 选择一个新的模式。此方式可减少面部追踪启停的耗时，更快获取面部追踪数据。

你可使用 GetFaceTrackingState 查询面部追踪能力是否开启、当前面部追踪模式等。

*获取面部追踪数据
你可使用 GetFaceTrackingData 获取面部追踪数据。目前仅支持将 Display Time 设置为 0 作为预测时间，即获取当前帧的眼动追踪数据。
GetFaceTrackingData 返回一个 72 定长的数组，对应 52 维面部表情动画系数（BlendShapes）数据和 20 维 Viseme 数据共 72 维表情数据。你可查看本文档 BlendShape & Viseme 说明部分了解 EPXRFaceBlendShape 枚举值及每个值对应的含义。
* 
*驱动骨骼模型
你可使用获取到的面部追踪数据驱动骨骼模型的混合变形。参考以下步骤：
*在 UE 编辑器中打开你的项目。
*在 内容浏览器（Content Drawer）中，找到并双击目标 VRPawn，进入 VRPawn 的编辑窗口。
*为你的 VRPawn 添加一个你预先准备好的带有面部表情 BlendShape 的 Skeletal Mesh Component。在下图示例中，该 Component 被命名为 ceres_avatar_rig。
*为你的 VRPawn 添加一个 PICO Face Tracking Component 组件。
*在 PICO Face Tracking Component 的 细节（Details）面板下，将 FTTarget Mesh Component Name 修改为上述 Skeletal Mesh Component 的名称。
*在 Blend Shape Name Mapping 选卡下，中添加面部表情的数据映射。例如，你可将面部追踪返回的数据之一 JawOpen 映射到骨骼模型中的 jawDrop 上。
*添加完毕后，你就可以使用面部追踪数据驱动骨骼模型的混合变形了。

enum class EPXRFaceTrackingMode : uint8
{
    PXR_FTM_NONE          = (uint8)-1,   /// 不开启面部追踪
    PXR_FTM_FACE          = 0,   /// 图像驱动模式
    PXR_FTM_LIPS          = 1,  /// 音频驱动模式
    PXR_FTM_FACE_LIPS_VIS = 2,  /// 融合驱动 Viseme 模式 
    PXR_FTM_FACE_LIPS_BS  = 3   /// 融合驱动 Blendshapes 模式
};

UENUM(BlueprintType)
enum class EPXRTrackingStateCode : uint8
{
    PXR_MT_SUCCESS                = 0,         // 追踪成功
    PXR_MT_FAILURE                = (uint8)-1, // 追踪失败
    PXR_MT_MODE_NONE              = (uint8)-2, // 未设置追踪模式
    PXR_MT_DEVICE_NOT_SUPPORT     = (uint8)-3, // 设备不支持追踪
    PXR_MT_SERVICE_NEED_START     = (uint8)-4, // 需要在 UE 编辑器中启动追踪服务
    PXR_MT_ET_PERMISSION_DENIED   = (uint8)-5, // 未授予眼动追踪权限
    PXR_MT_FT_PERMISSION_DENIED   = (uint8)-6, // 未授予脸部追踪权限
    PXR_MT_MIC_PERMISSION_DENIED  = (uint8)-7, // 未授予麦克风权限
    PXR_MT_SYSTEM_DENIED          = (uint8)-8, // 未授予系统权限
    PXR_MT_UNKNOW_ERROR           = (uint8)-9  // 未知错误
};
