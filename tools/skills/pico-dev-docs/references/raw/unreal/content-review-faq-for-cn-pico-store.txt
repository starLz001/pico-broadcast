中国大陆 PICO 商店内容审核相关 FAQ
========================================
*基础信息内容部分
*应用描述场景
*什么情况下提交基础信息后审核拒绝时会提示【语言不规范】
*常见于应用上架中国地区或某个国家地区时，设置的语种语言与填写的基础信息文本语言不一致
*建议参考：应用信息与对应语种保持一致，英文语种对应描述需使用英文，计划在中国大陆上线的应用需要提供正确的简体中文内容
*基础信息审核拒绝时会提示【基本信息描述违规】是什么原因
*常见问题1：应用信息&摘要等文本内容描述中的词汇涉及使用了“绝对化”的广告词，例如“最好、最优、极致、极品、绝无仅有、独一无二、前所未有”等
*“最”相关：最新、最好、最优、最受喜爱、最佳、最具、最爱、最赚、最优秀、最大、最大程度、最高、最高级、最高端、最流程、最受欢迎、最先进，最......等
*“极”相关：极致、极佳、极品、极......等
*“绝”相关：绝佳、绝对、绝版、绝无仅有、绝不再有、绝......等
*“第一”相关：第一、首款、首个、NO.1、TOP1
*其他：超强、国家级、特级、顶级、冠级、超凡、巅峰、顶峰、封顶、无人能及、翘楚之作、无与伦比、卓越、顶尖、史无前例、万能、独一无二、不可多得、前所未有，唯一
*常见问题2：应用信息&摘要等文本内容描述中的词汇涉及使用了涉及色情低俗、血腥暴力、违背公序良俗等问题的相关描述词汇
*建议参考：将此类违规词汇进行更改或删除
*基础信息审核拒绝时提示【存在违规功能】应该如何修改
*该问题常见于基础信息文本描述中涉及到PICO上线规范中不允许的功能设置，例如按规范中国地区应用服务器需架设在中国，应用描述文案或宣传素材中存在中国用户数据与境外数据互通的歧义表达
*建议参考：将歧义表述内容进行修改或删除
*审核结果提示【应用名称存在违规】一般涉及哪些情况
*应用名称属于用户定位和直接感知的关键信息，比较重要，一般该名称存在错误或违规内容时会因此打回
*常见问题1：应用名称存在错误信息，如test、测试等
*常见问题2：应用名称存在特殊符号、空格、繁体字、生僻字（丨）、拆字或颜文字等
*常见问题3：应用名称存在热门搜索词等易误导用户文字（如麻将、消消乐、斗地主）或 涉及侵权文字描述
*常见问题4：应用名称存在违规词描述，如血腥暴力、低俗色情内容描述
*建议参考：将相关违规词汇进行更改或删除
*图片&视频场景
*内容审核结果提示【图片视频存在违规】
*一般为PICO中国商店中的宣传图片或视频内容中存在违规问题导致
*常见问题1：图片或视频中存在竞品设备素材形象、LOGO或其他平台引流信息等内容
*常见问题2：图片或视频存在血腥暴力等感官画面效果呈现
*常见问题3：图片或视频内容素材质量较低，如：多个素材为相同重复内容、空白或与应用无任何关联等
*建议参考：依据审核结果返回的说明及示例参考修改即可
*隐私政策问题
*审核结果为什么会提示【隐私政策不规范】
*一般为在PICO后台上传的隐私政策链接中信息存在错误或不规范的情况
*常见问题1：开发者提供的隐私政策网址语言为非简体中文语言，如英文、繁体中文等情况
*常见问题2：开发者提供的隐私政策网址链接，无法正常打开
*常见问题3：开发者提供的隐私政策内，没有明确的运营公司主体
*常见问题4：开发者提供的隐私政策中运营主体与PICO后台登记名称不一致
*常见问题5：开发者提供的隐私政策中应用主体名称与实际应用名称不一致
*建议参考：依据审核结果返回的说明及示例参考修改即可
*PICO STORE 售价问题
*为什么会收到PICO商店售价【价格不合理】的审核结果
*按规定开发者需要保证应用在每个地区的价格相当，或符合双方合同中约定的情形，如果收到此类审核结果提示一般是因为该应用在PICO Store的售价相比其他竞品平台要高
*建议参考：修改PICO Store的售价，使其符合规定情况，如涉及特殊情况可联系PICO工作人员沟通
*包体内容合规部分
*应用名称&ICON图标
*应用包体会因为什么原因提示【应用名称&ICON违规】
*一般该情况为安装包的ICON图标素材或名称中存在错误信息或违规情况
*常见问题1：安装包的ICON名称与Store上架应用名称不一致
*常见问题2：安装包的ICON素材中存在低俗色情、血腥暴力等违规内容展示
*应用内文字脚本
*包体内文字脚本会存在哪些常见不合规问题
*常见问题1：PICO中国地区上架应用包体语言设置不包含简体中文 或 新手教程之类核心功能未汉化
*参考建议：应用需将简体中文设置为默认语言且应用内新手教材及核心功能需要完整汉化，包括但不限于文本、教程图示、语音（需要默认开启中文字幕）
*常见问题2：应用包体内文字脚本内容包含了部分违规内容，如涉及性行为之类色情低俗内容的描述、涉及违法违规内容的详细描述、血腥暴力内容等
*应用内美术素材及画面表现
*包体内美术素材或交互表现会存在哪些常见的不合规问题
*常见问题1：应用内美术素材或交互表现逻辑中包含了大量血腥暴力内容，如针对人形NPC的鞭尸、肢解、血肉堆叠等情况
*参考建议：①设计敌对NPC的受击表现时，保证其肢体的完整性，不产生肢解效果 ②敌对NPC被击败后尸体快速消失 或 尸体不产生任何攻击交互反馈，如血液喷溅、打击音效
*常见问题2：应用内美术素材（NPC、道具、装饰、皮肤等）涉及色情低俗画面、未成年人不当行为、违法违规、涉毒等违规画面
*色情低俗：如美术建模涉及漏点裸体、性器官凸出、性行为表现等
*涉毒：如毒品详细内容诱导宣传、制作过程、贩卖行为等
*未成年人不当行为：如未成年人违法违规行为等
*应用内地图问题
*应用内一般哪些常见问题会因为【地图不符合规范】打回
*一般该情况常见于应用内的地图素材包含了世界地图、中国地图素材并且其存在不符合规范的问题，如中国地图缺失了部分领土、中国边界线不完整等
*参考建议：①依据中国官方发布的地图素材，完善应用内的地图素材，中国地图请参见网站：https://www.gov.cn/guoqing/2017-07/28/content_5043915.htm ②使用完全虚拟的地图
*应用题材
*哪些题材类型的应用可能会被【存在应用题材问题】打回拒绝
*应用题材内容涉及到PICO平台暂未开放收录的应用品类或题材内容时会因此理由被拒绝，如虚拟币交易、赌博彩票等
*参考建议：建议持续关注PICO平台的准入政策更新，后续开放后可重新提交上架
*应用内UGC内容
*应用内UGC内容常见违规问题如下
*常见问题1：应用内用户可自定义上传的功能板块（文本/图片），如用户昵称、头像等场景不具备风险过滤能力
*参考建议：文本类场景可以接入PICO免费提供的服务https://developer-cn.pico-interactive.com/document/unreal/content-detection/
*常见问题2：应用内高自由度的UGC编辑功能，如创意工坊、MOD功能等官方分享场景，在审核测试时发现不具备风险过滤能力或该功能内存在违规内容
*参考建议：开发者可自行建设风险过滤机制，筛除违规内容，建议具备举报功能等
*其他问题
*应用提交包体后还存在以下两类常见的违规问题，需注意规避
*常见问题1：应用内存在海外地区的网址跳转功能 或 违规网址的展示及跳转
*参考建议：因此问题被拒绝打回后，需将对应反馈文档中提及的违规内容的网址链接信息删除即可
*常见问题2：应用内美术素材或文字脚本涉及将中国用户数据传输至海外地区 或 全球数据互通等
*参考建议：按要求国内上线版本数据应托管在中国服务器中，不允许中国数据传输海外地区，如不涉及该情况，建议删除修改歧义表达
