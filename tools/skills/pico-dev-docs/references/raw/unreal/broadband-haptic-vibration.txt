触觉反馈
========================================
PICO 4 系列设备配置了宽频线性马达，结合 SDK 能力，可通过手柄振动的形式提供触觉反馈。振动频率一般在 50 ~ 500Hz 之间，可精确模拟现实世界中大部分的触感输出，为用户提供丰富的触觉交互体验。
*非缓冲类触觉反馈
非缓冲类触觉反馈通常基于事件的发生而触发，提供相对简单的振动效果。通过结合事件类型和实场景，你可以设置振动属性，达到期望的振动效果。
*设备支持
PICO Neo3、PICO 4 系列。
*开启触觉反馈
调用 Set Controller Vibration Event 为手柄开启非缓冲类触觉反馈，并设置振动手柄、振动频率、振幅和振动时长。振动频率范围为 50 ~ 500Hz，频率越高，手柄振感越小。振幅取值范围为 0 ~ 1，取值越高，手柄振幅越大，振感越强。
 
*使用技巧
振动频率设置需基于实际事件类型。通常情况下，软性物体碰撞使用低频率，坚硬物体碰撞使用高频率。具体说明如下：
*
*缓冲类触觉反馈
通过缓冲类触觉反馈，你的应用会向指定手柄发送一个包含触觉数据（音频数据）的缓冲区，触发手柄振动。缓冲类触觉反馈常用于音乐类游戏或有音效需求的场景，当场景中的音量、音调、节奏等声音属性发生变化时，可触发手柄振动，让用户得以感知。
*设备支持
PICO 4。
*注意事项
*目前仅支持以下音频格式： MP3、WAV、OGG。
*不支持配置振动时长。振动时长由音频流的时长决定。
*开启触觉反馈
缓冲类触觉反馈所需的触觉数据（音频数据）来自于音频文件或 PICO Haptic File (PHF) 文件。左右手柄的触觉反馈由左右声道分别控制，你可以选择为单手柄或双手柄开启振动，同时设置振动参数，包括振幅、声道反转、缓冲类型等。声道反转由 channelFlip 参数控制。开启后，左（右）声道的音频数据将作为右（左）手柄的振动数据来源。
每一个触觉反馈都有一个 Source ID 作为其唯一标识，由 SourceID 参数返回。在相应蓝图接口参数中选择项目文件夹下的 PHF 文件， 可在调用接口后获取触觉反馈的 SourceID，以便后续对目标触觉反馈进行更新、停止、暂停或恢复。调用以下接口开启缓冲类触觉反馈：
*
*更新触觉反馈配置
调用 UpdateVibrateParams 接口来更新指定触觉反馈的振动配置，包括振动手柄、声道反转和振幅。目标触觉反馈由 SourceID 参数指定。
*停止/暂停/恢复触觉反馈
调用以下接口来停止/暂停/恢复指定振动。目标振动由 SourceID 参数指定。
*
*PHF 流式振动
PHF 流式振动具有较高的灵活性，你可以自定义往手柄发送触觉数据的时间间隔，同时自定义每次下发的数据量。基于该特性，你可以设置从整段音频的特定位置（例如中间）开始振动，或者取整段音频中的一部分作为触觉数据来发起振动。对于较大的音频数据文件，可通过 PHF 流式振动技术逐段下发，提升数据传输和振动反馈的流畅性。

接口

说明

备注

StartControllerVCMotor

为指定手柄开启触觉反馈。触觉数据来自存储于 Audio Clip 组件中的音频文件。

算法会根据音频流的声音属性（音调、音量）计算相应的振幅和振动频率。

StartVibrateBySharem

为指定手柄开启 PCM 类触觉反馈。PCM 数据转换自存储于Audio Clip 组件中的音频文件。

PCM 类触觉反馈具有 高保真 特点。通过脉冲编码调制 (Pulse Code Modulation, PCM) 技术对连续变化的模拟信号进行抽样、量化和编码，形成数字信号。

StartVibrateByPHF

为指定手柄开启触觉反馈。触觉数据来自于 PHF 文件。

PICO Haptic File (.phf) 是 PICO 自研的触觉数据文件格式，自定义程度高。

SaveVibrateByCache

缓存触觉反馈数据，可选择缓存时是否震动。
*注意：如果你使用 UE5 引擎，需在 UE 编辑器该资产的 细节（Details） 面板中，将 加载行为重载（Loading Behavior Override）设置为 强制内联（Force Inline），否则该接口无法生效。

从缓存目录中直接提取缓存数据，可以降低功耗，提高性能。

StartVibrateByCache

开启触觉反馈，需有缓存数据。

若在 SaveVibrateByCache 接口中配置了 “缓存但不振动（CacheNoVibrate）”，需调用StartVibrateByCache接口，在缓存完成后开启振动。

ClearVibratebyCache

清除触觉反馈数据。

无

说明

备注

StopControllerVCMotor

停止指定触觉反馈。

若该触觉反馈有缓存数据，可选择是否需要清除缓存数据，默认保留。

PauseVibrate

暂停指定触觉反馈。

若想恢复触觉反馈，需调用 ResumeHapticBuffer。

ResumeVibrate

字段

类型

说明

Name

string

PHF 文件名。

phfVersion

string

PHF 文件版本。

frameDuration

uint64_t

每帧数据下发时间间隔，默认为 20ms。

patternData_L

/

表示此处开始为左手柄的振动配置，无需赋值。

patternData_R

/

表示此处开始为右手柄的振动配置，无需赋值。

frameseq

uint64_t

帧序号。首帧序号为 1，随着时间累计，帧号增加。

play

int

控制振动状态：
* 0：停止振动
* 1：启动振动
* 2：振动中更改振动频率或振幅。
提示：一个连贯振动波形指令设计的 Play 值应是 1 > 2 > 2 > ... > 2 > 2 > 0，第一帧启动后，手柄也应振动。

frequency

int

控制振动频率，取值范围为 50-500Hz。

loop

int

设置当前帧为短振还是长振（循环振动）：
* 0：短振且不循环。振动时长为（1/frequency），完成后即停止。
提示：下一条指令的 Play 值必须为 1。
* 1：长振且一直循环，直至收到下一条指令。

gain

float

振幅，取值范围为 0-1，保留三位小数，振幅越高，振感越强。



接口

说明

PXR_CreateHapticStream()

创建流式传输的振动流。

PXR_WriteHapticStream()

在指定流中写入触觉数据。

PXR_RemovePHFHaptic()

移除指定流。

PXR_StartPHFHaptic()

启动指定流的传输。

PXR_StopPHFHaptic()

停止指定流的传输。

PXR_GetCurrentFrameSequence()

获取当前振动播放的帧号。

PXR_SetPHFHapticSpeed()

设置指定流的传输速度。

PXR_GetPHFHapticSpeed()

获取指定流的传输速度。
