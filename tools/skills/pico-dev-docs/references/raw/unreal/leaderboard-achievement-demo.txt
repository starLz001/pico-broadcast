空中霸主
========================================
空中霸主（Aerial Dominion）是接入 PICO 排行榜和成就服务的单人 VR 游戏 Demo。本文档提供该 Demo 介绍，带你快速了解应用接入排行榜服务、成就服务、“帐号&好友” 服务的实际效果，并提供 Demo 实现的具体步骤和代码说明。
*预览视频
你可以通过以下视频快速了解该 Demo 的主要功能。
 
*环境要求
要实现本 Demo，你需要配置以下环境：
*虚幻引擎 4.27.2 版本
*Visual Studio 2019 或 2022 版本
*SDK 2.1.1 版本及以上
要了解如何在 Unreal Engine 4.27.2 中配置安卓环境，请参考配置安卓开发环境。
*设备支持
PICO Neo3 系列和 PICO 4 系列。
*探索 Demo
你可以直接下载该 Demo 到本地，再使用 adb 命令将该 Demo 安装到 PICO 设备上体验。要下载 adb 命令行工具，参考安卓官方文档 Android 调试桥 (adb)。

*排行榜设计说明
Demo 内排行榜分为总排行榜和好友排行榜，具体设计如下：
*总排行榜：所有玩家单局游戏得分的排行，降序展示前 50 名玩家。
*好友排行榜：当前玩家的好友排行。若玩家首次启动 Demo 时拒绝好友关系授权，则此排行榜为空。
*写入规则
每局游戏结束后，若该局游戏得分为历史最高分，则将分数写入排行榜。
*好友超越通知
Demo 使用的排行榜服务在控制台启用了好友超越通知。若好友的排名超过当前玩家，该玩家将收到 Toast 通知。

*实现 Demo
本部分介绍自行实现 Demo 中排行榜&成就能力的步骤。
*第一步：获取 Demo 项目
*前往 GitHub 下载排行榜&成就 Demo 的项目文件夹到本地。
*解压该 Demo 压缩包到 Unreal Projects 目录下。
*将下载的 2.1.1 及以上版本的 SDK plugins 包移动到 Demo 文件夹内。
* 
*右键点击 AerialDominionVR.uproject 文件，点击 Generate Visual Studio project files，生成 AerialDominionVR.sln 文件。
* 
*双击 AerialDominionVR.sln 文件，该文件将通过 Visual Studio 打开。
*在 Visual Studio 界面中，右键点击 AerialDominionVR，在下拉选项中，点击 生成（Build）。
* 
*项目生成成功后，双击 AerialDominionVR.uproject 打开 UE 工程。
*第二步：创建应用
要使用 PICO 的平台服务能力，你需要前往 PICO 开发者平台创建应用。要了解更多信息，参考创建应用。
*第三步：在开发者平台创建排行榜
本 Demo 使用了 PICO 平台服务中的排行榜服务。因此，你需要在创建的应用中配置排行榜信息。步骤如下：
*登录 PICO 开发者平台。
*在 我的应用 页面，选择在第二步中创建的应用，进入应用概览页。
*在左侧导航栏，点击 平台服务 > 排行榜，点击 +创建排行榜。
* 
*  在排行榜配置页，参考下表填写信息。
**

*登录 PICO 开发者平台。

*Gameplay 架构与蓝图实现
本部分介绍 Demo 中的 Gameplay 的蓝图实现、GameMode 类与 C++类。
*获取排行榜信息
你可在虚幻引擎蓝图编辑器中调用 GetEntries，在其回调函数中从客户端一次性地、逐条地获取总排行榜信息。
* 
对于好友排行榜信息，你只需更换 GetEntries 输入参数即可获取。要了解 Demo 中具体如何获取排行榜和好友排行榜信息，你可前往 \AerialDominionVR-Unreal\AerialDominionVR\Content\UMG\UI_LeaderBoardForALL.uasset 文件查看相关蓝图。
*获取成就信息
你可在虚幻引擎蓝图编辑器中调用 Pico Get All Progress，在其回调函数中从客户端获取对应成就的进度信息。
* 
你可在蓝图编辑器中调用 PicoGetDefinitionsbyName，在其回调函数中获取对应成就的定义信息。
* 
将两个函数组合使用，便可获取用户当前已解锁和未解锁成就进度及其对应名称，以实现 Demo 中成就面板的展示。你可前往 \AerialDominionVR-Unreal\AerialDominionVR\Content\UMG\UI_Achievements.uasset 文件查看获取成就信息的所有蓝图实现。

游戏元素

说明

规则

飞机

玩家使用右手柄控制飞机，飞机可以发射子弹攻击敌方。

无

敌方

敌方从玩家视野正前方远处随机位置生成，朝飞机匀速移动，并不断向飞机发射子弹。

不同大小的敌方生命值不同。详情如下：
*较小敌方生命值为 1，被击中后消失
*较大敌方生命值为 3，被击中 3 次后消失
*敌方波次：每 10 秒生成一波敌方

得分

当前局的游戏得分。

玩家得分的方式有以下三种：
*击灭较小敌方获得 1 分
*击灭较大敌方获得 3 分
*获得道具宝箱可加 10 分

生命值

当前局玩家的生命值。初始生命值为 100。

玩家生命值变化的方式有以下三种：
*被子弹击中，生命值减 1
*被敌方撞击，生命值减 2
*获得道具回血药后，生命值加 10，上限 100

道具

道具有概率在玩家击灭敌方后出现，出现后自动生效。


道具有 3 种形式，对应机制如下：
*防护罩：被敌人子弹打中或撞击不减生命值，持续 10 秒
*回血药：生命值加 10，上限 100
*宝箱：得分加 10

C++ 类

功能描述

AirPlayerState

记录玩家生命值与受到伤害后生命值减小的值。当生命值小于 0 时，AirPlayerState 将结束当前游戏。

AirPropActor

道具类型。该基类实现 Demo 中以下三种道具的生成与使用：
*防护罩：被敌人子弹打中或撞击不减生命值，持续 10 秒
*回血药：生命值加 10，上限 100
*宝箱：得分加 10

EnemyActor

敌方 actor 的基类。该基类实现敌方的移动、生成子弹、造成伤害等游戏逻辑。

EnemyBullet

子弹的基类。该基类实现子弹的移动、发射、造成伤害的游戏逻辑。玩家发射的子弹和敌方发射的子弹均继承于该类。

EnemyManager

管理敌人的生成。

InvincibleActor

实现保护罩 actor 功能。

GradesManagerSubsystem

实现暂停游戏、开始游戏、结束游戏、记录日志等功能。
