排行榜 Demo
========================================
本文档介绍 PICO Unreal Integration SDK 提供的排行榜服务 Demo。要了解排行榜服务，查看排行榜文档。
*前提条件
确保你 PICO 设备的 PUI（ROM）版本为 4.8.0 及以上。
*使用说明
你可以前往 PICO GitHub 获取对应引擎版本的排行榜 Demo。排行榜 Demo 位于 Content\Maps\GameMaps 中。
平台服务为排行榜提供两个Demo：Game_PicoGameInstance_Demo 和 Game_Library_Demo 。
Game_PicoGameInstance_Demo
*包含排行榜服务的全部接口，可以用于接口调试、关卡测试，并将其打包为 Android .apk 文件进行测试；
*提供图形化界面，在其左侧功能按钮列表中：
*ReadLeaderboardData 按钮对应上文中 ReadLeaderboards 接口
*ReadLeaderboardDataForFriends 对应上文中的 ReadLeaderboardFriends 接口
*WriteLeaderboardData 按钮对应上文中的WriteLeaderboards接口
操作步骤
*启动 Game_PicoGameInstance_Demo。
*在左侧功能栏中，点击你需要的功能按钮（要调用的接口）。
*Params 面板中将列出需为该接口配置的参数，如 PageIndex、LeaderboardName 等。
*输入参数。
*点击 Execute。
*你可在右侧 Execute Log 面板中，查看执行的结果。
* 
Game_Library_Demo
你也可以打开 Game_Library_Demo，进行蓝图接口测试。该 Demo 提供的界面和 Game_PicoGameInstance_Demo 一致，区别仅在于它调用插件为开发者提供的默认的蓝图接口。
 
上图为该 Demo 中执行 ReadLeaderboards 的分支，它会自动调用 Login，你可以按照需要对其进行修改。
