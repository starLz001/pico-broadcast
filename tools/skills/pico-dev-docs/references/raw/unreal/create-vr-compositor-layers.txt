创建 VR 合成层
========================================
PICO SDK 支持你在虚幻引擎创建 VR 合成层，渲染场景中的焦点对象，例如信息、文本、光标，或展示简单的场景环境和背景。 本文档介绍如何创建 VR 合成层。你也可参考使用 VR 合成层示例直接上手体验 PICO 提供的 VR 合成层示例。
*合成层概念
使用 VR 合成层可提高渲染速度和质量。通常来说，渲染 VR 内容时，左右眼摄像机首先将捕捉到的场景内容渲染到 Eye Buffer 上；绘制完成后，异步时间扭曲线程（Asynchronous Timewarp，ATW）对 Eye Buffer 进行畸变、采样、合成等处理；处理完毕后，场景内容最终被渲染到屏幕上。若通过 VR 合成层技术进行场景渲染，则无需将场景内容绘制到 Eye Buffer 上，而是直接透传给 ATW 线程进行畸变、采样、合成等处理。因此，减少了一次额外的纹理采样，简化了整个渲染流程，同时可提升渲染质量。 
*注意事项 
*目前，单个场景最多支持添加 7 个 VR 合成层，建议不超过 4 个。
*VR 合成层不可以作为相机组件的子组件。 
*使用正确的坐标位置关系放置模型和叠加层，例如遵循近处物体遮挡远处物体的规则；否则会存在景深冲突，引起视觉不适。

参数

说明

动态纹理（Live Texture）

控制合成层纹理是否需要每帧（场景捕捉、视频等）更新实时内容。如果是，勾选该选项。 

支持深度（Supports Depth） 

控制合成层是否与场景几何体深度相交。默认情况下，合成层总是显示在场景中其他对象的顶部，如果你想要更改该规则，勾选该选项。
* 

无透明度通道（No Alpha Channel）

控制立体图层纹理是否使用 Alpha 通道。如果纹理不使用自己的 Alpha 通道，勾选该选项。 

纹理（Texture） 

立体图层上显示的纹理。 

四边形保留纹理比例（Quad Preserve Texture Ratio） 

控制合成层的比例是否按照纹理的比例进行显示。如果是，勾选该选项。 

附加标志（Additional Flags）

控制合成层是否开启超分辨率、超采样和锐化功能。根据需要开启对应的 FlagName 即可。

四边形尺寸（Quad Size） 

渲染的合成层四边形的大小。 

UV 矩形（UV Rect） 

决定了四边形合成层（Quad Layer） 的 UV 坐标。左上角为 UV (0,0)，右下角为 UV (1,1)。 

立体图层类型（Stereo Layer Type） 


指定合成层参照哪个空间坐标系进行平移和旋转。SDK 目前支持以下类型： 
*场景锁定（World Locked）： 无论如何移动或旋转头戴设备，合成层都不会随着头戴移动，而是保持其在世界中的固定位置。 
*追踪器锁定（Tracker Locked） ：合成层组件位置与其父组件的位置保持相对静止。 
*面部锁定（Face Locked）： 无论如何移动或旋转头戴设备，合成层内容保持在屏幕中的固定位置。 

立体图层形状（Stereo Layer Shape） 

指定合成层的形状。SDK 目前支持 Quad Layer、Cylinder Layer、Equirect Layer、Cubemap Layer 和 EAC (Equi-Angular Cubemap) Layer 五种形状。要了解每个形状及其属性设置，查看下文的合成层形状及其属性说明。

优先级（Priority） 

如果你需要使用多个合成层，你可以使用优先级设置来控制合成层显示的深度顺序。数值越低，优先级越高。

四边形图层（Quad Layer）

具有四个顶点的四边形平面纹理，通常用来显示场景中的文本或信息。

圆柱体图层（Cylinder Layer）

具有柱面弧度的圆柱形纹理，通常用于显示曲面 UI 界面。 


* 
*半径（Radius）：控制圆柱体图层半径
*覆层弧形（Overlay Arc）：控制圆柱体图层的弧线角度
*高度（Height）：控制圆柱体图层的高度

Equirect Layer

球体纹理，通常用于显示 360/180 全景纹理。在使用这一形状时，建议你在上述 Stereo Layer 选卡下：
*勾选 无透明度通道（No Alpha Channel）
*勾选 四边形保留纹理比例（Quad Preserve Texture Ratio）
*将 立体图层类型（Stereo Layer Type） 设为 场景锁定（World Locked）


* 
目前，PICO 仅支持修改 Left UVRect 和 Right UVRect，用于选取纹理的显示范围。
*左 UV 矩形（Left UVRect）：用于选取左眼纹理的显示范围。 范围 [0,1]，左上角 UV(0,0)，右下角 UV(1,1)。
*右 UV 矩形（Right UVRect）：用于选取右眼纹理的显示范围。范围[0,1]，左上角 UV(0,0)，右下角 UV(1,1)。

立方体贴图层（Cubemap Layer）

立方体贴图（Cubemap）是将多个纹理组合起来映射到一张纹理上的一种纹理类型。

参考使用 VR 合成层示例 Cubemap Layer 一节了解该图层相关参数配置。

Equi-Angular Cubemap (EAC) Layer
 

等角立方体贴图是一种用于展示 180 度或 360 度全景图片和视频的投影技术，是等距投影和立方体投影的结合体。
在 EAC 投影中，360 度全景图首先被分成六个立方体面，然后将来自每个立方体面的像素映射到一个球体上，从而创建一个可以从任何角度浏览的无缝全景图像。 EAC 的 6 个面的排列方式如下图所示：

PICO SDK 支持 EAC360 和 EAC180。EAC 图层支持 Transform 参数。
对于 EAC360 图层，你还可以设置其 Offset 和 OffsetRot 参数：
*Offset：EAC 纹理中相机矩阵的位置。需要注意的是，从 EAC 纹理中取样时，此位置将会被反转。
*OffsetRot：EAC 纹理中相机矩阵的旋转。需要注意的是，从 EAC 纹理中取样时，此旋转也将被反转。

若不调用该接口，可能在关卡切换等情况出现纹理资源加载失败的问题。

开启支持深度可能会影响性能。

*超分辨率可以将低分辨率图像重建为高分辨率图像，提升画面清晰度。超采样可以使用比正常分辨率更高的分辨率来采样数据，防止锯齿边缘的产生。锐化可以通过增强图像中高频信息，使图像的细节边缘和轮廓更加清晰，增强对比度，从而突出图像的重要特征和细节。
*超分、超采样和锐化不支持同时开启，三者的优先级如下：超采样 > 锐化 > 超分。在同一图层上，三者互斥，只能选择一种使用；在不同图层之间，三者可以组合使用。 
*超分会增加合成服务侧 GPU 的压力。对三个以上的图层开启超分可能导致合成服务侧 GPU 资源紧张而产生画面撕裂。SDK 会在 GPU 负载过大时自动关闭超分辨率能力，待 GPU 负载恢复正常后自动开启。
*锐化功能增加了采样次数和计算量，会增加 GPU 功耗。 
*锐化功能可能会使图像噪点或摩尔纹更明显。
