如何更改应用安卓包名及版本？
========================================
*什么是应用安卓包名？
UE 默认的应用安卓包（Android package name）命名组织形式为 “com.YourCompany.[Project]”：
*一级包名：com
*二极包名：一般为公司/个人域名
*三级包名：根据应用进行命名。
*什么是安卓包保存版本？
安卓包保存版本（Store Version）表示你对外发布应用的版本号。每个项目都需要有版本控制来记录所有发布的版本。
你也可以自行设置项目安卓包名和保存版本，以便更好地识别应用。参考以下步骤：
*在编辑器左上角，点击 编辑（Edit） > 项目设置（Project Settings）。
*在左侧导航栏，选择 平台（Platforms） > Android。
*在 APK 打包（APK Packaging） 选卡下：
* 
*设置 安卓包名称。
*设置完后，编辑器将会自动帮你在导出的 APK 文件的 AndroidManifest 文件中填充包名；你也可以对在 AndroidManifest 文件中对其进行修改。
*设置 保存版本。
* 


在应用每次提交 PICO 商店前，请确保该版本号比之前的版本更高。
