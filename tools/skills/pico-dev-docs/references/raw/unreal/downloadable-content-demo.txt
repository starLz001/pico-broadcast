可下载内容 Demo
========================================
本文档介绍 PICO Unreal Integration SDK 提供的可下载内容服务 Demo。要了解可下载内容服务，查看可下载内容文档。
*前提条件
设备的 ROM 版本为 4.8.0 或以上。
*使用说明
你可以前往 PICO GitHub 获取对应引擎版本的 DLC Demo。DLC Demo 位于 Content\Maps\WindowsMaps 中。Demo 的图形化界面如下：
 
界面的控件说明见下表：
*
*API 参考
*DLC 相关 API 详情可阅读 API 参考。



界面控件

说明

AssetFileList 下拉菜单

获取到的 AssetFileList 列表。

AssetFileID 输入框

作为输入和显示的资产文件 ID。

AssetFileName 输入框

作为输入和显示的资产文件名称。

DeleteByID 按钮

点击后，可通过文件 ID 删除某个设备上已下载的某个 DLC。

DeleteByName 按钮

点击后，可通过文件名称删除某个设备上已下载的某个 DLC。

DownloadById 按钮

点击后，可通过文件 ID 将某个 DLC 下载到设备上。

DownloadByName 按钮

点击后，可通过文件名称将某个 DLC 下载到设备上。

DownloadCancelById 按钮

点击后，可通过文件 ID 取消下载某个 DLC。

DownloadCancelByName 按钮

点击后，可通过文件用名称取消下载某个 DLC。

GetAssetFileStatusById 按钮

点击后，通过资产文件 ID 获取文件当前状态。

GetAssetFileStatusByName 按钮

点击后，通过资产文件名称获取文件当前状态。

GetAssetFileList 按钮

点击后，可获取某个应用的可用 DLC 列表。

GetNextAssetDetailsArrayPage 按钮

点击后，可获取某个应用的下一页 DLC 列表。

LaunchCheckoutFlow 按钮

点击后，启动 DLC 购买流程。
