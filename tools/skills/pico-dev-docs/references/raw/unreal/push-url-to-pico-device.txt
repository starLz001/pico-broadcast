推送 URL 到 PICO 设备
========================================
PDC 提供一系列快捷工具。在快捷工具卡片中，你可以推送指定 URL 到 PICO 设备，该 URL 将在设备中的 PICO 浏览器应用内打开。本文档介绍使用 PDC 推送 URL 的具体步骤。
 
*前提条件
*你已经安装了 PDC 工具并连接到你的 PICO 设备。详细步骤可参考安装 PDC 并连接设备。
*具体步骤
*打开 PDC 工具。
*在 快捷工具 卡片的 PICO 浏览器 字段右侧，输入你想在设备内打开的 URL 地址，点击 运行。
* 
*PICO 设备头戴端将在 PICO 浏览器 应用内打开该网址。
