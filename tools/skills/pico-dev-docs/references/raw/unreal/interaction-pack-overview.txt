交互概览
========================================
PICO 将交互相关功能统称为交互套件（Interaction Pack），提供输入映射、系统键盘、触觉反馈、运动追踪等能力。相关说明如下：
*




功能

说明

输入映射

PICO Unreal Integration SDK 支持使用 Unreal 官方键值进行手柄和头戴的输入事件映射。

系统键盘

用户可通过应用内的键盘在各类文字场景下完成文本输入，例如：文字聊天、设置昵称等。

触觉反馈

触觉反馈可精确模拟现实世界中大部分的触感输出，为用户提供丰富的触觉交互体验。

眼动追踪

通过眼动追踪功能，可在应用中实时追踪用户的注视点，将用户的眼部移动作为 PICO 设备的输入。

手势追踪

手势追踪功能可以将用户的手部动作作为 PICO 设备的输入。

面部追踪

在检测到人脸的前提下，在后续帧中持续捕捉人脸位置和面部表情等信息，将其作为 PICO 设备的输入。

全身动捕

*全身动捕是一种动作捕捉技术，用于收集用户的身体位置和动作信息，并将其转换为可再现的姿态数据。

独立追踪

独立追踪模式可实时追踪并输出体感追踪器的 6DoF 信息，用于追踪体感追踪器本体或绑定的物体。
