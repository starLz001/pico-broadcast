void appCopyrightVerify(String packageName, Consumer<Integer> callback);
参数名称
类型
说明
packageName
String 
应用报名
callback

Consumer<Integer>

callback 执行结果回调：
1:接口调用失败

有版权的情况：
100:  查询的应用不在校验名单中
101:  无网且无缓存该应用的数据
102:  请求服务端后，返回该应用有版权
103:  网络异常，但本地缓存该应用有版权
无版权的情况
-102：请求服务端后，服务端返回该应用无版权
-103：网络异常，但本地缓存该应用无版权
-104：请求服务端后，发现应用签名与服务端返回的对不上
-105： 网络异常，但本地缓存发现应用签名与服务端返回的对不上
try {
ToBServiceHelper.getInstance().getServiceBinder().appCopyrightVerify("com.example.app", new IIntCallback.Stub() {
    @Override
    public void callback(int i) throws RemoteException {}
});

int keepAliveBackground(int keepAlivePid, int flags, int level);
参数名称
类型
说明
keepAlivePid
int 
要保活进程pid
flags
int 
接口会根据flag取值执行对应操作，具体取值和操作如下：
            2：当前进程提高优先级；
            1：当前进程所在包下的所有进程提高优先级；
            0：取消（flag 1或2 的）高优先级；
level
int 
提高优先级的程度
 1:高优先级 将adj提高到 149
类型
说明
int 
0-成功
1-失败
((IToBServiceProxy)ToBServiceHelper.getInstance().getServiceBinder()).keepAliveBackground(111111, 2, 1);
