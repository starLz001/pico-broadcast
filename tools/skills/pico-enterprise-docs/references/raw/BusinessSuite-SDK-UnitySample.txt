*核心组件介绍
*PXRBusinessSuiteAPI ： 负责SDK的初始化和消息通信的预处理，并封装所有供外部访问的方法；

* 

*注意：同一时刻仅允许存在一个PXRBusinessSuiteAPI实例。

*所有数据的更新及状态的反馈均通过PXRBusinessSuiteAPI.OnDeviceCmd事件派发，上层应该通过对此事件的侦听获得设备状态。例：
* 


*PXREAOpenApiCallbackType 枚举代表了所有服务端返回的消息类型，如有特殊需求，需要屏蔽相关消息的，可以自行通过Inspector面板设置ReceiveMask值：
* 

*Device ：设备基本数据的缓存对象；
*所有Device数据的更新均是依赖于PXRBusinessSuiteAPI.OnDeviceCmd事件，如需要获取最新的设备数据，应该先调用对应的请求函数，然后等待OnDeviceCmd事件的响应，之后再读取对应数据。


*YuvTexture2D ：YUV纹理类；

*服务端返回的纹理数据默认为YUV420格式，YuvTexture2D类封装了从YUV420数据到Unity Texture2D的转化。
*
* 

*你也可以选择自行处理YUV数据。例如通过编写Shader逻辑，将YUV的转化交给GPU计算。

*另外：
*如果你使用的企业套件版本为4.3.0或更高，则可以通过修改key-setting.ini配置中PixelFormat=1 来将格式改为BGRA。然后就可以直接使用Unity Texture2D对象：

* 

*详细代码逻辑可以参考SDK的Sample场景。

private void Awake()
{
    PXRBusinessSuiteAPI.OnDeviceCmd += OnDeviceCMD;
}

private void OnDestroy()
{
    PXRBusinessSuiteAPI.OnDeviceCmd -= OnDeviceCMD;
}

private void OnDeviceCMD(PXREAOpenApiCallbackType type, string deviceId, int status, byte[] custom)
{
if (!string.IsNullOrEmpty(deviceId))
{ 
Device device = PXRBusinessSuiteAPI.GetDevice(deviceId);
}
}
private YuvTexture2D _yuvTexture;
private void UpdateScreenMonitorTexture()
{
    if (_yuvTexture == null)
    {
        _yuvTexture = new YuvTexture2D(_device.ScreenFrame.Width, _device.ScreenFrame.Height);
    }
    
    _yuvTexture.LoadRawYuvData(_device.ScreenFrame.Data);
    Image.texture = _yuvTexture.Texture2D;
    Image.transform.localScale = Vector3.one;
}
private Texture2D _rgbTexture;
private void UpdateScreenMonitorTexture()
{
    if (_rgbTexture == null)
    {
    _rgbTexture = new Texture2D(_device.ScreenFrame.Width, _device.ScreenFrame.Height, TextureFormat.BGRA32, false);
    }
    
    _rgbTexture.LoadRawTextureData(_device.ScreenFrame.Data);
    _rgbTexture.Apply();
}
