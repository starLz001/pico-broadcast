String pbsStateGetDeviceInfo(PBS_SystemInfoEnum systemInfoEnum, int ext);
参数名称
类型
说明
systemInfoEnum
PBS_SystemInfoEnum 
详见枚举类PBS_SystemInfoEnum
ext
int
扩展位，无意义
类型
说明
String
systemInfoEnum 对应的设备信息
蓝牙状态：1-已连接，0-未连接
WiFi状态：1-已连接，0-未连接
充电状态：充电中-BatteryManager.BATTERY_STATUS_CHARGING
未充电-BatteryManager.BATTERY_STATUS_DISCHARGING
String puiVersion = ToBServiceHelper.getInstance().getServiceBinder(). pbsStateGetDeviceInfo(PBS_SystemInfoEnum.PUI_VERSION, 0);

float[] pbsGetDeviceTemperatures(int type,  int source);
参数名称
类型
说明
type
int 
0-DEVICE_TEMPERATURE_CPU （设备CPU温度）
1-DEVICE_TEMPERATURE_GPU （设备GPU温度）
2-DEVICE_TEMPERATURE_BATTERY （设备电池温度）
3-DEVICE_TEMPERATURE_SKIN （设备表面温度）
source
int
0-TEMPERATURE_CURRENT （当前的设备温度）
1-TEMPERATURE_THROTTLING （节流温度阈值）
2-TEMPERATURE_SHUTDOWN （关机温度阈值）
3-TEMPERATURE_THROTTLING_BELOW_VR_MIN（节流温度阈值，高于此温度阈值将不会满足VR模式的最低时钟频率。） 
类型
说明
float[]
返回float类型的设备温度数组
float[] temps = ToBServiceHelper.getInstance().getServiceBinder().pbsGetDeviceTemperatures(HardwarePropertiesManager.DEVICE_TEMPERATURE_CPU, HardwarePropertiesManager.TEMPERATURE_CURRENT);
