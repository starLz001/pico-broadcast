*json消息接口

*参数说明
*msg: 传入参数，json 格式字符串
*res: 传出参数，以字符串方式返回查询结果，存储空间由用户分配，请根据消息类型分配足够的空间
*len: 传入参数，指定 res 长度，以字节为单位
*timeout: 查询超时时间，单位毫秒，防止长时间无响应导致 API 阻塞，默认超时时间300毫秒
